# 游戏开始页：早餐旅行手账与世界地图

## 当前体验（2026-09-14）

启动 Logo → 早餐铺首页 → 新旅程／继续旅程／世界地图 → 城市明信片 → 现有城市经营首页。

- Logo 停留 3 秒，可鼠标或 Enter／空格跳过；返回首页不重播。
- 新旅程先看天津手账，最终点击“从天津出发”才创建新档。已有或损坏存档先确认覆盖，默认焦点为取消；失败保留原数据。
- 继续旅程展示上次城市、已开放营业日、章节状态、金币与下一城市目标；“前往早餐铺”进入经营首页，不恢复营业中途状态。
- 世界地图沿用天津 → 武汉 → 西安 → 广州 → 扬州的真实解锁条件；海外区域只是探索装饰。只浏览明信片不更改存档位置。
- 从各城市经营首页进入地图时，返回按钮回到来源城市。地图也可返回游戏首页；所有开店与升级仍在原经营首页进行。
- 正式结算首次成功保存章节完成后，关闭账本触发盖章和路线演出，随后展示下一城明信片。可跳过；重复完成、练习和加载旧档不触发。扬州完成后展示五城地图。
- 设置支持常用窗口尺寸、无边框全屏、主音量／音乐／音效和静音。显示切换 15 秒内确认，超时或退出弹窗恢复原设置。音乐通道预留，当前无背景音乐。
- 设置、声音、帮助和退出位于旅行外层首页与地图；使用 P2 圆形底板和专属图标，同时保留文字与键盘焦点。

详细的已实现内容、未实现内容和后续素材清单见 [入口页面实现与美术待办](入口页面实现与美术待办.md)。

## 实现与兼容

`Scenes/UI/StartScreen.tscn` 保留固定背景、1920×1080 画布、页面及弹窗容器。旅行页内容通过 `StartScreen` 各 partial 文件更新；图片、输入、设置弹窗和页面流程分开维护。

`JourneyModel` 统一五城展示信息；`GameController` 处理实际进城，继续使用 `SaveService.ContinueCityId`、`TryRecordCityVisit` 与失败回滚。原城市地图的入口现在导向旅行世界地图，五城工作台与经营规则保持原实现。

游戏存档仍为 v3，不新增持久化游戏字段。`PendingJourneyCompletion` 只是一条内存演出消息，成功重置、加载或消费后清空。v1/v2 迁移及已有 v3 的继续位置兼容逻辑保持原样。

`JourneySettings` 作为自动加载服务，将设置保存在 `user://journey_settings.cfg`，与新旅程重置分离。首次不修改窗口模式，音量默认 100%；音效原始播放音量保留。总线为 Master 下的 Effects 和 Music；主静音统一生效。

外层显示时使用 Expand 并等比居中画布，隐藏时恢复原窗口适配。Tab／方向键切换入口，Enter／空格激活；滑块用左右键调整，Esc 返回。弹窗限制背景焦点和点击，关闭后恢复原焦点。

本次只复用 `resource/art/Global/StartPage` 与已有城市资源／食物控件，没有生成、绘制或覆盖源美术。旅行虚线和按钮底板的透明空白通过运行时 AtlasTexture 裁切视区处理，PNG 不变。按钮用 NinePatchRect 保留端部比例，只伸展空白中段。

## P2 素材接入（2026-09-14 追加）

开发运行参数：`-- --dev-ui` 开启未解锁城市测试入口；桌面 Depth、点击框和拖放框默认隐藏，需要布局调试时额外添加 `--desk-guide`（例如 `-- --dev-ui --desk-guide`）。两个开关互相独立。

- 首页使用墙挂地图底板、新／已有旅程封面及存档纸签；文字仍由控件提供，纸签只展示真实城市和已开放营业日。
- 通用主次按钮、圆形功能底板、设置／音频／帮助／退出图标已接入；音乐、音效图标随各自音量和全局静音更新。
- 手账页签打开地图，左翻页箭头用于返回；从明信片返回地图恢复所选城市焦点。悬停环与选中底座只表达浏览状态，不写入城市访问。
- 武汉、西安使用新明信片、专属节点与印章；下一站演出使用解锁光效、飘带、三帧星闪和路线旗标。
- 首页／启动页使用晨光、窗内缓移云层与三帧蒸汽。所有 Tween 跟随页面清理，动画素材按原帧画布对齐。
- 中国阶段纪念章用于现有五城全部完成的成果展示，没有增加城市或存档字段。P2 文档第 36 项明确留待多存档，空白存档手账本次不启用。

## 复现

测试使用独立存档目录，不接触玩家进度。图形专项运行去掉 `--headless`，增加 `--capture`；快速图库增加 `--capture --gallery`，720p 再加 `--small`，宽屏再加 `--wide`。

```powershell
# 当前沙箱不能读取系统 NuGet 配置，使用项目已有的本地构建配置。
$env:APPDATA = "$PWD/.tmp/build-appdata"
$env:LOCALAPPDATA = "$PWD/.tmp/build-local"
$env:DOTNET_CLI_HOME = "$PWD/.tmp/dotnet-home"
dotnet build --no-restore

# 隔离 Godot 用户目录与设置。
$env:APPDATA = "$PWD/.tmp/journey-test-user"
$env:LOCALAPPDATA = "$PWD/.tmp/journey-test-local"
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' `
  --headless --path . --log-file "$PWD/.tmp/journey-test.log" `
  res://Scenes/Tests/StartScreenSelfTest.tscn `
  -- --journey-settings res://.tmp/journey-test-settings.cfg
```
