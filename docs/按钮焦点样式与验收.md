# 按钮焦点样式与验收

2026-09-14：修复首页图片按钮出现矩形外框，并排查其余按钮的同类问题。

## 实现规则

- 图片按钮使用 `ArtworkButtonFocus`，移除原生矩形 focus 样式；`TextureRect` 复用现有 alpha 轮廓高亮，形状跟随实际图片及缩放。
- 九宫格按钮直接对原有底板进行暖色提亮，保留九宫格端部形状；纯文字入口使用下划线。焦点提示不改变按钮的点击区域、禁用条件或键盘导航。
- 旅行首页、地图节点、手账入口、设置及帮助等共用按钮工厂统一接入；首页圆形工具按钮也沿圆形图片高亮。
- 天津、武汉、西安 HUD 的暂停和图标式账本入口复用相同处理。
- 广州、扬州经营页及经营首页、普通／实验煎饼工作台共 106 个原生按钮补齐匹配底板圆角的焦点样式。每个场景共用一份透明描边资源，不另画方框；聚焦文字沿用各按钮正常文字颜色。
- 原生按钮已有且匹配底板的焦点样式继续保留；已禁用焦点或已有交互轮廓的控件不移除其原有交互反馈。
- 鼠标移出已聚焦的旅行按钮时保留选中反馈，按下后松开也恢复当前焦点／悬停状态。

## 排查与验证

- 静态检查项目 C# 按钮工厂、显式 focus 样式及场景内 Button 资源。
- `StartScreenSelfTest --focus-gallery --capture` 在真实主场景中核对普通底板与焦点圆角是否匹配，以及无底板图片按钮是否残留矩形焦点框。首页状态检查 307 个可聚焦按钮，地图状态检查 317 个；两组有重叠，不累加为独立按钮数量。
- 1920×1080、1280×720 实际视口检查首页胶囊按钮、圆形图标、地图节点、设置／手账九宫格按钮及广州、扬州经营首页；修改后未见独立矩形外框。小分辨率确认原生按钮聚焦时文字仍清晰。
- `StartScreenSelfTest`：108 项通过，0 失败，保留导航、存档保护及设置行为。
- `BusinessHudSelfTest --capture`：天津、武汉、西安各在 1920／1280 宽度通过，确认图标按钮可用键盘聚焦、没有矩形焦点样式，暂停／恢复正常。已查看三城暂停按钮聚焦截图。
- C# 构建：0 警告、0 错误；`git diff --check` 通过。
