## 已接入

| 工位 | 可见操作与持续状态 |
| --- | --- |
| 煮面锅 | 原面入勺、烫煮气泡与蒸汽、品质变化、手动/自动提篮、自然滴水、抖水、倾倒熟面、空勺返回 |
| 拌面台 | 空碗、熟面、芝麻酱与基础酱汁倾倒、葱花/辣油/牛肉覆盖层、筷子跟随碗内手势、半拌匀与拌匀、整碗出餐 |
| 豆皮锅 | 浇浆、加蛋、手动/自动翻面、铺馅、煎熟、四刀切痕、八块入盘、实际库存、偏焦/焦糊与丢弃 |
| 蛋酒台 | 底料杯库存、杯子移到出水嘴、冲水、成品杯、交付、补底料 |

操作方法：点击漏勺执行当前步骤；点击生面盘向可用的空勺下面；点击调味容器加料；按住碗内移动拌面，松手、出碗或失焦停止；拌匀后松开，再按住成品碗拖给顾客。点击豆皮锅执行当前步骤，从备货盘拖出一块豆皮给顾客。点击蛋酒台冲泡，完成后按住成品杯拖给顾客。底部按钮仅执行制作或补料；热干面、豆皮出餐按钮改为拖拽说明，蛋酒成品待取时按钮禁用。无需选中顾客。

## 状态与动画

- `WuhanWorkstationView` 独立负责绘制、实物命中、工具和转运动画；`WuhanDayScreen` 协调制作、库存和顾客交付。
- 制作状态机即时提交一次结果，制作动画结束不再扣料或入库。出餐复用天津 DragService：吸附完成时复核目标顾客 ID、订单与库存，再提交一次交付；落空、取消或目标变化保留成品。漏勺、碗、豆皮锅、备货盘、蛋酒分别加动作锁，倒面同时锁漏勺和碗，入库同时锁豆皮锅和盘。
- 制作 Tween 由营业页统一手动推进；失焦、暂停和提前打烊确认框同步冻结制作及动画。隐藏、重开和结算清理临时动作。
- `TryTransferTo` 在碗接收成功之后才清空漏勺，避免碗满时丢失一份面条。
- Lv2 煮面锅沿用数据中的“锁熟、手动提篮”；Lv3 双勺分别自动提篮。豆皮 Lv3 自动翻面。
- 保留存档、配方、生产时间、容量和经营数值；复用 `accessibility/reduce_motion` 设置。

## 素材处理及待确认清单

部分 PNG 留白区存在低透明度残留。绘制时按 alpha ≥ 32/255 计算可见主体边界，统一工具、容器及食物定位；源文件保留不变。

武汉场景及设备展示已接入 `resource/art/Wuhan` 中 19 张对应的 `v2.png` 素材；风格锚点图作为美术参考，没有场景引用。三档新版煮面锅均为无漏勺锅体，直接显示原画水面，独立绘制漏勺，并按各等级的前沿高度遮挡入水部分。新版锅体使用方形画布，漏勺、Lv3 豆皮锅面、蛋酒杯及出水落点已按新图对齐。豆皮成品原图为斜视角，采样其顶面四角并投影到实际锅面。成品蛋酒杯自带蒸汽，绘制时将陶瓷杯体对齐底料杯，蒸汽另行绘制。

| 后续可补素材 | 用途 | 当前替代方案 |
| --- | --- | --- |
| 倾倒中的连续熟面条层 | 丰富面条滑入碗中的形变 | 已有熟面层位移、旋转及落碗过渡 |
| 独立破壳鸡蛋 | 丰富豆皮加蛋动作 | 复用天津鸡蛋、武汉鸡蛋覆盖层及程序蛋液 |

这些素材不是本轮功能前置条件，后续生成需确认。透明背景素材继续遵守“先生成绿底，再抠图”。水流、水滴、气泡、蒸汽和切痕无需生成图片。

## 复现验证

从项目根目录执行，使用 Godot Mono。沙箱下将测试存档与日志放入 `.tmp`，避免触及真实用户存档：

```powershell
dotnet build --no-restore
$env:APPDATA = "$PWD/.tmp/wuhan-animation-appdata"
$env:LOCALAPPDATA = "$PWD/.tmp/wuhan-animation-local"
New-Item -ItemType Directory -Force -Path $env:APPDATA,$env:LOCALAPPDATA | Out-Null
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --headless --path . --log-file "$PWD/.tmp/wuhan-selftest.log" res://Scenes/Tests/WuhanSelfTest.tscn
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --headless --path . --log-file "$PWD/.tmp/wuhan-animation-test.log" res://Scenes/Tests/WuhanAnimationSelfTest.tscn
```

制作过程捕获使用实际 OpenGL 渲染，不能加 `--headless`。运行 `Scenes/Tests/WuhanVisualCapture.tscn`，用户参数 `--animations`；另外支持 `--capture-720` 与 `--reduced-motion`。

输出位于 `.tmp/wuhan-animations/{1080|720}-{normal|reduced}/lv{1|2|3}/`。涵盖下面、提篮、抖水、倒面、调味、拌面、出餐、豆皮四刀与备货、蛋酒冲泡/补料、暂停等中间帧。实物点击和拌面通过 Godot Viewport 的输入分发，验证控件遮挡、命中及窗口缩放。

行为自测覆盖原子转移、连点防重、工位并行、双勺自动提篮、手动锁熟、满盘拒绝、焦糊丢弃、交付拒绝与接受、补料、暂停恢复、隐藏重开和减少动态效果。

## 本次验证结果

- C# 构建通过，0 警告、0 错误。
- 原武汉自测 30 项、新增动画交互自测 37 项全部通过。

- 验证由 Godot Mono 实际 OpenGL 渲染及 Viewport 输入分发完成；暂停、失焦和恢复由自动化行为测试覆盖。
- 沙箱启动日志存在系统根证书读取失败提示，未影响本地美术加载、制作交互或捕获完成。日志保存在 `.tmp/wuhan-*-test.log` 和 `.tmp/wuhan-*-capture*.log`。
