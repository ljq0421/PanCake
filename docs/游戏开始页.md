# 游戏开始页：早餐旅行手账与世界地图

## 当前体验（2026-09-17）

启动 Logo → 早餐铺首页 → 新旅程／继续旅程／世界地图 → 城市早餐铺合并页 → 开张。首页另设全局“旅途收藏”入口。手账、升级与合并页共用一致的书页规格。

- Logo 停留 3 秒，可鼠标或 Enter／空格跳过；返回首页不重播。
- 新旅程先看天津手账，最终点击“从天津出发”才创建新档。已有或损坏存档先确认覆盖，默认焦点为取消；失败保留原数据。
- 继续旅程直接打开上次实际开张城市的合并页，展示营业日、章节状态、金币与下一城市目标；不恢复营业中途状态。
- 世界地图沿用天津 → 武汉 → 西安 → 广州 → 扬州的真实解锁条件；海外区域只是探索装饰。浏览城市和升级不更改继续位置，正式开张才更新。
- 从合并页、经营手账或升级页进入地图时，返回按钮恢复来源城市和页面；各城市开张、手账选日和设备购买使用新的共享页面。
- 正式结算首次成功保存章节完成后，关闭账本触发盖章和路线演出，随后展示下一城合并页。可跳过；重复完成、练习和加载旧档不触发。扬州完成后展示五城地图。
- 设置支持常用窗口尺寸、无边框全屏、主音量／音乐／音效和静音。显示切换 15 秒内确认，超时或退出弹窗恢复原设置。音乐通道预留，当前无背景音乐。
- 首页按参考图排列为左上 Logo、中央墙挂地图、底部继续旅程／新的旅程／旅途收藏／世界地图；后两项使用并排小按钮、图标在上文字在下。收藏复用现有早餐贴纸手账封面。地图展示所有已解锁城市，无有效存档时展示天津。
- 首页四个操作按钮的底板使用 NinePatchRect：按高度等比缩放，保留左右端部圆角、边框与高光比例，仅调整中间留白宽度，禁止整图横纵向独立拉伸。图标维持等比显示。
- “旅途收藏”打开全局“早餐旅行手账”，沿用已有五份早餐和入册规则，正式版与 Demo 共用入口。收藏页使用统一书页，不带城市经营／升级书签；返回按钮、底部返回首页和 Esc 均回到首页并聚焦收藏入口。无存档时可浏览待记录早餐，浏览不创建或修改存档。
- 各城市经营手账保留营业日历、成绩与重玩入口，移除原“营业记录／旅途收藏”切换页签。
- 首页右上角为设置、帮助、退出，整体静音在设置内操作；世界地图页沿用原有四个功能入口。按钮保留文字与键盘焦点。

## 实现与兼容

`Scenes/UI/StartScreen.tscn` 保留固定背景、1920×1080 画布、页面及弹窗容器。旅行页内容通过 `StartScreen` 各 partial 文件更新；图片、输入、设置弹窗和页面流程分开维护。

`JourneyModel` 统一五城展示信息；`CityPageModel` 适配手账和升级展示；`GameController` 处理正式开张，继续使用 `SaveService.ContinueCityId`、`TryRecordCityVisit` 与失败回滚。原城市地图的入口现在导向旅行世界地图，五城工作台与经营规则保持原实现。

游戏存档仍为 v3，不新增持久化游戏字段。`PendingJourneyCompletion` 只是一条内存演出消息，成功重置、加载或消费后清空。v1/v2 迁移及已有 v3 的继续位置兼容逻辑保持原样。

`JourneySettings` 作为自动加载服务，将设置保存在 `user://journey_settings.cfg`，与新旅程重置分离。首次不修改窗口模式，音量默认 100%；音效原始播放音量保留。总线为 Master 下的 Effects 和 Music；主静音统一生效。

外层显示时使用 Expand 并等比居中画布，隐藏时恢复原窗口适配。Tab／方向键切换入口，Enter／空格激活；滑块用左右键调整，Esc 返回。弹窗限制背景焦点和点击，关闭后恢复原焦点。

本次只复用 `resource/art/Global/StartPage` 与已有城市资源／食物控件，没有生成、绘制或覆盖源美术。旅行虚线和按钮底板的透明空白通过运行时 AtlasTexture 裁切视区处理，PNG 不变。按钮用 NinePatchRect 保留端部比例，只伸展空白中段。

# 当前沙箱不能读取系统 NuGet 配置，使用项目已有的本地构建配置。

$env:LOCALAPPDATA = "$PWD/.tmp/build-local"
$env:DOTNET_CLI_HOME = "$PWD/.tmp/dotnet-home"
dotnet build --no-restore

# 隔离 Godot 用户目录与设置。
