# 武汉小料库存状态素材

四种小料各有 `满`、`3-4`、`1-2`、`空` 四张 PNG，共 16 张。`3-4` 与 `1-2` 分别表示约 3/4 和 1/2 的可见量。所有图片均为 160×112 像素，使用同一画布中心；`空` 为完全透明的占位图。

素材仅包含食材，不包含碗、勺、桌面、阴影或库存文字。颜色、颗粒和笔触来自当前工作台背景 `resource/art/Wuhan/武汉-热干面-v1.png`，并按原图碗口透视修整。对应的绿底过程图位于 `artifacts/wuhan-supply-assets/source-green/`；透明图由 `tools/GenerateWuhanIngredientStates.ps1` 重新生成。

当前工作台背景已画有满量食材。后续接入状态图时，须先清除各阶段背景中的原食材，再把状态层放到碗内、勺子下方；本组 PNG 不直接覆盖现有满量背景。
