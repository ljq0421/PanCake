# 最关键的 ImageGen 使用规则

## 规则 1：升级素材不要重新生成

煎饼炉：

Lv1 → 以 Lv1 为参考编辑 Lv2 → 以 Lv2 为参考编辑 Lv3。

油条锅：

同样处理。

---

## 规则 2：煎饼覆盖层必须参考同一张底图

29 号煎饼底是唯一锚点。

30～35 全部基于这张图生成。

---

## 规则 3：后续单体素材尽量带上已确认的场景或设备作为风格参考

这样更容易保持：

- 描边；
- 色彩；
- 透视；
- 阴影；
- 世界尺度

一致。

---

## 规则 4：最终尺寸不要交给 ImageGen 决定

ImageGen 只负责：

- 画布；
- 主体占比；
- 相对尺度；
- 透明留白。

最终在 1920×1080 中的尺寸，全部在 Godot 中调整。

---

## 规则 5：不要一次生成大量同类素材再挑

先确认一个标准素材，再以它为参考继续生成。

例如：

煎饼炉 Lv1 确认  
→ 再做 Lv2 / Lv3。

配料盒确认一个  
→ 再做其他盒子。

顾客确认一人  
→ 再做其他顾客。

这会明显减少返工。
