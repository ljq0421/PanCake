# 天津、武汉设备升级开业提示

用户确认范围：仅天津、武汉，正式版与 Demo 同步。

- 购买成功后记录待展示设备；首次正式开业、开场倒计时结束时，按设备依次播放金色光圈、星点、“设备名 Lv.X”和短促上行升级音，每台约 1.35 秒，不阻断操作。
- 天津覆盖煎饼炉、配料台、油条锅；武汉覆盖煮面锅、豆皮锅。复用现有工作台设备坐标，不更改原图或升级数值。
- 同一设备在开业前连续升级只展示最终等级。准备页及独立教学不消费待展示记录；当日未出现的设备保留至可见营业日。
- 播放前原子保存消费结果，退出重进不重复。保存失败回滚记录并沿用营业页错误提示；旧存档不追补历史升级提示。
- 暂停、明细页、失焦或离开营业页停止本轮表现与声音，恢复不补播；音效使用现有音效总线和音量设置。

实现：`SaveService.UpgradeCelebrations.cs` 负责记录消费，`EquipmentUpgradeCelebration.cs` 共用绘制和合成音，两个营业页在 Running 状态接入。

专项：`Scenes/Tests/UpgradeCelebrationSelfTest.tscn`。传入 `-- --output=<可写绝对目录>`；`--capture` 采集实际视口，`--small` 使用 1280×720，`--demo-pilot` 验证 Demo 入口。测试包括购买与重载、连续升级、去重、保存失败回滚、旧存档、教学隔离、暂停/失焦/离页以及顺序播放。
