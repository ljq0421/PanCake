文字统一深暖棕 `#4D352A`、辅助暖棕 `#765648`；程序纸色 `#F5E8CF`、浅分区色 `#EFDDBD`、描边 `#594034`。PNG 纸面保持共用原图，不进行整图颜色相乘。城市色只用于少量页签、按钮交互反馈和弱装饰；西安装饰以浅砂岩为主、枣红用于选中描边及焦点。

`CitySettlementTheme` 集中维护色板。`BookArtCatalog` 按完整资源路径缓存图片，`GetBoard(city)` 和原有 `Get(name)` 共用加载与透明裁边逻辑；Alpha > 0.125 用于测量裁边范围，原图片不修改。共享装饰仍从 Global/BookUI 加载，各章节局部着色材质独立缓存。`book_accent.gdshader` 根据素材用途限定调色区域：

- 天津底板直接使用用户指定母版；武汉、西安改用 v3 重绘，不附加染色材质，节点 Modulate/SelfModulate 保持白色。v1、v2 素材保留。
- 头像只调整内圈；便签只调整贴角及右上小装饰。
- 热销、升级、解锁贴片只调整较明亮的暖色装饰，保护奶油空白和深棕描边。
- 轻分隔线使用章节指定色，整体透明度 28%。

金币、满意度、完成／错误／流失状态章、Perfect 和食物不附加章节材质。系统语义色固定，不随城市变化。奖励章中心符号仍保留为可用资源，未额外添加奖励功能。

## 城市边框重绘

使用内置 imagegen 编辑 `ledger_book.png` 母版，保留双页轮廓、纸面、书脊、深暖棕描边和相对比例，只调整少量边缘及弱装饰。武汉采用青绿 `#71A08D` 与浅豆青 `#A9C1B3`；西安以浅砂岩 `#CBB38B` 为主，少量枣红 `#98594D` 和暖金 `#D0A04E` 点缀。章节色面积遵循正式规范，不覆盖大面积奶油纸面。

按项目约定先生成纯绿背景，再扣除外部背景得到透明 PNG。生成源图和 `*.prompt.txt` 提示词保留于 `resource/art/Global/BookUI/Sources/ledger-v3/`，该目录以 `.gdignore` 排除游戏导入。抠图时区分纯绿背景与武汉低饱和青绿装饰，并检查透明轮廓和书脊细节。最终武汉、西安透明素材保存于 `resource/art/Global/BookUI/`。

生成提示词要点：precise-object-edit；preserve the reference open-book silhouette, page proportions, central spine, brown outlines and cream paper；change only edge colors and restrained ornaments；no text or new UI content；solid #00FF00 exterior for chroma key。分别追加武汉、西安正式辅助色与小面积用色限制。

天津最新确认：账本装饰仅使用暖金色系，取消海河蓝及蓝灰。主辅助色 #D7A45F，浅金 #E7C994，弱暖米金 #F1DFC0。页签、边框、头像内圈和贴角统一按此执行；状态语义色保留。
