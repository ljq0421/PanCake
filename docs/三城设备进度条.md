# 天津、武汉、西安设备进度条

三城复用 `EquipmentProgressView` 与 `EquipmentProgressPresentation`，读取现有状态机计时，不推进制作或改变品质规则。

- 天津：煎饼两面煎制、油条油炸与沥油。
- 武汉：每个面篮独立煮面与沥水、豆皮两阶段加热。
- 西安：白吉馍两面烙制、胡辣汤盛汤。

制作阶段暖黄 `#E8B650`，完成绿色 `#78A65A`，过火风险由橙色 `#E58A3D` 逐渐转红，焦糊或煮烂红色 `#C95343`。底槽米白 `#FFF3DB`，描边深棕 `#654536`。

阶段切换重新填充；完成等待保留满条；自动转移后隐藏；库存满保留等待提示。防焦设备不显示过火风险。空闲、未解锁、清空时隐藏。补货与手工铺馅不计入计时进度。组件忽略鼠标输入，随工作台缩放；暂停时读取的制作时钟保持不变。

验收场景：`res://Scenes/Tests/EquipmentProgressSelfTest.tscn`。使用 Godot .NET，指定可写的 `--log-file`；无界面模式检查状态与绑定，图形模式追加 `-- --capture` 生成 1080p 截图，追加 `--capture-720` 生成 720p 截图。截图输出到 `.tmp/equipment-progress/`。
