# 天津经营手账

天津经营首页的手账入口使用静态摊开双页书本：左页三列五行日期，右页主题图片和历史最佳记录。范围仅限天津手账，沿用现有日期、存档和经济规则。

## 实现与交互

- `Scripts/UI/TianjinLedger.cs` 负责模态遮挡、日期选择、记录显示、键盘焦点和营业请求；`MorningHub.cs` 持有手账并转发既有 `DayRequested(int)`，继续管理重置确认和存档变化通知。
- 每次打开默认选择最高已解锁日（1～15）；打开期间的存档刷新保留正在查看的日期并重新检查可用性。点击日期只预览；右页主按钮再次检查锁定、存档读取错误及确认弹窗状态，通过后才发出营业请求并关闭手账。
- 右页复用天津食物、配料及顾客素材。已有记录显示存档中的最佳收入、满意度和 Perfect 单数；收入支持 `int.MaxValue`。提示重玩只补发超过历史最佳的收入差额，结算逻辑未在手账中重写。
- 无记录显示“等待开店”；锁定显示前一日解锁条件及锁图标；存档读取失败显示恢复说明并禁用营业。印章只表示已有记录，章节星级只在左页汇总，不引入每日星级。
- 全屏遮挡拦截背景鼠标；Tab／Shift+Tab 循环可用按钮，方向键按三列日期网格移动焦点，Enter／Space 使用按钮原生激活输入。Esc／关闭按钮合上手账并恢复原焦点。重置保留不可撤销说明和确认；取消保留进度，确认成功刷新为 Day 1，失败在手账内反馈。
- 以 1920×1080 设计坐标布局，通过现有画布缩放适配 1280×720；图片等比显示。没有翻页动画。

## 素材与维护

运行资源位于 `resource/art/TianJin/Ledger/`：`ledger_book.png`、`ledger_bookmark.png`、`ledger_record_stamp.png`。通过 `TianjinArtCatalog` 稳定 ID 缓存加载并裁透明留白；字体、日期、记录及交互状态保持动态绘制。日期状态使用 `TianjinUi.BrownText`，避免暖棕小字在选中背景上对比不足。

三个素材先用内置 imagegen 生成纯绿背景原图。书签和印章使用 imagegen 去背景；账本工具提取未得到真实 alpha 后，经用户明确同意，使用现有 `tools/prepare_tianjin_stock_ui.ps1` 在 Windows PowerShell 5.1 中处理。绿底原图和完整提示词保存在 `Sources/` 与其中的 `README.md`，该目录由 `.gdignore` 排除运行时导入。可复现的账本处理命令见 [素材来源说明](../resource/art/TianJin/Ledger/Sources/README.md)。

## 复现命令

从包含 `project.godot` 的项目根目录运行，使用 Godot .NET 控制台版本，日志始终写入可写路径。测试场景另用 `.tmp/ledger-tests/` 下独立存档；以下环境目录进一步隔离用户数据。

```powershell
$env:APPDATA = Join-Path (Get-Location) '.tmp/ledger-test-appdata'
$env:LOCALAPPDATA = Join-Path (Get-Location) '.tmp/ledger-test-local'
New-Item -ItemType Directory -Force -Path $env:APPDATA, $env:LOCALAPPDATA | Out-Null
dotnet build ProjectCake.csproj
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --headless --path . --log-file "$env:TEMP/tianjin-ledger-headless.log" res://Scenes/Tests/TianjinLedgerSelfTest.tscn
```

截图需要图形渲染，不加 `--headless`：

