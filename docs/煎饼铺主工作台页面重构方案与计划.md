# 卡通风格早餐工作台首版说明

> 状态：首版已接入，本文记录当前实现边界与验收合同。  
> 更新日期：2026-09-03。  
> 正式场景：`res://scenes/gameplay/cartoon_breakfast_workstation.tscn`。  
> 基准分辨率：1920×1080，同时支持 1280×720。

## 1. 实现结论

主场景现已加载独立的卡通早餐工作台。新场景继承旧工作台，复用顾客、订单、交付、收款、日结与存档业务，但旧场景美术仅作为历史资源保留，不会在新工作台显示。

新工作台的位图素材只能来自 `res://resources/art/cartoon/`。煎饼本体由既有 `PancakeModel` 生成覆盖率、厚度、湿度、熟度和破损字段，再由卡通过程材质着色；完成一圈摊制后，饼皮铺满卡通鏊子的有效内圈。油条余量、盒装果汁和付款反馈继续使用 Godot 绘制。

## 3. 首版玩法边界

### 煎饼

- 点击画面中的工具拿起面糊勺，在空鏊面长按控制倒浆量；松开后自动拿起 T 形摊饼器。
- 拿着摊饼器绕鏊面转满一圈即完成摊制，饼皮随即铺满有效内圈并进入第一面煎制。
- 到翻面阶段点击铲子翻面；小料与酱料点击添加。
- 再次点击铲子后，沿用自动折叠、装袋、交付和收款流程。
- 鸡蛋、薄脆、肉松、香葱、火腿和酱料均为无限供应；香菜完全排除。

### 油条

- 基础炸锅容量固定为 4。
- 空锅长按一次装满四根生坯，点击开始炸制。
- 保留计时、成熟、沥油与焦糊状态机。
- 满锅使用卡通状态图；取走一根后，剩余 3/2/1 根由程序绘制。
- 装入生坯属于生产操作；不存在库存补货操作。

### 饮品

- 饮品区购买后同时开放普通黄豆浆与盒装果汁。
- 豆浆没有糖度选择或设备升级。
- 盒装果汁无限供应，不补货；果汁外观由程序绘制在 `doujiang-2.png`/`shebei-2.png` 的空盘中。

## 4. 经营、成长与订单

- 第一天只开放煎饼区。
- 日结成长只显示“油条区”和“饮品区”，价格均为 200 金币。
- 两区无小料前置，可独立购买，购买次日生效；每天最多挂起一项购买。
- 设备固定基础级，不显示自动化、糖度、鸡排、托盘或其他设备升级。
- 每张订单只有一个商品，只从当前已解锁的煎饼、油条、黄豆浆与盒装果汁中生成。
- 不生成套餐、香菜、鸡排、特殊顾客、特殊订单和每日目标。
- 六张 `customer-*.png` 构成顾客池，按 2×2 图集映射普通、不耐烦、满意/付款和生气/超时状态。
- 同屏最多四位顾客，订单内容以文字显示，避免依赖卡通目录之外的商品图标。

## 5. 存档兼容

存档版本已递增。读取旧版战役存档时，仅早餐章节重置为卡通首版第一天状态；其他章节、全局解锁、口碑与设置继续保留。新存档继续保存营业日、订单、成长购买与日结状态。

## 6. 首版明确不包含

- 设备升级与自动化；
- 糖度辅助；
- 鸡排；
- 香菜；
- 库存与长按补货；
- 套餐；
- 特殊顾客、特殊订单与每日目标。

旧场景、脚本和美术暂不删除，后续功能逐步加入时再按新场景合同扩展。
