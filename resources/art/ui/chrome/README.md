# Stall UI chrome v1

Reusable hand-drawn UI frames for the formal ProjectCake path. `stall_parchment_panel_v1.png` is the paper/account-book panel; `stall_teal_button_v1.png` is the lacquered wooden button/signboard. Both are source-generated without text, chroma-key removed, and consumed as nine-patch `StyleBoxTexture` resources by `stall_handdrawn_ui_v1.tres`.

Patch margins are 66 px for parchment and 58 px for lacquer. Existing order-card, payment, quality, and lock-cover assets are intentionally not replaced.
