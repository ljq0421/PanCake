# 工作台小料长按补货真人验收单

> 引擎：Godot 4.7.1 stable，窗口：1920×1080。  
> 自动化和 GPU 事件回放均不能替代真人手感验收；勾选时记录日期、测试者和发现的问题。

## 正式入口

- [ ] 从主菜单开始新游戏，确认进入正式工作台而不是只进入隔离预览。
- [ ] 首日订单只使用鸡蛋、薄脆和香葱，不出现需要锁定火腿或其他未解锁小料的订单。
- [ ] 完成订单并实际点击收款后，金币余额增加；未收款前不提前入账。

## 同一盘位拖取与长按补货

- [ ] 鸡蛋、薄脆、香葱短拖到鏊子，落点、库存扣减和后续折叠流程保持正常。
- [ ] 在鸡蛋、薄脆或葱花盘位原地按住 0.1 秒后开始持续补货，松开立即停止。
- [ ] 按下后移动超过 10px 进入拖取，不应误触发补货；进入补货后也不应生成拖取预览。
- [ ] 工作台上不存在补料抽屉、抽屉把手或第二套补货热区。
- [ ] 长按过程中每完成一份才增加一份盘内库存、扣除一次单份费用；画面没有环形、条形、盘沿百分比或单份进度文字。
- [ ] 首日鸡蛋、薄脆、香葱每份补货分别约为 0.20、0.225、0.167 秒，连续增加份数的节奏清楚且不过快；锁定火腿不应出现可操作补料源。
- [ ] 在一份尚未完成时松开，再次按住同一盘位可延续上次内部耗时；松开期间盘内份数不提前增加。

## 边界与提示

- [ ] 已解锁空盘仍可直接长按该盘位补货。
- [ ] 库存已满时长按盘位不启动；持续补货到满时会自动停止。
- [ ] 金币不足时长按盘位不启动；持续补货耗尽金币时会自动停止。
- [ ] 其余九个锁定盘位既不能拖取，也不能长按补货。
- [ ] 悬停或失败提示能说明单份价格、耗时、当前容量、已满或金币不足，且位于左上说明条，不遮挡鏊子和料盘。
- [ ] 鸡蛋、薄脆、香葱的盘内份数图能清楚反映库存增加，常态页面没有额外小料名称或补货进度文字。

## 连续操作与主观手感

- [ ] 连续交替执行盘位短拖、原地长按补货、松开续补至少三轮，没有粘滞、误触或鼠标释放丢失。
- [ ] 盘位的按压反馈足够表达“输入已生效”，但不会被误读为补货进度。
- [ ] 鏊子连续鼠标操作、酱料、折叠、顾客、收款和设备成长路径未出现回归。
