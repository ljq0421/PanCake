输出尺寸严格为 **768×1024，透明背景**。

生成一名具有天津港口城市气质的 **码头工作者顾客**。

人物定位是：  
在港口、码头或相关物流岗位工作的城市从业者，清晨来早餐铺买早点。  
重点表现天津港口城市特色、朴实劳动者气质和城市工业生活面貌。

【画风要求】

必须是明显的 **二维休闲经营游戏 NPC**。

整体必须是：

**二维、扁平、圆润、粗描边、大色块、低细节、轻微Q版、强卡通化。**

人物比例要求：

- 头稍大
- 身体略短
- 四肢简化
- 五官简洁
- 工作服轮廓清楚

禁止：

- 半写实工人肖像
- 复杂工装细节
- 安全帽写实结构
- 企业 logo
- 大量工具装备
- 复杂污渍
- 3D 渲染感

【人物设定】

年龄约 **30～50岁**。  
男性，整体朴实、可靠、接地气。  
服装建议为：

- 简洁工作夹克
- 实用型长裤
- 稍带功能性的工作穿着
- 可以有少量高可视度暖色元素，但不要过强

不要手持工具。  
不要大型安全装备。  
重点让玩家感觉是“港口城市劳动者”，而不是施工现场人物。

【姿态与表情】

站立，轻微正面偏 **3/4 视角**。  
默认表情自然、平和、略带忙碌感。  
整体应让玩家感觉：

**这是一个很有天津港口城市生活气息的顾客。**

【尺寸要求】

摆放到 1920×1080 游戏主界面时，实际显示高度约 **220～265像素**。  
主体占 768×1024 画布高度约 **78%～84%**。  
透明背景，主体完整居中。

不要订单气泡。  
不要食物。  
不要文字、数字、Logo、水印。
