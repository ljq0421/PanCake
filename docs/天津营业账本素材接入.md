# 天津营业账本素材接入

2026-09-12。素材已迁移至 `resource/art/Global/BookUI`，天津、武汉、西安共享这套 PNG 与双页布局，广州、扬州继续使用原样式。正式章节配色见[三章节账本配色接入](三章节账本配色接入.md)。营业中和收摊的两个页签均使用营业结算账本底板-v1，统计、收银、暂停、保存和返回规则不变。

## 布局与共享边界

`BusinessDetailsView.ArtSkin.cs` 管理三章节素材皮肤，沿用 1920×1080 设计画布与 1680×900 账本区域；两个页签的同一底板按原比例居中。小结左页展示收入、销售、小费和热销，右页展示经营指标与 Perfect，手记在左下，解锁和升级贴片在右下，关闭按钮对齐底板的操作区。

同次出现多个解锁提示时，小结合并为“新解锁 · 回店查看”，全部原始提示保留在明细末尾；升级提示单独展示。失败时不显示成功贴片，禁用关闭与重试能力仍由传入模型决定，不改变天津原有保存失败后可返回的规则。

明细仍为单一滚动容器、左右配对客单行。新版底板完整留白，已移除旧底板纸面切片与遮盖。轻分隔线按动态行高定位并避开书脊，人物、外框和图标不拉伸。保留一个实际滚动条；长名称、多商品和错误原因继续按内容扩展行高。所有装饰纹理忽略鼠标输入。
