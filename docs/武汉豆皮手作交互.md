# 武汉豆皮手作交互

更新：2026-09-12。切块改为横一刀、竖一刀，竖划同时完成三条竖刀痕。

## 操作

拖浆入空锅并松手 → 点击锅前鸡蛋位 → 等待定型 → 上划并松手翻面 → 从馅碗拖馅进锅、继续按住铺开 → 等待成熟 → 横划一刀、竖划一刀（同时切三条） → 自动入盘 → 从备餐盘拖给顾客。

- 浆碗、鸡蛋、馅碗有独立入口，锅面不能替代原料。拿错、投错不毁锅，锅外放浆不推进状态。
- 馅料首次进入可加馅的锅面即投入，容器留在桌上；鼠标经过的区域显示馅层，不通过累计移动距离假装铺满。投入后不允许再加第二份。
- 松手、Esc、失焦、暂停或隐藏页面均结束当前输入，保留铺馅进度和已完成刀线；重新按住锅面继续。未完成的一刀取消预览，需重新划。
- 铺馅达到 85% 自动补齐边缘，才进入第二段煎制。铺馅无额外烧焦倒计时，也不评价厚薄。
- 切块顺序不限，正反向均可。每次按住最多完成一个方向；任意竖刀线划过一次即完成三条竖刀痕，重复方向不计数；短划、斜划或偏离刀线不扣品质。
- 第一条有效刀线完成后收火、停止热气并显示“已收火”，锁定当前品质。未成熟不能提前切，偏焦不恢复，焦糊只能右键长按拖入垃圾桶。
- 满盘时余量留锅，腾位后自动补入，余量清空前不能开新锅。盘中不同锅次逐块保留品质。

Lv1/Lv2 不间断制作一锅为 6 次按下；Lv3 为 5 次。每锅 8 块，备餐盘 16 块。Lv2 恒温、Lv3 自动翻面和现有加速不变；交付、耐心恢复、满意度与点击收钱沿用共享规则。

## 实现与调节入口

- `Scripts/Wuhan/DoupiInteraction.cs`：32×16 覆盖网格，85% 完成阈值，笔刷半径为锅面短边 22%；刀线吸附带半宽为垂直方向尺寸 18%，长度覆盖率 70%；上划 40 设计像素、侧移小于 150 设计像素。
- `DoupiStateMachine`：新增 `Spreading`；`Spread(from, to, aspect)` 按有效锅面内线段覆盖更新格子。`TryCut(DoupiCutLine)` 记录四条物理刀痕；一次竖划同时记录 Left、Center、Right，横划记录 Horizontal，保留自动转盘与品质规则。
- 工作台输入：取消 `DoupiPressed/DoupiAction`。使用独立倒浆、加蛋、投馅、铺馅、翻面、清理请求；控制层统一检查状态、动画锁与营业条件。
- 坐标：所有覆盖和刀线判断都使用现有锅面四边形的双线性逆映射。铺馅覆盖层按网格绘制，顶点透明度平滑边界；切割预览、刀痕和命中使用相同坐标。
- 手势：一次按住不重新解释成其他动作；仅取馅可衔接铺馅。两刀完成后的剩余移动不能成为交付。
- 表现：独立鸡蛋位复用已有鸡蛋和托盘素材；新增浆勺用于拖影和倒浆动画。翻面前缘跟手抬起，短划回落；成功接续当前姿态。切刀完成后在鼠标位置抬起，不重播三次纵切。

未增加存档字段、原料库存、自由几何切割、简化点击模式或直接触屏输入。

主动操作耗时尚未获得真人前后对照数据；自动注入鼠标事件的执行耗时不能代表玩家速度。每锅新增约 1.5～2.5 秒仍是待试玩验证的目标，非已实现的测量结论。

试玩建议固定同一组订单、锅具等级和初始库存，各完成五锅：记录从按下到松开的主动操作总时长（排除两段等待）、无效取料次数、铺馅重拿次数、无效刀数和完成订单数。先确认铺馅、四刀能随时中断续做，再评估是否挤占热干面操作；需要调整时仅改集中参数，不自行修改产量、火候或通用经营机制。
