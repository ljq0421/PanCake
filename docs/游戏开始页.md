# 游戏开始页：去各地开早餐铺

## 已实现的体验

启动先展示全局标题页。封面代表持续前往各地开店的旅程，与城市数量、城市解锁状态和具体地标无关。左侧为游戏名、主题句与三个固定位置的按钮，右侧为清晨早餐铺、旅行箱、合起的手账以及延伸到远方的街道。

- **开始游戏**：无存档时创建新档；已有或损坏存档时先确认覆盖，说明会清空所有城市进度、金币和设备升级，默认焦点为取消。保存成功后进入天津经营首页。
- **继续游戏**：有效存档时作为主按钮并默认获得焦点，进入上次城市的经营首页；不会恢复营业中途状态。没有存档时保留按钮并标注“暂无存档”。
- **退出游戏**：退出应用，不触发保存。
- 保存失败保留原有磁盘和内存状态，标题页提供中文恢复说明，底层异常保留在日志中。损坏存档沿用现有备份逻辑，未确认时禁止覆盖。

Tab、方向键在有效按钮间循环；Enter／Space 激活。确认弹窗拦截背景点击并限制键盘焦点，Esc 取消并恢复开始按钮焦点。页面淡入 250ms，按钮按下／释放缩放反馈 120ms，背景静态。

## 实现位置

- `Scenes/UI/StartScreen.tscn`：固定节点与 1920×1080 布局；`Scripts/UI/StartScreen.cs`：状态、输入、弹窗与等比缩放。
- `Scripts/UI/StartScreenTheme.cs`：独立的全局配色和控件样式，不直接依赖天津城市皮肤。
- `Scenes/Main/Main.tscn`、`Scripts/Core/GameController.cs`：启动显示标题页，统一隐藏其他页面，处理新游戏、继续与城市导航。`OpenCity` 在正式导航时记录城市，保存失败时停留原页面。
- `resource/art/Global/start-journey.png`：内置 image_gen 生成的完整不透明背景；提示词见同目录 `start-journey.prompt.md`，并嵌入 PNG 元数据。所有文字、按钮和弹窗均由程序绘制。

标题页显示时临时采用 Expand 视口适配，再将设计画布等比缩放居中、以深色留边填充剩余空间；隐藏或释放标题页时恢复窗口原有适配方式。没有修改城市页面的全局项目显示设置。

## 存档接口与兼容

`SaveData.LastVisitedCityId` 是 v3 存档的新增可选字段，默认天津。旧 v3 存档无该字段仍可读取，v1/v2 继续使用原有迁移流程。无效或未解锁的城市回退天津。

`SaveService` 增加 `HasSavedGame`、`CanContinue`、`RequiresNewGameConfirmation`、`ContinueCityId` 和 `TryRecordCityVisit`。零金币、尚未营业但已成功写盘的新档也可以继续；不能通过关卡或金币数值推断存档存在。未解锁城市的开发预览不改变继续位置。重置失败恢复数据及读取错误、备份路径、迁移和存档存在标志；城市记录失败恢复原城市。

新城市加入时需接入原有城市数据／导航注册，并扩展存档的有效城市识别；标题页画面和菜单不需要追加城市元素。

### 复现

在项目根目录运行：

```powershell
dotnet build --no-restore
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --headless --path . --log-file "$env:TEMP/start-screen-test.log" res://Scenes/Tests/StartScreenSelfTest.tscn
```

截图运行时去掉 `--headless`，在命令末尾增加 `-- --capture`；720p 使用 `-- --capture --small`，宽屏留边使用 `-- --capture --wide`。每次测试使用新的隔离存档目录。
