# F3 成品饮品与油条人工验收

工程自动检查入口：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\run_f3_checks.ps1`

## 成品饮品柜

1. 选择一个要求常温纯牛奶的订单项，点击“纯牛奶”；确认库存立即减少 1、订单项出现完成标记，加热位保持为空。
2. 选择一个要求加热纯牛奶的订单项，点击“纯牛奶”；确认此时不扣库存、不交付，并显示“点击空加热位”的提示。
3. 点击空加热位；确认库存减少 1，位置显示“加热中”。
4. 加热完成后点击该位置；确认商品进入匹配订单项。
5. 用常温订单项尝试领取热饮；确认拒绝，热饮仍留在加热位。
6. 等热饮冷却后点击该位置；确认只能报废，不能交付。
7. 分别检查基础、中级、高级：开放位数为 1/2/4，加热时间为 2/1/1 秒，高级热饮持续保温。

## 油条炸锅

1. 选择原味油条，设定数量，依次点击“装入”“开始炸制”；确认面胚库存按数量一次扣除。
2. 熟成前点击“升篮”；确认被拒绝且批次仍在炸锅。
3. 熟成后观察安全期和过火提示；延迟升篮时确认品质从 100 逐步下降，最终整批焦糊只能报废。
4. 在可升篮状态点击“升篮”，等待离油完成后点击“取出交付”；确认每次只交付 1 份，剩余份数继续占用炸锅。
5. 分别检查基础、中级、高级：容量为 2/2/4，炸制时间为 12/9/9 秒。
6. 检查温控辅助、自动升篮与自动装料成长项只在各自门槛满足后生效。

## 并行与结算

1. 同时启动饮品加热和油条炸制；确认两台设备独立计时、互不暂停。
2. 完成含热饮与油条的套餐订单；确认两个订单项各自匹配，提交后金币、声誉和两个区域熟练度各结算一次。
3. 退出并继续游戏；确认设备状态、库存、订单与升级档位恢复一致。
