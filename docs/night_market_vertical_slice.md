## 1. 章节定位

第三章是晚间经营的「灯火串铺」，同时经营炭火烤串与炸串。它延续前两章“亲手操作留下可见结果”的主线，但不复用摊饼或削面的手感：

- 第一章早餐煎饼：单件连续制作、配料装配与多设备早餐调度。
- 第二章午餐刀削面：连续刀工、分批入锅、熟度与沥水判断。
- 第三章夜宵串铺：两条火线并行、双面翻烤、油温批次与共享装盘。

本章的记忆点不是“菜单更多”，而是玩家必须在同一张案台上照看两种完全不同的热加工：左侧烤炉需要频繁回看每串正反面，右侧炸锅需要在正确油温下整批起落，中间装盘台把两条线汇成一个订单。

## 2. 成功标准

垂直切片完成时必须满足：

1. 主菜单显示第三章、解锁进度、独立金币和营业日。
2. 完成第二章四项成长并使其在次日生效后，第三章永久解锁。
3. 第三章具有独立存档状态、金币、营业日、订单、生产与成长；只共享全局口碑。
4. 首次进入可以完成一份不限时的“羊肉串＋炸藕片”教学拼盘并收款。
5. 玩家可在一个屏幕中完成放串、翻面、取串、下炸篮、提篮、沥油、装盘、调味、递交、评分和收款。
6. 1920×1080 与 1280×720 下不裁掉核心设备或关键按钮。
7. 自动逻辑检查、真实 GPU 输入检查与真人手感/视觉验收分别记录，互不替代。

## 4. 营业循环

### 4.1 首次教学

第一单固定为“新手双拼”：

- 一串孜然羊肉串；
- 一串椒盐炸藕片；
- 不限顾客耐心，不计营业倒计时，不可谢绝；
- 无论评分固定支付 18 金币；
- 收款后才启动首日剩余 60 秒正式营业。

教学提示按唯一下一步推进：

1. 将羊肉串放入中火位；
2. 将藕片串放入炸篮；
3. 放下炸篮；
4. 当羊肉一面达到金黄区时翻面；
5. 两面达标后取串装盘；
6. 炸串达标后提篮并沥油；
7. 将炸串装盘；
8. 分别撒孜然与椒盐；
9. 递交拼盘并收款。

### 4.2 正式营业

- 首日教学后：60 秒。
- 后续营业日：120 秒。
- 普通顾客拥有独立耐心倒计时。
- 未开始制作时谢绝订单：全局口碑 -1。
- 已有生产时谢绝订单：全局口碑 -2，并清空当前生产。
- 顾客耐心耗尽：全局口碑 -2，并清空当前订单与生产。
- 日结时自动收取已经生成但未点击的付款，未递交的食物作废。

## 6. 左翼：炭火烤串

### 6.1 设备结构

长条烤炉具有三段火区，每段两个可用烤位，共六位：

- 小火区：升温慢，适合等待与保温。
- 中火区：羊肉串主目标区。
- 旺火区：上色快，鸡肉串可以短时使用，但更容易焦。

垂直切片允许玩家直接选择目标火区放串。后续完整版可把“放串”替换为实际拖拽，但稳定数据合同保持为火区与槽位，不把命中位置烘焙进配方。

### 6.2 双面熟度

每串独立保存：

- 正面热量；
- 背面热量；
- 当前朝向；
- 所在火区；
- 累计制作时间；
- 是否已装盘；
- 已添加调味。

只有朝向炭火的一面继续升温。点击烤串执行翻面，视觉上切换把手朝向与当前面标记。正反面差异必须影响评分；只等总时间而不翻面的串不能获得高分。

### 6.3 火候阶段

| 单面热量 | 视觉/状态 |
| ---: | --- |
| 0–24 | 生 |
| 25–44 | 转色 |
| 45–68 | 金黄嫩熟目标区 |
| 69–82 | 焦香，可递交但扣分 |
| 83+ | 烧焦，不可恢复 |

火区基础速率为小火 4、中火 7、旺火 11 热量/秒。余火挡板成长把每种烤串的高分窗口上限扩大 8 热量，但不降低生熟门槛。

### 6.4 取串与返工

- 任一面不足 25 时仍允许继续烤。
- 已装盘但未调味的烤串允许回炉一次；回炉后最高熟度分限制为 90。
- 任一面达到 83 后不可恢复，只能低分递交或废弃整盘。
- 调味后不可回炉。

## 7. 右翼：炸串

### 7.1 设备结构

双篮炸锅在垂直切片中启用一个主篮，第二篮作为后续扩展的实体预留。主篮可一次放入最多两串同类食材；混合炸制不是本切片目标。

### 7.2 油温与批次

玩家选择低温 / 标准 / 高温火力，目标温度分别为 160 / 178 / 195℃。实际油温平滑趋近目标，不瞬间跳变。

每个炸制批次保存：

- 食材类型与数量；
- 炸篮是否入油；
- 累计炸制时间；
- 炸制期间平均油温偏差；
- 提篮后的沥油时间；
- 是否已经装盘；
- 已添加调味。

油温低于 160℃时熟度增长慢并积累“吸油”惩罚；高于 190℃时上色过快并积累“外焦”惩罚。恒温炸锅成长降低油温追随延迟，并把配方目标温区上下各扩大 5℃。

### 7.3 起锅与沥油

- 炸篮入油后持续计时；提篮停止熟度增长并开始沥油计时。
- 提早起锅可以重新入油一次，最终熟度分上限为 90。
- 沥油不足时成品油亮、扣除沥油分；沥油过久时温度下降、制作时间扣分。
- 装盘后不可重新入油。

## 8. 中轴：装盘、调味与递交

中央装盘台是两条产线的共享出口：

- 当前托盘最多容纳两串；
- 取下烤串或沥好炸串后进入托盘；
- 调味作用于最近一串尚未调味的成品；
- 孜然、辣椒面、椒盐、甘梅粉互相区分；错误调味不阻止递交，但配方分显著下降；
- 只要托盘非空即可递交，订单不完整或多放食物会进入评分，不使用硬性阻断；
- 收款后才清空托盘并迎接下一位顾客。

## 13. 音效与反馈

- 放串：短促木签落架声。
- 翻面：金属架与木签轻碰声。
- 烤制：低音量持续炭火噼啪，旺火区略增强。
- 下篮/提篮：金属篮碰锅沿声。
- 炸制：入油瞬间增强、提篮后快速衰减。
- 调味：粉料轻撒声；错误调味不播放失败蜂鸣，只显示清楚文本。
- 递交、收款、耐心告警沿用前两章听感层级，但不复用削面刀声。

垂直切片可先使用项目原创确定性厨房音效或无外部版权占位声；正式音频生产另行记录来源。

## 15. 真人验收门槛

自动 PASS 不代表下列项目已经通过：

- 连续制作至少 15 份双拼后，左右往返是否疲劳；
- 烤串翻面节奏是否可以凭视觉判断，而不是盯数字；
- 炸篮提起与沥油是否有明确的物理反馈；
- 同时照看烤炉和炸锅时是否忙而不乱；
