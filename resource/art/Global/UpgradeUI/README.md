## v1 历史制作记录

四张素材使用内置 image_gen 绘制，以用户提供的店铺升级参考图为视觉来源。已执行绿底生成、抠图去绿边、尺寸归一化、成对 alpha 轮廓对齐。无文字、无设备图标；中间纸面为不透明底色，轮廓外透明。

以 2 倍图方式使用：卡片基础显示尺寸 565×167，面板基础显示尺寸 280×180。效果面板顶部 80 像素作为固定标题带，扩高只拉伸中央正文区；底板可使用 NinePatchRect 或 StyleBoxTexture。若整体缩放 0.5，显示边距相应为一半。

同类两态逐像素 alpha 一致，切换时轮廓不跳动。暖色边缘经过除绿处理，保留半透明抗锯齿。原始生成图与提示词、加工记录、校验结果位于 `output/imagegen/shop-upgrade-v1/`。

已接入 `Scripts/UI/EquipmentUpgradeView.cs`，天津、武汉、西安、广州、扬州升级书页及结算升级弹窗共用。设备卡片随选择切换普通／选中底板；效果面板使用九宫格，标题带固定，正文随内容增高并在详情区滚动。
