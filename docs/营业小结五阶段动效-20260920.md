# 天津、武汉营业小结精简布局与动效

## 已确认范围

天津、武汉收摊小结使用同一套 Godot Tween 编排，正式版和试玩版共用。其他三城保留原小结，营业中打开账本直接显示完整统计。原有翻书衔接与“顾客明细”翻页继续保留。

2026-09-21 确认精简内容：左页仅保留今日接待、顾客满意度与营业手记；右页仅保留今日收入（含菜品销售、顾客小费与挑战奖金明细）、挑战结果、店铺升级按钮和开始下一天按钮。亮点、评级、Perfect 印章、解锁贴片和“下一步期待”均不在天津、武汉小结展示。

## 时间与表现

现有翻书入场为 0.52 秒；以下时间从翻书结束开始计算。接待在 0.15 秒淡入，满意度在 0.40 秒淡入，挑战结果在 0.65 秒淡入；收入随后在 0.86 秒入场，由 0 用 0.80 秒累计至本次总入账，入场缩放从 0.84 恢复至 1.00。2026-09-22 调整：计数结束后，最终金额用 0.20 秒放大至 1.18，停留 0.12 秒，再用 0.28 秒柔和回落至 1.00，突出“今日收入”；营业手记延后至 2.26 秒从下方 8 个布局像素归位，避免抢占金额强调时刻。收入底板使用更亮的城市主色强调。底板、区域标题、翻页和两个操作按钮始终可见可用。

收入总额为营业收入加本次已领取的挑战奖金，明细保留菜品销售、顾客小费和挑战奖金三项；未达成或没有挑战时奖金为 ¥0。它不改变营业收入、挑战保存或历史营业额记录的口径。不再播放盖章、落币或 Ready 提示音。无数据入账或存档格式变化。

## 中断与可访问性

- 动画期间点击空白或按空格立即补齐结果，不关闭账本；吞掉该次空格的按下、重复及释放，避免激活聚焦按钮。
- 翻页、查看设备、收好账本及重试保存按原规则立即执行，保存失败与教学限制仍生效。
- 返回小结不重新计数；隐藏、重新打开和退出节点清理 Tween、临时金币及位移。
- 减少动态效果模式直接显示完整结果。

## 验证入口

先执行 `dotnet build --no-restore`，再使用 `D:\Godot\GodotSharp\Godot_v4.7.1-stable_mono_win64_console.exe` 运行 `res://Scenes/Tests/BusinessBookSelfTest.tscn`，日志使用绝对可写路径。

- 无用户参数：现有五城账本回归，包括翻页、升级和保存失败恢复。
- `-- --motion-only`：真实 Tween 分步推进，验证五阶段、累计、无小费、零收入、大金额、无 Perfect、跳过、翻页、设备入口、隐藏和重开。
- 非 headless 加 `-- --motion-only --capture --capture-dir=res://.tmp/book-motion-captures`：两城、1920×1080／1280×720／1600×720 的阶段截图和按真实帧时钟完整播放，并检查最终统计文字实际像素。

动效实现集中在 `BusinessDetailsView.TravelMotion.cs`，布局登记参与动画的内容节点，位置遵循上述左右页布局；动画结束或跳过时恢复各节点的布局位置。
