# 天津煎饼翻面动画

2026-09-17，按用户确认实现：铲子托起、饼小幅腾空翻转后落回，约 0.35 秒；落回后才能继续抹酱、加料。

- 点击翻面和 F 键共用成功操作入口。无效或重复输入不启动动画，不重复消耗原料。
- 饼与铲子读取同一进度，包含接近、腾空、侧面压缩、落回收稳；复用现有饼和鸡蛋素材。升起约 44 个设计像素，炉面保留轻阴影。
- 同日追加用户确认的明显软饼弧度：铲子先挑起右侧，腾空时中部下垂，落回时中部先落、边缘随后贴平。轮廓、饼皮与鸡蛋纹理共用同一曲线；用 40 条连续纹理带绘制，不新增场景节点，仍为 0.35 秒。
- 动画中锁定当前煎饼制作及拿起丢弃，油锅、豆浆和库存补货维持现有交互。第二面熟制沿用原计时，不增加制作状态或存档字段。
- 暂停、明细、失焦、隐藏、重置会立即收稳，恢复不补播；减弱动态直接完成翻面，运行中切换也会解除动画锁。
- 仅天津启用翻面动画，其他共享工作台不启动此效果。

## 复现

从项目根目录运行；使用独立 APPDATA，避免读写真正玩家存档：

```powershell
$env:APPDATA = Join-Path (Get-Location) 'artifacts/tianjin-flip-20260917/profile-flip'
dotnet build --no-restore
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --headless --path . --log-file (Join-Path (Get-Location) 'artifacts/tianjin-flip-20260917/flip.log') res://Scenes/Tests/TianjinFlipSelfTest.tscn
```

实际视口去掉 `--headless`，结尾添加 `-- --capture`；窗口放在屏幕外，输出连续帧到同一 artifacts 目录。旧测试使用项目 `.tmp`，沙箱拒绝写入时需要以允许访问该目录的测试权限运行。
