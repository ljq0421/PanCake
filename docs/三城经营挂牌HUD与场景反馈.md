# 三城经营挂牌 HUD 与场景反馈

2026-09-14，根据《优化顶部HUD design》落实，仅涉及天津、武汉、西安。广州、扬州未接入。

- 三城复用 `BusinessHud`：左侧营业日签、中央订单进度及计时器、右侧收入牌及暂停铜扣，牌之间露出场景。订单分母仍是每日计划顾客数，同屏上限仍为 5 人。
- 使用 `resource/art/Global/HUDUI` 对应城市素材。底板只延展空白段，挂绳、边饰与中央章保持比例；图标等比显示，导入启用 mipmaps。营业日、计时状态和收入含义可悬停查看。
- 时间显示 `mm:ss`，开门和收尾阶段使用各自倒计时。高峰徽记沿用现有章节标题含义，武汉最终挑战也显示徽记，不新增高峰玩法。
- 暂停固定在右上。天津、西安复用已有暂停页；武汉新增“继续营业／放弃本日”暂停页，保留原放弃确认。Esc 和按钮可暂停，恢复不会清除失焦或账本造成的独立暂停。
- 天津、武汉仍自动入账并飞币进入场景挂件；西安原点击收钱控件覆盖到收入牌的金币图标，数字只显示收入。西安账本入口以左侧小账页图标保留。
- 顶部旧操作提示隐藏。`BusinessSceneFeedback` 在订单附近显示部分交付小勾、完成／Perfect 星章及失败叉；天津、武汉翻面提示显示在锅具附近。错误原因、补货和必要教学文字保留在操作附近。短暂反馈不拦截鼠标，最多同时 4 条，暂停、失焦或离开界面时清理，减弱动态效果设置关闭弹出缩放。
- 飞币复用提供的“小费飞行金币”素材，不改变收入、小费、耐心、声音或存档计算。候场人数不再占用常驻顶部区域。

## 天津反馈减量（2026-09-14）

天津成功投入食材（面糊、鸡蛋、酱料、配料）和翻面不再弹出小勾或翻面箭头。食材及煎饼自身变化、原音效、失败原因和顾客交付反馈保留。武汉、西安不变。

## 验证

- `dotnet build --no-restore`。
- `Scenes/Tests/BusinessHudSelfTest.tscn`：三城 × 1920×1080／1280×720，实际点击暂停及西安金币；订单反馈尺寸、鼠标穿透、暂停清理、恢复时间、独立暂停原因。加 `-- --capture` 输出 `.tmp/hud-review/` 运行、暂停、反馈截图。
- 相关现有回归：`CoinCollectionSelfTest`（天津、武汉挂件与飞币），`XianSelfTest`（西安经营逻辑）。`XianVisualCapture` 的顶部点击坐标同步到新 HUD。
- 使用 Godot Mono 控制台，`--log-file` 指向工作区内绝对路径，测试使用独立存档。
