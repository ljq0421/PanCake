## 01｜广州章节美术风格锚点图

```text
生成一张休闲模拟经营电脑游戏《早餐铺子》广州章节的美术风格锚点图，用于统一后续所有游戏素材的画风、透视、配色和世界尺度。

画布尺寸严格为 1920×1080，16:9 横向构图。

画面必须是明显的二维卡通休闲游戏美术，必须明显区别于真实照片、半写实插画、写实游戏美术和 3D 渲染。

整体呈现必须为：
二维、扁平、圆润、粗描边、大色块、低细节、玩具化、图标化、强卡通化、温馨、轻松、干净、清晨感。

禁止：
真实材质、真实木纹、真实金属反光、真实玻璃反射、真实皮肤细节、复杂衣料褶皱、复杂阴影、摄影景深、电影光照、写实食物质感、半写实体积塑造。

所有物体都要做明显几何简化：
轮廓清晰、结构简化、颜色层级少、易识别、适合游戏中小尺寸阅读。

透视统一为：
轻微俯视的 3/4 卡通视角。

广州章节专属视觉关键词：
岭南玉绿色、奶油白、暖木棕、少量朱红点缀、骑楼、满洲窗、竹蒸笼、白瓷茶具、柔和蒸汽、清晨早茶铺氛围。

注意：
不要把广州塔做成主体，不要把真实城市地标堆满画面。
如果需要体现广州气质，应优先通过骑楼、满洲窗、竹蒸笼、茶具、花砖、岭南配色和蒸汽氛围来表达。

画面内容不是正式游戏界面，而是一张“广州章节美术风格展示锚点图”：
画面中集中展示广州早餐铺的核心视觉元素，包括：
双屉肠粉炉、竹蒸笼点心蒸柜、白色肠粉蒸盘、卷起的肠粉成品、虾仁肠粉、猪肉肠粉、鸡蛋肠粉、烧卖、虾饺、白瓷茶壶、茶杯、米浆桶、鸡蛋盒、猪肉配料盒、虾仁配料盒。

环境氛围体现广州清晨早茶铺风格：
有简化的岭南骑楼元素、满洲窗、少量花砖、竹蒸笼、柔和白色蒸汽、奶白色墙面和玉绿色点缀。
可在远处极小范围点到为止地体现广州城市感，但绝对不要让广州塔成为主体。

画面重点要体现：
1. 广州章节的主操作是“肠粉”
2. 广州章节的辅助系统是“蒸笼点心”
3. 广州章节的快速商品是“茶”
4. 整体气质是“蒸汽早茶篇”
5. 画风必须明显是二维卡通休闲模拟经营游戏，而不是插画海报或写实场景

所有元素必须保持清晰、可爱、简化、统一比例，适合作为后续所有广州素材的风格基准图。
```

桌面表现要求：
桌面边缘延伸到画面底部，可以表现桌面厚度，但不要表现桌子的垂直正面大面积区域。

整体视觉重点：
这一定是一家“广州早茶风格的肠粉早餐铺”，并且与天津、武汉、西安画风一致，但城市气质明显不同。
