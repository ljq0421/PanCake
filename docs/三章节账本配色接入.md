# 天津、武汉、西安共用账本素材与配色

2026-09-12。按照《营业结算页的正式配色生产规范》，将账本美术统一读取 `resource/art/Global/BookUI/`。天津、武汉、西安的营业中查看与收摊结算均使用这套素材和双页布局；广州、扬州维持原皮肤。旧天津 BookUI 路径不再被运行代码引用。

## 布局与资产

“今日小结”和“顾客明细”均使用 `营业结算账本底板-v1.png`，保留 1920×1080 设计画布、1680×900 账本区域、等比居中与 40% 背景暗化。三章共用纸面、收入和小费图标、经营指标、状态章、Perfect、头像圆框、热销标签和提示贴片。

小结左侧为收入、构成、热销及手记，右侧为完成／流失、完成率、完成顾客满意度、Perfect、评级及条件贴片。明细以一个滚动容器维持左右配对，保留全部／完成／错误／流失筛选及动态行高。武汉使用实际热干面等商品图，西安使用实际肉夹馍等商品图，缺图继续使用命名程序图标，不染色或借用其他城市菜品。

文字统一深暖棕 `#4D352A`、辅助暖棕 `#765648`；程序纸色 `#F5E8CF`、浅分区色 `#EFDDBD`、描边 `#594034`。PNG 纸面保持共用原图，不进行整图颜色相乘。城市色只用于少量页签、按钮交互反馈和弱装饰；西安装饰以浅砂岩为主、枣红用于选中描边及焦点。

`CitySettlementTheme` 集中维护色板。`BookArtCatalog` 缓存 Global 素材及各章节的局部着色材质，Alpha > 0.125 用于测量裁边范围，原图片不修改。`book_accent.gdshader` 根据素材用途限定调色区域：

- 底板仅调整小角饰，保护纸面和棕色书皮。
- 头像只调整内圈；便签只调整贴角及右上小装饰。
- 热销、升级、解锁贴片只调整较明亮的暖色装饰，保护奶油空白和深棕描边。
- 轻分隔线使用章节指定色，整体透明度 28%。

金币、满意度、完成／错误／流失状态章、Perfect 和食物不附加章节材质。系统语义色固定，不随城市变化。奖励章中心符号仍保留为可用资源，未额外添加奖励功能。
