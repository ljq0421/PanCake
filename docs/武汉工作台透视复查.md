# 武汉工作台透视复查

2026-09-09。用户反馈新版托盘角度仍不正确，明确要求以桌面为主基准，检查托盘、工具和设备。

结论：上一轮尺寸、边界及交互修复有效，但“透视已统一”的判断不成立。本轮不改游戏素材或布局，只作基于实际渲染的审查。

## 检查结果

| 对象 | 结论 |
| --- | --- |
| 生面、葱花、牛肉托盘 | 优先修正。素材在自身中心左右对称收拢，放到桌面左侧或中央后没有继承相应位置的桌面深度方向；前壁偏高使浅盘读起来像深盒。 |
| 蛋酒、豆皮托盘 | 优先修正。位于桌面右侧仍正对镜头；豆皮盘前壁厚重。需连同杯底、食物底面与盘底关系检查。 |
| 金币盘 | 已在桌内，但移动位置并没有改变原图的独立透视，横长比例也不能证明相机角度正确。 |
| 三档豆皮锅 | 锅面也在自身中心对称收拢，不能直接用作绝对参考。锅体、锅面、状态食物和切线须作为整组校准。 |
| 煮面锅和漏勺 | 圆形轮廓让偏差不如方盘明显，但仍不能认定正确。锅口、水面与漏勺口共同检查；抬起后的工具姿态允许不同于桌面。 |
| 面碗、调味壶、浆碗、馅碗 | 面碗相对自然，可以暂留待校准；开口大小受位置、高度和器皿形状影响，不能把不同开口的椭圆扁率直接强制统一。前排低矮器皿看见更多内部在方向上合理。 |
| 筷子和铲刀 | 斜放不等于错误。桌面内旋转和动作中离开桌面均合理，应检查厚度、缩短、同组平行边及握持／接触关系。 |

桌沿平行摆放的方盘和方锅应共享桌面的深度收拢方向；在桌面内旋转的工具可以有其他消失方向。不能对所有道具套一个旋转角，也不能把物体的整体高宽比当作俯视角。

## 后续修复顺序

1. 用当前空桌建立一张统一的简化透视参照；保留手绘风格，不凭单张背景杜撰精确35°等相机参数。
2. 在桌面左、中、右实际摆放位置校准同一种浅盘，先审整桌合成，确认侧壁、盘底、收拢方向和接触关系。
3. 按各位置制作托盘，再整组校准必要的设备和食物层；保持已确认的体量，不以拉伸单张图片修补角度。
4. 原有布局／交互测试继续作为功能回归；透视是否自然必须独立验收，577项几何检查不能证明视觉透视正确。

本轮仅覆盖视角、遮挡及相应识别风险，不构成完整的可访问性或手势操作审计。没有修改游戏资源、相机或布局。
