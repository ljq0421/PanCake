# 天津拖动折叠

2026-09-22，按用户要求先将天津折叠改成直接拖动饼皮；随后根据“像硬纸板”的反馈，改为连续柔性卷折。

- 抹酱完成后，从饼皮左、右侧按住左键向对侧拖动，达到约饼宽 42% 的有效位移后松手折叠。支持拖回、短拖回落；只点击不折叠，不按速度或精确轨迹判断。
- 以实际饼面椭圆判定起点，接受侧边较宽的区域；松手远离饼面则取消。Esc 或按下右键取消；暂停、明细、失焦、隐藏、换饼和重置清除手势。
- 天津隐藏原折叠按钮，保留 F 快捷键。按住折叠时不会重复提交、加料或拿起丢弃。成功仍走原 Fold 指令，保留配料、品质、酱量、教学记录与装袋衔接。其他城市不启用新手势。
- 教学文字改为从左侧或右侧饼边拖动，聚焦饼炉；取消不记为学会，成功只记录一次原有 fold 教学项。
- 折叠通过弯曲切线积分保持饼皮长度，外缘先卷，抓取处领先，两端滞后，中段下垂；随各段朝向展示涂料面或饼皮背面。网格使用明确的三角形索引，避免卷曲、侧立时多边形自动剖分失败。
- 复用当前饼皮、鸡蛋、酱料和配料素材，合成到局部透明预览纹理。松手完成后有约 0.22 秒的贴合收尾，短拖约 0.18 秒回落；减弱动态或极快松手直接落定，装袋不等待视觉尾段。
