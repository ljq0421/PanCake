# 营业账本直接升级设备

五城正常营业成功结算后，可点击店铺升级入口打开共享设备升级弹窗。左侧列出本城全部设备（扬州两项，其余三项），右侧展示选中设备的当前与升级后效果。无可购买项时入口仍保留；未开放、金币不足、满级与武汉固定备料台均可查看。练习、营业中与结算保存失败不开放入口。

弹窗展示钱包余额、设备等级变化、配置对应的效果、价格和唯一的“升级设备”按钮。点击设备卡片只切换详情；点击购买后保存设备与扣款，下次营业生效。刷新余额、列表与贴片并保留所选设备，不重复结算营业收入。不可购买时禁用购买按钮并说明原因；满级与固定设备不显示升级目标。长效果内容内部滚动，购买按钮固定可见。

`BookUpgradeOffer` 保存城市及购买标识，`BookUpgradeSource` 复用现有购买接口，扬州适配 `PurchaseYangzhou`。确认时重新比较报价和目标等级，避免重复回调把扬州再次升一级。保存失败由原有存档事务回滚，弹窗显示错误并可重试。

章节升级页与弹窗共用 `EquipmentUpgradeView`、`CityPageModel` 与 `EquipmentEffect` 结构化效果数据。升级效果由 `BookUpgradeEffects` 对比现有等级配置生成，数值不另行维护。豆皮锅 Lv2 显示恒温防焦、每锅 8 块且仍需手动翻面；Lv3 显示实际煎制时间变化及自动翻面，仍需手动切块。

弹窗遮挡底层输入；Tab／Shift+Tab 在弹窗按钮间循环，Enter／Space 激活，Esc 返回账本，焦点回到升级入口。

验证入口：`Scenes/Tests/BusinessBookSelfTest.tscn`，新增 `BusinessBookUpgradeChecks` 覆盖五城购买筛选、保存回滚、重复提交、重新载入、模态输入与1920×1080、1280×720、1600×720 三档分辨率；`--capture` 可生成视觉截图。

升级专项可附加 `-- --upgrades-only --capture --capture-dir=res://.tmp/upgrade-book-review`，使用独立测试存档。新增校验包括查看全部设备、选择不扣款、唯一购买按钮、失败重试、购买后保留选择及满级后入口和焦点保留。

2026-09-14 验证结果：升级专项 441 项通过，C# 构建零警告、零错误；真实 OpenGL 视口检查包含五城、三档分辨率、效果滚动底部、余额不足和全部满级。保存失败日志为测试注入，环境根证书读取提示不影响此次本地界面验证。
