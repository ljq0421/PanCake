# 首页、天津与武汉页面转场

用户确认：采用明显的手账翻页、幕布揭开效果；首页全部子页及两城营业、结算、返回、设置、升级、暂停等相关弹窗全部纳入。

## 实现

- `JourneyTransition` 自动加载，单个 CanvasLayer 管理临时截图、Shader、Tween、输入拦截和独立暂停原因。
- 首页跨页使用 520ms 纸页卷折、暖色纸背与折边阴影；返回首页及从账本／升级返回章节使用反向翻页。同页存档刷新不重播。
- 天津、武汉进入或退出营业使用 720ms 双侧布帘：旧画面上合拢，完全遮挡后揭开新画面。布帘优先于目的页及弹窗动效，避免同一次切换叠播。
- 设置、帮助、确认页、营业明细、暂停菜单及界面教学采用 320ms 开合；账本升级入口和返回采用翻页。原生 ConfirmationDialog 使用 220ms 淡入及截图合拢，保留窗口自身确认、取消、焦点规则。
- 原营业结算数字累计、印章及账本内页动画保留。西安、广州、扬州营业页不接入本次弹窗动效；共享首页页面照常使用翻页。
- 截图只在转场开始时采集，结束后释放；不新增美术图片。窗口尺寸变化、失焦或减少动态效果启用时结束当前转场；headless 环境直接切换。
- 转场使用 `journey-transition` 暂停原因；教学重新准备营业时保留该原因，结束时仅释放该原因，不解除手动暂停或营业明细暂停。天津工作台同步读取控制器暂停状态。

## 验收

- .NET 构建：0 警告、0 错误。
- `JourneyTransitionSelfTest.tscn`：真实 Godot OpenGL 视口，1280×720；正式版 64 项、试玩模式 65 项通过（后者增加自动完成释放检查）。覆盖翻页、鼠标遮挡与键盘拦截、设置开合、两城升级及日历、布帘、营业时钟冻结、营业账本、暂停、原生放弃确认取消、返回、减少动态效果与重复清理。截图在 `.tmp/journey-transition/`，最后一轮为试玩模式。
- `TianjinLedgerSelfTest`：190 项通过。
- `WuhanLedgerSelfTest`：51 项通过。
- `StartScreenSelfTest --dialogs-only`：17 项通过，包括显示设置超时恢复。
- 完整旧版 `StartScreenSelfTest`：61 项通过后，在 `TravelChecks` 查找章节页 `Back` 按钮时中止；当前章节页使用首页等工具入口，没有该按钮。本次未修改此旧测试。
- `DemoJourneySelfTest` 的 headless 尝试完成两城关卡数据检查后，在 `native fullscreen preview` 断言中止：headless 不提供真实全屏窗口。试玩转场改由实际视口下的 `JourneyTransitionSelfTest --demo-pilot` 验证。
- 部分旧 headless 测试打印现有 `FoodInk.Material` 的 shader compiler 诊断及故意制造的存档损坏／写入失败日志；新转场视口专项没有 shader 错误。

测试使用隔离 APPDATA 和独立测试存档，没有使用或修改玩家存档。
