# 油条区重做后操作与升级路线对照

## 实施结论

油条区已收束为单品“油条”。保留内部稳定 ID `recipe.youtiao.plain`、`product.youtiao.plain`、`stock.youtiao.plain_dough`，对外统一显示“油条”和“油条面胚”。旧存档版本已提升，不迁移旧油饼、糖油饼和自动投胚数据。

## 操作流程对照

| 环节 | 重做前 | 重做后 |
|---|---|---|
| 原料 | 原味油条、油饼、糖油饼三种面胚来源 | 一个“油条面胚”来源，占据原三种面胚区域；长按补货，每单位 0.25 秒 |
| 装锅 | 多配方选择，基础/中级容量偏小 | 每次拖入 1 根，固定使用 4 个位置；装入至少 1 根即可启动 |
| 炸制 | 旧参数为 2/2/4 容量、12/9/9 秒 | 全锅共享计时和品质；固定为 4 根、10 秒 |
| 成熟 | 手动升篮；旧自动化路径混有自动投胚等概念 | 5 秒安全期后进入 10 秒品质衰减，之后烧焦；不加入翻面 |
| 自动化 | 存在自动投胚相关面板、逻辑和资源 | 仅保留“自动升篮”；解锁后可随时开关，开启时成熟即升篮 |
| 沥油 | 升篮后等待 | 固定自动沥油 2 秒 |
| 收纳 | 可按单份从炸锅取用，成品槽为多个小格 | 任意一根发起整锅拖拽，完整校验后一次收纳到唯一大托盘；空间不足时整批保持原状并返回缺少格数 |
| 出餐 | 可从炸锅直接逐份进入订单 | 必须先整锅收纳，再从成品区逐根拖入订单；订单显示 `已装数量/需求数量` |
| 煎饼配料 | 原味油条可作为配料 | `stock.pancake.youtiao` 保留；必须从成品区逐根拖入煎饼 |
| 废弃 | 旧全局垃圾区与多鏊台布局冲突 | 油条站内提供固定可见废弃投放区；炸锅整批废弃，成品区逐根废弃 |

## 固定升级路线

| 顺序 | 升级内容 | 参数或效果 |
|---:|---|---|
| 1 | 四格油条炸锅 | 容量 4、炸制 10 秒、成品区 4 |
| 2 | 油温区间提示 | 价格与口碑条件保持原配置 |
| 3 | 可切换自动升篮 | 沿用原价格与门槛；只替代手动升篮动作 |

油饼和糖油饼升级已从固定成长路线直接删除，不设置替代商品。没有自动投胚、自动收纳或全自动生产。

## 数据与界面删除项

- 删除油饼、糖油饼的配方、商品、面胚库存、成长项、订单候选和独占图片资源。
- 删除油条区 `slot.05`、`slot.06`，其他区域稳定槽位 ID 不重排。
- 删除自动投胚面板、运行逻辑、常量、测试与投胚器图片资源。
- 场景中只保留一个油条面胚来源、一个成品大托盘、4 个稳定油条位置和一个可切换自动升篮控件。
- 普通油条订单数量为 1–3 根，权重为 50%/35%/15%；教学订单固定 1 根。
