## 实现边界

`DayController.BusinessRecords` 暴露只读的本次营业记录。完成入口在成功标记顾客已服务并记账后保存 `BusinessOrderRecord`；流失入口同步保存流失快照。快照复制订单行，以订单 ID 去重，为天津和武汉采集。开新局及放弃清空，不改存档格式。汇总仍读取 `DayLedger`，不根据界面记录重复结算。

`BusinessDetailsView` 负责两城共享模态显示，`TianjinBusinessDetails` 保留兼容入口；`CashPendantFeedback` 负责共享飞币与暂停清理；`TianjinDayScreen` 负责挂件点击、暂停状态与付款飞币。原金币盘节点为兼容共享场景绑定保留，但天津中隐藏且禁止收取，移除收钱教学。武汉已接入同一挂件规则，其他城市继续使用原共享收钱逻辑。
