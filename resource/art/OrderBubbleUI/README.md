# 顾客订单气泡外框

天津、武汉、西安共用相同的晨光、白云、圆角纸卡和底部尾巴结构，只更换城市边框色：天津暖金、武汉青绿、西安砂岩红棕。运行时由 `OrderBubbleView` 绘制 `StyleBoxTexture` 九宫格：源图左右及顶部各保留 110 像素、底部保留 80 像素，再按 0.4 倍绘制。切片线避开完整装饰和圆角，仅拉伸无装饰的中段。订单行按实际订单动态生成，支持单行和多行。

顶部装饰向控件外延伸 24 像素；布局内边距为左右 18、顶部 18、底部 12，耐心条保持 6 像素高，避免内容覆盖边缘。武汉顾客区域向上扩展裁剪范围，保持顾客、交付区域和柜台裁剪底线的原位置。底部中段使用原图左侧完整直边采样，避开武汉源图旧尾巴的缺口；尾巴单独按固定尺寸绘制，与纸面连接，避免随气泡宽度变形。`.tres` 的 texture margins 是源图切片尺寸，内容布局由组件的 `StyleBoxEmpty` 管理。

`frame-*.png` 是运行素材，`frame-*.tres` 定义九宫格边距。源图位于 `Sources/`，使用内置 ImageGen 生成的完全不透明绿幕源图，再用 `tools/prepare_tianjin_stock_ui.ps1` 抠除绿色、裁边、缩放。源图不参与 Godot 导入。

生成提示词的共同要求：仅保留参考图中的左上晨光、右上白云、圆角纸卡、底部气泡尾巴和两条简洁分隔线；不增加城市图标、结饰或额外装饰。天津边框为 `#C78337/#F2C67D/#4A3024`，武汉为 `#387F70/#A9C1B3/#24594F`，西安为 `#B8785F/#D7B072/#873F38`。运行时移除源图中的固定分隔线，避免与动态订单行冲突。
