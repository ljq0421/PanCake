# 天津工作台视角审查

日期：2026-09-09。沿用武汉视角检查的原则，以同一桌面和共同观察位置审查，分别处理物件高度、圆口、盘内食物与工具姿态。

检查页：[带辅助线的天津检查页](../.tmp/tianjin-perspective-audit/index.html)。原图、日志和复现脚本 `capture.ps1` 在同目录；`.tmp` 为本地审查产物，未纳入版本管理。

## 结论

若按武汉的统一观察位置标准验收，天津仍存在独立素材各自正对镜头的问题。右侧四只食材盘、后排三只托盘、左侧三级炸锅优先校准。不能靠统一压扁或拉高解决位置对应的透视。

与武汉不同，天津背景只清楚提供桌面前后横沿（约 y995、y580）；左右桌侧边位于画外。桌面内部斜色块属于阴影／纹理，不能据此推出准确消失点。检查页青线标注可见桌沿，黄／粉线只表示器具侧边的近似延长方向，没有虚构已标定的统一网格。

## 对象检查

| 编号 | 对象 | 结论与建议 |
| --- | --- | --- |
| 1 | 鸡蛋、薄脆、香葱、火腿盘 | 优先。位于右侧仍重复左右对称、自身居中收拢的盘形，空库存同样可见。共用 `通用食材托盘.png`，`TianjinWorkbenchLayout.IngredientSlot` 统一纵向拉伸 1.12 倍，`WorkstationSlotView.TrayVisualRect` 仅执行尺寸变换，没有按位置改变透视。盘底、内外壁和食物落点应一起校准。前壁醒目，但不能在实际厚度未知时仅凭厚度判错。 |
| 2 | 金币、成品、豆浆盘 | 优先。三个后排托盘的侧边分别向自身上方收拢。若与桌沿平行，其同方向边应服从共同空间关系。袋子可转向，杯子按高度检查开口和前后遮挡，不强求杯口与盘面高宽比一致。 |
| 3 | 三级炸锅与炸篮 | 优先。位于最左侧仍大体以自身中心对称收拢。锅体、内槽、篮框、格栅和油条成组校准；高锅与抬升中的篮子不能套低托盘四角。 |
| 4 | 生油条盘、沥油架 | 随左侧设备复核。各自居中收拢，沥油架观感较深；物件尺寸、高度不同，不能仅按画面深度判定哪个角度错误。油条可在平面内斜放。 |
| 5 | 圆炉、饼面 | 局部较协调，暂留。三级空炉可读为圆形平面，Lv3 带饼状态基本贴合。圆炉不能充当新的独立绝对参照；未检查 Lv1/Lv2 的带饼状态。 |
| 6 | 面糊碗、酱料碗、勺刷 | 暂留，核对底部接触和阴影。开口与内壁大体连贯；前排碗能看见更多内部不自动构成错误。工具允许斜放或离桌，不强制平行桌边。鸡蛋有直立、同姿势重复感，随小料盘复核支撑和遮挡。 |
| 7 | 垃圾桶 | 低优先级。可见顶面和侧面，截图不足以要求单独重画；按高物件检查落桌关系。 |
