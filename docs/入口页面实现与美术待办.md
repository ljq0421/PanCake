# 早餐旅行入口：实现与美术待办

## 本次实现

- Logo 启动页：3 秒自动进入；鼠标、Enter、空格可跳过，返回首页不重复播放。
- 早餐铺首页：墙挂世界地图、随存档变化的城市标记、新／已有旅程手账封面与真实进度纸签、设置／声音／帮助／退出图标。
- 新旅程：世界地图聚焦天津，进入旅行手账；点击“从天津出发”后才创建存档。已有或损坏存档先确认覆盖，取消与保存失败保留原进度。
- 继续旅程：当前城市、已开放营业日、章节完成状态、金币、下一城市目标。进入现有经营首页后选日与升级，不恢复营业中途状态。
- 世界地图：五城路线、解锁门槛、当前城市呼吸、完成标记、返回来源页。城市位置为路线示意，不是精确地理坐标。
- 五城章节明信片：城市与食品展示、营业日记录、进入现有城市首页。只浏览不会改变继续位置；无有效存档时转入新旅程创建流程。
- 章节演出：首次成功保存章节完成后，关闭结算账本时盖章、展示路线、进入下一城明信片；可跳过。练习、重复完成、保存失败和读取旧档不会触发。扬州之后展示五城地图。
- 独立设置：主／音乐／音效音量、静音、常用窗口尺寸和无边框全屏。显示切换 15 秒自动恢复；设置持久化独立于游戏进度。
- 帮助手账、键盘导航、弹窗焦点限制、页面动画清理、1920×1080 等比画布与宽屏留边。

## 接口与验证

P2 追加验收：C# 构建 0 警告、0 错误；`StartScreenSelfTest` 106 项通过（原 98 项加城市焦点恢复、主静音／独立通道图标和手账页签返回检查）。真实视口图库覆盖 1920×1080、1280×720、1600×720，包含新增武汉／西安印章、五城纪念章、按钮及设置弹窗；三档均输出 `JOURNEY_GALLERY_OK`。存档和设置使用测试隔离路径，本轮没有修改经营玩法，也没有重复跑无关城市工作台专项。

截图：`.tmp/start-review/{1920,1280,1600}/continue.png`、`map-progress.png`、`new-journey.png`、`completion-武汉.png`、`completion-西安.png`、`five-cities.png`、`settings.png`。日志：`.tmp/p2-test-output.log`、`.tmp/p2-final-{normal,small,wide}-output.log`。环境根证书提示仍存在；预期的存档写盘失败测试会输出错误并验证回滚。

- `StartScreen` 的旅行页面事件由 `GameController` 接入现有城市经营首页；旧城市地图入口统一导向新世界地图。
- `JourneyModel` 集中保存五城展示信息，章节天数复用 `SaveService.ChapterDays`，状态直接读已有存档。
- `SaveService.PendingJourneyCompletion` 只存在内存，来自共享结算／扬州结算返回的首次完成结果；不序列化。消费、读取存档和成功重置会清空。
- `JourneySettings` 自动加载，默认设置文件为 `user://journey_settings.cfg`。可用 `--journey-settings res://.tmp/example.cfg` 隔离设置；测试另行使用独立进度文件。
- 音频总线为 `Master ← Effects / Music`。原音效自身音量不变，默认通道 100%；暂停、失焦与离城停止规则保持原样。
- 场景保留固定画布、背景和弹窗容器；旅行页数据内容位于明确标记的动态子树。

验收记录与截图入口见 `游戏开始页.md`。
