## 统一美术交付要求

1. 使用现有武汉米白、青绿、墨绿的二维卡通画风，圆润粗轮廓、低细节，不添加写实金属、复杂渐变或深重阴影。轻微俯视3/4，顶部可见面积约30%～40%作为视觉校准目标，最终以全桌合成图为准。
2. 以1920×1080工作台合成验收；同时缩至1280×720检查。独立物件保持等比，不靠横向压扁或拉高来补救透视。
3. 提供PNG及可编辑分层源文件。需透明图时遵守项目流程：**先生成纯绿色背景图片，再抠成透明背景**。交付前检查无绿色溢边、半透明杂点与裁切缺口。
4. 同一设备不同等级及状态共享画布尺寸、中心、基线和锚点；另外标注可见边界、锅面四角/碗口椭圆、手柄抓取点、盘内安全区域。蒸汽与可选阴影独立分层，不能决定物体本身尺度。
5. 库存数、价格、按钮、箭头、进度和状态文字全部由程序绘制，不烘焙进素材。保留点击空白及食物堆叠空间；实际点击目标不得小于48×48设计像素。
6. 按“锅体＋状态层＋工具”“碗＋食物层”“托盘＋盘内食物”分别整组审图，再放回整张桌面比对。需同时展示空、制作中、完成、缺货和补货状态；确认三档设备与16块豆皮、6杯蛋酒库存的代表图不会重叠越界。
