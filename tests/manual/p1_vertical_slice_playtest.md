# P1 完整煎饼垂直切片真人验收单

> 引擎：Godot 4.7.1 stable  
> 自动检查不能替代本表。每次验收记录实际完成时间、订单和主观问题。

## 1. 首次游玩可理解性

- [ ] 不阅读开发文档，仅根据订单卡、阶段提示和按钮文字完成第一张订单。
- [ ] 能说明“确认面饼、放鸡蛋、用 T 形摊面器摊蛋、翻面、确认第二面、刷酱/放料、折叠、包装、出餐”的顺序。
- [ ] 翻面过早、鸡蛋未摊开、第二面过生或缺少鸡蛋时，能根据现场提示修正，而不是进入死路。
- [ ] 能分辨甜面酱瓶与辣椒酱瓶，并知道切换酱料会清空刷上剩余的另一种酱。

## 2. 连续操作与画面

- [ ] 左侧四个配料盘的整格拖拽范围符合视觉预期。
- [ ] 配料拖到饼外时会回到托盘；落在破洞或无饼区域时提示清楚。
- [ ] 完整鸡蛋拖动、刚打入的生蛋图和开始摊动后的程序化蛋层衔接自然，没有明显跳变或双重叠图。
- [ ] T 形摊面器接触蛋黄后能看到蛋黄破开，连续画圈能扩大蛋液覆盖；等待过久后蛋液变稠但仍保留低效率补救路径。
- [ ] 鸡蛋、薄脆、火腿肠、葱花在真实运行尺寸下都能辨认，且不会遮住火候和酱料判断。
- [ ] 鏊子外圈、底部区域和左侧控制条可舒适到达，没有 UI 截断有效椭圆操作域。
- [ ] 第一面和第二面的颜色变化足以支持翻面与完成火候判断。
- [ ] 两种酱料在饼面上的颜色、重叠和浓度差异可见。

## 3. 订单、评分与反馈

- [ ] 至少完成经典、香辣火腿、双酱全料三种订单。
- [ ] 故意漏放一种配料后，订单分与顾客反馈明确指出缺失。
- [ ] 故意放入订单外配料后，订单分与反馈能区分“多放”而不是“缺少”。
- [ ] 分别制作火候偏生、偏焦和两面较均匀的成品，火候评分顺序符合观察。
- [ ] 配料明显靠边、堆在中央和较均匀摆放时，配料评分与标签有可理解差异。
- [ ] 分别制作鸡蛋覆盖不足、局部堆积和较均匀摊开的成品，“摊蛋”分、标签和总分顺序符合观察。
- [ ] 厚料压在折片上时能出现鼓包；严重破洞仍可用托盘结束，不产生死路。
- [ ] 正常纸袋、加固纸套、托盘三种包装的结构代价符合预期。

## 4. 节奏、暂停与声音

- [ ] 单张正常订单制作时间落在暂定 35–70 秒附近；若普遍超出，记录具体步骤。
- [ ] 耐心下降能制造压力，但不会迫使玩家放弃观察面饼。
- [ ] `Esc` 暂停期间火候和顾客耐心都不继续推进。
- [ ] 倒面、摊面、翻面、刷酱、放料、折叠和出餐提示音不会刺耳或过密。
- [ ] 完成评价后能收款并进入下一订单，面饼、配料、工具、酱刷和包装全部重置。
