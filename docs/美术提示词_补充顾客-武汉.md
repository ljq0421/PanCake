# 《早餐铺子》武汉章节补充特色顾客美术提示词

## 使用说明

本稿是基于《美术提示词_补充顾客-天津.md》结构与画风规范新增的武汉角色提案。人物年龄、面貌、性别、衣着和配色均为游戏原创设定，不代表相关职业的统一穿着，也不对应现实中的具体人物。

使用独立编号WH-C01～WH-C10，不占用或覆盖天津素材编号。生成图片时，应同时提供已确认的武汉工作台锚点图和既有顾客图片；本次天津附件是文字提示词，不包含这两张实际参考图。

统一采用768×1024透明背景、完整全身源素材、轻微正面偏3/4视角。保留附件的画布占比规范。附件中约220～270像素的数值作为旧版全身展示参考；当前半身靠近柜台的显示方式以游戏里已确认NPC的头部尺度为准，不机械套用旧的全身高度。

武汉服装以灰蓝、低饱和青绿、米白、燕麦、柔和橄榄绿为基础，可少量加入淡灰紫、柔和暖红或浅金。不是所有人物都穿青绿色，皮肤、头发不套青绿色滤镜。城市感通过人物组合和生活细节建立，不通过古装、舞台装或复杂地标图案建立。

这些角色是城市专属外观，不新增十套顾客机制。可挂接已有普通街坊、上班族、老熟客、游客和大单等顾客逻辑；职业不自动决定耐心、订单或消费能力。

# WH-C01｜老汉口街坊婆婆顾客

```text
严格参考生成时随附的武汉章节锚点图和已确认顾客人物参考图。
输出尺寸严格为768×1024，透明背景。
生成一名适合《早餐铺子》武汉章节的“老汉口街坊婆婆顾客”。

人物定位：
住在老汉口街区、经常来早餐铺过早的老年女性熟客。重点表现熟络、精神、温暖的邻里感，不要把地方性表现为凶悍、吵闹或夸张市井姿态。

【画风要求】
必须是明显的二维休闲经营游戏NPC，不是人物立绘、半写实插画或宣传海报。
二维、扁平、圆润、粗描边、大色块、低细节、轻微Q版、强卡通化。
头稍大、身体略短，四肢与手脚简化；五官只保留少量清楚的线条和色块。
与已确认顾客保持相同头身比例、描边粗细和简化程度，描边沿用深暖棕。
禁止真实人体比例、复杂衣褶、精细发丝、皮肤纹理、写实材质、复杂光影、3D渲染感和噪点。

【人物设定】
年龄约58～72岁，女性。脸型偏圆，身形略矮、略圆润，头部比例仍须与既有NPC一致。灰白短卷发，用三至四组大块弧形发团概括，不画细密卷发丝。穿简洁针织开衫、米白内搭、舒适长裤和平底鞋。服装整洁，只有少量必要的衣领与袖口线条。

【配色与识别重点】
主色为浅豆青、米白，裤子用柔和灰褐。头发、圆脸和开衫轮廓是主要识别点。不要依赖被柜台遮住的购物袋或鞋子区分人物。

【姿态与表情】
站立，轻微正面偏3/4视角，朝向与已有顾客一致。表情自然亲切，嘴角轻轻上扬，像刚和摊主打过招呼。双手自然放松，不叉腰，不指人，不张大嘴讲话。

【尺寸要求】
人物主体占768×1024画布高度约76%～82%。
输出单名角色、完整全身、透明背景，主体居中，四周保留透明留白。
头顶、头饰、双手和双脚均须完整，不要贴边或被裁切。
在1920×1080游戏界面中与现有NPC保持同一头部尺度；可以由工作台遮住下半身，但不要在源图中裁掉腿脚。
不要订单气泡、食物、餐具、文字、数字、Logo、水印、场景背景、地面、底座或投影。

【额外禁止】
不要密集皱纹，不要夸张老态，不要花布满版图案，不要菜篮子，不要拐杖。
```

## 落地检查

将人物临时遮到腰部，只看上半身；再缩小到实际游戏尺寸，检查是否仍能区分。优先检查头发、头饰、脸型、衣领、肩部轮廓及胸前大色块，而不是看不清的小配件。以上服装描述是原创视觉方案，不能据此把某种服装说成真实职业的专属制服。

同一角色后续制作开心、正常等待、不耐烦、生气四状态头部时，锁定头型、发型、帽子、眼镜、耳朵、下巴、尺寸和对齐位置，仅调整表情，避免切换时跳动。默认整身不手持早餐和工具，便于复用接餐动作。

优先制作WH-C01、WH-C02、WH-C03、WH-C04、WH-C06、WH-C07。第一批覆盖老年熟客、店主、轮渡从业者、技术通勤者、休闲运动者和手艺人。已有学生或工人底型可用于第二批调整，不必将所有原型都重画。
