# 天津经营循环轻回弹

依据 `果冻动感分析.md`，本轮仅处理天津拿配料、制作、装袋、交付、自动收款这一条循环。

- 食材料盒沿用现有轮廓高亮，仅一份可见食物响应悬停及按下；容器保持稳定。悬停 0.10 秒，按下 0.05 秒。
- 天津拖放松手时执行业务接受，0.11 秒吸附作为独立视觉收尾；下一次拖拽不等待它。未命中或被拒绝仍返回原位，不扣库存。共享 DragService 默认仍使用原有流程，仅天津开启即时接受。
- 点击鸡蛋、香葱可见单份飞入；拖放使用已有预览。落料形变约 4.5%，薄脆和油条约 2%，只影响炉面食物绘制，不缩放设备或输入区域。
- 摊饼、刷酱继续由输入进度驱动；保留已有翻面规则，翻面落锅时播放短滋啦声。
- 装袋业务状态立即可交付。纸袋以底部为支点，0.055 秒轻压、0.085 秒反弹、0.14 秒归位，最大横向形变 7%，纵向使用倒数倍率。拿起可打断，取消拿取不损失成品。
- 部分交付只弹实际增加进度的订单行商品图标，文字及整张订单卡保持稳定；整单完成、自动入账、飞币和挂件反馈继续复用现有实现。
- 新增短落料、薄脆、纸袋合成材质声，沿用音效总线；纸袋声对齐轻压接触，落料声对齐吸附接触。单个制作声音播放器限制叠加；完成和收款继续由共享业务音效负责。
- 暂停、失焦、离开天津会取消收尾并复位，不补播声音。沿用“减少动态效果”设置，保留静态状态及目标高亮。
