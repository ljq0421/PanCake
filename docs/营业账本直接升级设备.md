# 营业账本直接升级设备

五城正常营业成功结算后，“可升级”可点击打开共享设备升级弹窗。仅列出已开放、满足前置等级且余额足够的下一档设备；无符合项时隐藏入口。练习、营业中与结算保存失败不开放购买。

弹窗展示钱包余额、设备等级变化、配置对应的效果和“升级 ¥价格”。点击购买后保存设备与扣款，下次营业生效；刷新余额、列表与贴片，不重复结算营业收入。全部买完或余额不足时显示“暂无可购买升级”。

`BookUpgradeOffer` 保存城市及购买标识，`BookUpgradeSource` 复用现有购买接口，扬州适配 `PurchaseYangzhou`。确认时重新比较报价和目标等级，避免重复回调把扬州再次升一级。保存失败由原有存档事务回滚，弹窗显示错误并可重试。

升级效果由 `BookUpgradeEffects` 对比现有等级配置生成，数值不另行维护。豆皮锅 Lv2 显示恒温防焦、每锅 8 块且仍需手动翻面；Lv3 显示实际煎制时间变化及自动翻面，仍需手动切块。

弹窗遮挡底层输入；Tab／Shift+Tab 在弹窗按钮间循环，Enter／Space 激活，Esc 返回账本，焦点回到升级入口；入口消失则回到“收好账本”。

验证入口：`Scenes/Tests/BusinessBookSelfTest.tscn`，新增 `BusinessBookUpgradeChecks` 覆盖五城购买筛选、保存回滚、重复提交、重新载入、模态输入与两档分辨率；`--capture` 可生成视觉截图。
