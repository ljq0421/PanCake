# 天津首次维护教学与 Demo 首日收尾

- 补货在首次低库存时，优先于炉面空闲且没有待交付煎饼的空档提示；实际制作被缺料阻断时立即提示。摊饼、刷酱、拖动期间不插入低库存提醒。有限料盒使用现有低库存阈值，豆浆余量不超过 2 杯时提示。
- 左键长按 0.45 秒启动真实补货，提示随后切换为等待补满；实际补满才保存已学动作。短按、取消长按、重置营业均不误记为完成。暂停和失焦隐藏提示并保留未完成补货。
- 首次焦糊优先提示右键长按 0.45 秒；形成丢弃拖动后高亮垃圾桶，成功丢弃才保存已学动作。正常食物不主动提示丢弃，取消后仍可再次提示。炸锅与炉面的清理优先于空闲制作提示。
- 沿用每个动作的学习记录及“本次关闭”控制，不强制首份教学制造焦糊或消耗额外食物。
