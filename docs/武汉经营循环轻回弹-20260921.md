# 武汉经营循环轻回弹（2026-09-21）

参照天津经营循环实现，按本次确认覆盖热干面和豆皮，取消纯动画等待。正式版与 Demo 复用同一实现。

## 行为

- 动画不再占用面篮、拌面碗、豆皮锅和备餐盘的操作资格。煮制、沥水、煎制、最低加热时间及配料顺序仍由原状态机判断。
- 倒面后可以立即调味；连续加入基础调味、葱花、辣油后可立即拌面；拌好加牛肉后立即可拖给顾客。
- 倒浆后可立即加蛋，翻面后可立即加馅；横切后无需等刀具收尾就可竖切。切完入盘后立即可交付或制作下一锅。
- 同一位置开始新动作时，将上一段视觉表现落定到已经提交的状态。抓起提篮时从当前显示位置接管，不再受提篮 Tween 牵引。开始拌面、拿取成品及成功交付会清除对应旧表现。
- 左键交付松手时立即判定并提交，复用天津的 0.11 秒独立吸附收尾。无效目标和取消不消耗商品；右键长按 0.45 秒丢弃保留原可取消吸附流程。
- 碗中食物、首份豆皮及独立勺具提供轻微悬停/按下反馈：悬停约 0.10 秒、按下约 0.05 秒，勺具仅位移约 2 像素；食物最大约 2.5% 横向变化，纵向使用倒数倍率。豆皮落盘收尾增加约 3.5% 轻压回位。
- 背景里已经绘制的容器和食材保持现有轮廓高亮；不让整张配料台、碗、锅或托盘变形。设备位置及输入命中区域保持稳定。
- 保留现有面条跟手、配料材质、豆皮翻面/摊开，以及制作、订单、收款音效。暂停、失焦、明细及退出取消旧收尾，恢复不补播；减少动态效果保留立即可用的静态结果与目标高亮。
- 实际渲染检查发现倒面四边形网格在中间帧可能自交，改为明确的三角形单元，跳过退化三角形，避免渲染器三角化失败。
