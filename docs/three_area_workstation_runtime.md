# 三区域工作台运行时合同

> 当前基线：2026-08-13，Godot 4.7.1。

## 正式入口与场景结构

- 正式入口固定为 `res://scenes/gameplay/five_area_workstation.tscn`，根节点类型继续为 `Workstation`。
- 该场景是独立场景，不继承历史工作台。`FiveAreaInfrastructure/Stations` 只包含现磨豆浆、煎饼和油条三个常驻区域。
- 历史 `initial_unlock_workstation.tscn`、`workstation.tscn`、`initial_unlock_preview.tscn` 已删除，不提供内部路径跳转。
- 旧单鏊、旧五区点击层、旧单顾客订单卡、旧材料架/工具架、旧全局废弃与暂存控件，以及槽位 7–18 的锁层均不在运行树中。
- 日结、成长、付款、教程、三顾客服务位、豆浆/油条操作和旧存档暂存品数据兼容仍保留。

## 三鏊布局与解锁

- 源索引和存档顺序不变：主鏊为 0、左鏊为 1、右鏊为 2。
- 显示横坐标为主鏊 `405`、左鏊 `96`、右鏊 `714`，视觉外沿相接；三个 `PancakeSurface` 热区互不相交。
- 解锁顺序仍为主鏊，然后左鏊，最后右鏊。

## 添面与摊面视觉

- `begin_order()` 成功扣除一份面糊后，立即在鏊面中心创建面糊团并强制上传首帧纹理。
- 首次按下摊饼器只开始摊制，不重复添加面糊。
- `BATTER` 阶段的旧存档若覆盖率为零，加载时自动补建中央面糊。
- 快速拖动按不大于 2.5 个模拟格的间距分段采样；紧凑鏊面脏纹理按 30 Hz 刷新。
- Shader 对高湿度生面糊增加暖色和明暗对比；熟化、焦化、酱料、损伤与评分仍读取原模拟字段。

## 兼容与验证

- `five_area_*` 存档键、订单/进度接口、库存扣除次数、三鏊独立快照和交付评分规则不改名。
- `tools/run_checks.ps1` 是完整 headless 清单；旧单鏊坐标/隐藏状态/预览入口测试不再属于当前合同。
- `five_area_formal_scene_self_check.gd` 检查独立正式场景和已删除节点；`multi_griddle_station_self_check.gd` 检查布局、热区、首帧面糊、连续拖动和零覆盖存档恢复。
- `three_area_multi_griddle_gpu_smoke.gd` 使用真实鼠标路径，在 1920×1080、1366×768、1280×720 下截图，并分别保留初始面糊、摊制中和成形状态。
- 自动化与 GPU PASS 只证明对应工程合同；“是否清楚、是否足够紧贴、拖动手感是否自然”仍需人工验收。
