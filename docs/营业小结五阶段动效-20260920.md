# 天津、武汉营业小结五阶段动效

## 已确认范围

天津、武汉收摊小结使用同一套 Godot Tween 编排，正式版和试玩版共用。其他三城保留原动效，营业中打开账本直接显示完整统计。原有翻书衔接继续使用。

顺序固定为：今日接待 → 顾客评价 → 今日亮点 → 收入揭晓 → 营业手记。

2026-09-20 后续确认：左右页内容对调，左页为接待、评价与亮点，右页为收入与手记；移除“最受欢迎”的标题、底板、食物图、名称与销量，手记上移承接收入。操作按钮保持原位置。

## 时间与表现

现有翻书入场为 0.52 秒；以下时间从翻书结束开始计算。

| 时间 | 内容 |
|---|---|
| 0.15–0.50 秒 | 接待人数、完成、错误、流失及完成率淡入；进度条填充 |
| 0.50–0.90 秒 | 满意度显现；有 Perfect 时轻盖章，无 Perfect 时显示原占位文案 |
| 0.90–1.15 秒 | 亮点、评级与解锁说明同步淡入 |
| 1.15–1.75 秒 | 总收入数字从 0 累计到销售收入，销售明细显示终值 |
| 1.75–1.95 秒 | 总收入数字补入小费，小费明细显示终值 |
| 1.95–2.10 秒 | 三枚小金币局部落入，金额放大到 105% 后归位 |
| 2.25–2.50 秒 | 手记整句淡入，便签从下方 8 个布局像素归位 |

底板、区域标题、翻页和操作按钮始终就位。收入揭晓前隐藏主金额、金币主体和两行明细。收摊亮点中的小费文案为“收获小费”，具体金额仅在收入区显示；营业中的原文案不变。

无小费时省略补入阶段，后续提前 0.20 秒。零收入不播放落币及金额缩放。累计时长与金额大小无关，最终金额以快照中的整数准确归位。

保留开账本及有效 Perfect 盖章声；不播放结算金币声，手记不播放 Ready 提示音。无数据入账或存档格式变化。

## 中断与可访问性

- 动画期间点击空白或按空格立即补齐结果，不关闭账本；吞掉该次空格的按下、重复及释放，避免激活聚焦按钮。
- 翻页、查看设备、收好账本及重试保存按原规则立即执行，保存失败与教学限制仍生效。
- 返回小结不重新计数；隐藏、重新打开和退出节点清理 Tween、临时金币及位移。
- 减少动态效果模式直接显示完整结果。

## 验证入口

先执行 `dotnet build --no-restore`，再使用 `D:\Godot\GodotSharp\Godot_v4.7.1-stable_mono_win64_console.exe` 运行 `res://Scenes/Tests/BusinessBookSelfTest.tscn`，日志使用绝对可写路径。

- 无用户参数：现有五城账本回归，包括翻页、升级和保存失败恢复。
- `-- --motion-only`：真实 Tween 分步推进，验证五阶段、累计、无小费、零收入、大金额、无 Perfect、跳过、翻页、设备入口、隐藏和重开。
- 非 headless 加 `-- --motion-only --capture --capture-dir=res://.tmp/book-motion-captures`：两城、1920×1080／1280×720／1600×720 的阶段截图和按真实帧时钟完整播放，并检查最终统计文字实际像素。

动效实现集中在 `BusinessDetailsView.TravelMotion.cs`，布局登记参与动画的内容节点，位置遵循上述左右页布局；动画结束或跳过时恢复各节点的布局位置。
