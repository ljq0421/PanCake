# 帮助页插画手账改版

完整版与试玩版共用一页通用说明；试玩版保留配乐署名入口。帮助页采用独立书本尺寸，不改变其他书页。三张旅程说明卡和四个操作区均只读。

城市页、日历、升级、收藏及地图按当前选择城市显示贴士；首页按有效存档的继续城市显示，没有有效存档时显示天津。贴士不修改进度、收银或制作规则。

现有帮助按钮仅位于首页，本次保留入口范围。城市上下文通过专项测试直接打开帮助页验证，不新增城市页按钮。

## 已接入的手势图

用户提供 `resource/art/Global/StartPage/帮助手势.png`，1448×1086，透明背景。通过 Godot AtlasTexture 引用点击、拖动、长按、丢弃四个区域，保留原图。分区线 x=724、y=590，各区裁除透明留边并缓存。

## 已接入的旅程插画与城市标记

使用用户提供的 `resource/art/Global/StartPage/新的旅程.png` 和 `继续旅程.png`，所有待补插画现已接入，原图保持不变。

城市贴士中移除独立城市名，明信片从 265×142 展示区域放大至 324×197。定位符与城市名放入明信片右下角空槽，并继续跟随当前旅程城市。天津及通用明信片使用原画空槽；武汉、西安使用现有纸签承载定位标记。

其余复用现有书本、新旅程封面、地图、设置齿轮、星星、城市明信片和按钮。广州、扬州使用通用明信片加早餐铺标记。

“记住了”按用户指定使用 `首页地图按钮底板.png`，按钮文字、鼠标与键盘响应仍由 Godot Button 处理。
