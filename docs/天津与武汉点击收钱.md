# 天津与武汉点击收钱

2026-09-08。按用户确认，保留自动记账，点击金币盘仅收走钱堆并播放反馈；未点击不损失收入。

- 天津沿用成品托盘左侧金币盘。武汉在工作台局部坐标 (1395,16) 新增同素材金币盘，250×110，缩放0.9，位于蛋酒底料杯上方。
- 钱堆表示本日收入减去已点击收走的金额，每10元一枚示意币，向上取整，最多12枚；盘下显示“点击收钱 ¥金额”。
- 点击立即清空钱堆，托盘100ms轻压、160ms恢复；3～8枚金币依次飞向顶部金币图标，主飞行280ms，间隔35ms。金额跳字短暂停留后淡出，顶部图标放大并恢复，同时播放三声递升的短促收钱音。
- 重复空点不播放收益反馈；收钱期间新订单付款独立累积，可以再次收取。飞行动画不改账本或存档。
- 武汉整单付款增加顾客到金币盘的飞币；部分交付、拒绝交付不触发。收取时清理仍在飞向托盘的付款金币，防止清空后出现残留落币。
- 天津、武汉的钱堆采用固定错落位置、轻微旋转、扁平透视和局部重叠，刷新收入时已有金币不换位；0～12枚金币旋转后的完整边界均在盘面内。付款飞币抵达后用180ms向三个不同落点轻弹散开，再用100ms淡出并融入钱堆；沿用原飞币的暂停、失焦和清理机制，减少动态效果时直接呈现静态钱堆。
- 暂停、失焦及确认打烊弹窗阻止收取并暂停反馈；隐藏、重开及结算清理反馈。重开清空展示余额。减少动态效果时保留金额淡出与图标颜色提示、音效，省略位移与缩放。
