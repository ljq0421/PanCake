# 天津垃圾桶与右键丢弃

2026-09-11：天津三个营业阶段切换为 `天津-煎饼-v1.png`、`天津-煎饼-炸锅-v1.png`、`天津-煎饼-炸锅-豆浆-v1.png`。垃圾桶直接使用背景中的桶身，热区按原图 `(1000, 838, 170, 103)` 转换到工作台坐标。

## 操作

- 长按食物上的鼠标右键 0.45 秒，再拖到桌面底部垃圾桶后松开丢弃。右上角丢弃按钮、炉面及炸锅点击清理入口已移除。
- 炉面煎饼（含制作中、焦糊和装袋成品）每次清一张，熟油条每次一根，炸锅清当前整批。
- 豆浆及未投入的原料不可丢弃；不返还已经消耗的原料，不额外扣金币。
- 左键继续制作和交付，不能丢弃。右键拖动不能交付或添加配料。结束刷酱使用短按右键、F 或收刷按钮。
- 按 Esc、桶外松开或暂停取消拖动。只在有效投放提交时清理；拖动期间经营时间继续，来源已经交付、入库或更换时拒绝旧拖动。

## 实现与验收

共享拖动服务新增可选鼠标键参数，默认左键。天津使用专用丢弃载荷和来源验证回调；炉面、炸锅的重置代数与熟油条队首代数防止旧拖动清理新食物。无存档变更，实验工作台和其他城市保持原操作。

针对测试入口：`StageFourSelfTest.tscn -- --trash-only`，覆盖各制作阶段、按键隔离、库存扣除、来源变化、取消和吸附动画期间暂停。背景和缩放验收截图位于 `output/tianjin-stage-workbench/` 的 `day01.png`、`day05.png`、`day09.png`、`day15-720.png`。
