# 天津美术一致性与顾客显示修复

2026-09-12。按已确认方案保留素材造型，以深棕色线条统一画风；顾客按可见半身收敛大小。

## 实现

- 食物使用共享 `FoodInk` 渲染材质，源 PNG 不变。桌面、豆浆库存、订单图标和普通拖拽预览共用规则；订单图标使用较细的屏幕像素描边，香葱降低内部加深强度，保留绿色填色。只匹配天津指定食物资源，其他城市引用这些资源时同样生效。
- 炸篮保留绿幕扣除、原有网格和升降动作；强化棕色外框，网格使用更细的描边。
- 夹具前景直接采样现有背景，以两侧夹臂和木筒的独立轮廓遮罩覆盖顾客，保留夹臂间隙。沿用炸锅前景的层级；前景为 `Node2D/Polygon2D`，不占用鼠标命中区。
- 24 款顾客各保留一张身体和四张表情。身体按单独校准的衣领高度移除原头像；表情以颈部皮肤锚点对齐，不再合并四个头像轮廓擦除身体。
- `tools/tianjin_portrait_calibration.json` 保存每个角色的颈部位置、头部宽度、身体切分线和腰线。准备脚本输出 `counterWaist`、`counterHeight`，天津按 240 个设计像素的半身高度等比显示。同一角色切换表情不移动身体或腰线。
- 顾客资源为共享修复；天津半身配置单独启用。西安继续使用既有的头部高度布局接口，武汉继续使用其既有布局。

原始整身 PNG 和表情原图均保留。运行时顾客文件仍位于 `resource/art/TianJin/Customers`，无需存档迁移。

## 复现与验收入口

在项目根目录执行：

```powershell
./tools/prepare_tianjin_customer_portraits.ps1
dotnet build --no-restore
./tools/capture_tianjin_art_review.ps1
```

准备脚本输出 120 张顾客 PNG；重复执行已验证 120 张结果内容完全一致。图片导入需由 Godot 编辑器刷新。
