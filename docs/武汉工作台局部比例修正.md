# 武汉工作台局部比例修正

2026-09-08。保留主要设备、背景、面碗及玩法，修正设备周边物件的局部比例。以现有青绿把手豆皮托盘为基准，未替换美术源文件。

## 第一轮布局规则

- 拌面底座使用525×250的设计区域，比原420×200放大25%；面碗尺寸保持不变。调料、食材盘、酱汁瓶和筷子重新落在台面上。
- 生面与小料区分别定义托盘外框、盘内安全区域和食材显示矩形。食材完整等比缩放到内沿内缩8像素的区域；点击使用托盘范围，拖影与补货使用食材范围。
- 食材盘和豆皮盘以分段纹理投影增加盘面纵深，分别映射后壁、底面、前壁，避免连同盘壁一起拉高。该投影仅用于工作台，不修改天津共用素材。
- 豆皮盘为252×90；每层4列×2排，最多2层。层内位置使用`index % 8`，层级使用`index / 8`，上层向上6像素、向右2像素，先画底层再画上层。静态摆盘和入盘动画共用`StockItemRect`。
- 面浆和糯米馅容器等比放入107×93区域，约为原尺寸的1.45倍；动画使用相同的容器大小。
- 补货按钮48×48，位置跟随容器和拌面台。库存主标签与“余量低／补货中”分行。工作台输入范围扩大到1920×425，覆盖备餐盘前沿。

## 第二轮：豆皮放大与拌面区整理

按后续确认方案，以第一轮结果为基准：

- 豆皮在第一轮已经等比适配的实际显示尺寸上乘以1.2，宽高同步增加。摆放中心横向收拢到原偏移的96%、纵向收拢到80%，保留每层4列×2排及上层偏移；允许重叠，仍从底层到上层、后排到前排绘制。备餐盘、锅内豆皮和交付拖影尺寸不变。
- 拌面台从525×250扩大到580×276，面碗保持原有位置和尺寸。调味、葱花在左，辣油、牛肉在右；两壶使用110×94的等比显示区域，两盘统一118×68。小料盘前移到台面平面内，避免压着底座前壁。
- 酱汁瓶靠近调味壶，筷子沿碗右侧放置。四组库存与补货入口放在台面下方同一行，左右各两组；“已加”和缺料／补货状态合并到独立状态行。热干面制作提示移到工作台上方。
- 绘制、点击和现有制作动画继续共用位置定义；无公共接口、库存规则、交付规则或存档改动。
