## 油条

生熟油条不再强制拉伸填满矩形。使用原图等比缩放、32°旋转，并以旋转后的不透明轮廓计算盘内适配。拖拽继续使用原图等比展示。取用判定跟随旋转、缩放后的图片不透明轮廓（Alpha > 0.05），托盘、标牌和图片透明部分不能触发拖拽；无油条可见时不能取用。

煎饼炉的透明布局层与左侧油条区域有重叠，必须忽略鼠标事件，由炉面输入控件处理实际操作。点击回归在完整营业页面内验证，覆盖油条实体采样点、透明部分、标牌、页面缩放和悬停动画，不能只用独立槽位或直接调用 `_GuiInput` 代替页面命中验证。

- `StageFourInputSelfTest.cs` 在完整营业页面、三级设备、100%/67% 页面缩放和悬停状态下，对小料、面糊勺、酱刷、豆浆与装袋煎饼的不透明像素采样并检查实际鼠标接收节点；另验证少量库存、补货按钮和摊饼、加蛋、翻面、刷酱、加葱、折叠、装袋的鼠标操作。

## 库存

2026-09-08：天津营业工作台取消小料、豆浆、熟油条与炸篮的显式库存数字；低库存提示不再报具体份数。熟油条通过固定位置的1～3组素材表达少、半、满，用完露出空架。名称标牌暂时保留；其他城市与实验台维持原显示。


- 鸡蛋、薄脆、火腿：1～6份按真实数量显示；超过6份用最多十个独立位置表现疏密，天津营业工作台不显示库存数字，由盘中素材数量表达余量。取消前后层重复叠图，每张素材保持纵横比，图片之间留出间隙。
- 固定排列按容量确定：最多5列2排，容量不超过5时使用一排。取走时从最后一个可见位置依次消失，补货后恢复；同一容量下食材位置、大小和节点均保持不变。
- 大于6份时显示数量为 `min(真实数量, 10, 6 + ceil((真实数量 - 6) / (容量 - 6) × 4))`。这是库存疏密示意，高库存的一张图不代表一份；玩家通过盘中疏密判断余量，不显示精确数字。容量24时，实际24、18、12、7、6、3、0分别显示10、9、8、7、6、3、0份图。
- 豆浆：固定两排三杯，取走一个隐藏一个；整盘仍只有一个取杯入口，补货按钮独立。开始拖拽与取消不扣杯，交付成功后随运行库存更新。
- 香葱、液面：0为空；大于0且不超过容量25%为少；25%～60%为半；超过60%为满。香葱以互不重叠的1～3簇表达，面糊与酱料通过独立液面层表达。勺子和刷子尺寸固定，空库存时弱化显示工具。
- 小料补货动画：鸡蛋、薄脆、火腿、香葱在原有1秒补货时间内，按 `原余量 + floor((容量 - 原余量) × 补货进度)` 逐份增加展示量，复用原有固定位置、最多十张食材及香葱1～3簇的表现规则。进度不变时画面不变，补满后与正常库存展示一致；低动态模式同样只改变可见数量，不增加位移或弹跳。
- 补货预览不提前增加可用库存，补满前不能取料，天津营业工作台只显示补货进度条，不显示百分比。面糊、酱料与豆浆仍在补货完成后更新库存图。
- 槽位接收真实数量与容量，食材和杯子节点创建后复用。未解锁的槽位仍隐藏并保留原位置。

### 盘沿与豆浆排列修正

原摆放检查只使用托盘图片外框，允许小料压到前盘沿。当前小料锚区为 `(34,28,180,60)`，内盘安全区域为 `(30,24,188,68)`；鸡蛋、薄脆、火腿和香葱全部按内盘检查，并验证可见图片两两不重叠。

豆浆托盘画面保持246×86，杯子两排各三杯，同排间距53px、前排错位8px；取杯热区扩展覆盖整盘杯子。数量标牌位于杯盘前沿，补货按钮独立在右侧，补货时不挤占盘面。拖拽预览仍为一杯。

## 订单气泡

使用专用美术底框、独立尾巴、耐心条底框。底框九宫格缩放，尾巴独立等比显示并指向顾客。保留动态食物图标、商品名称、数量、完成标记、差异配料与顾客状态。

商品名称18px、数量16px、配料18px。五顾客栏仍以1920×1080设计，支持1280×720画布缩放。新增装饰全部忽略鼠标事件，继续支持直接拖给顾客。气泡皮肤只在构建时安装，不在刷新循环里反复替换。

美术文件、原始绿底图、实际生成提示词及抠图复现命令见 [素材说明](../resource/art/TianJin/StockUI/README.md)。使用内置 image_gen，无外部 API 调用。
