# 武汉工作台尺寸、透视与越界修复

2026-09-09。依据用户四张标注图及确认的“适中放大＋重绘托盘”方案实施。本页更新此前优化文档中的尺寸、托盘绘制和金币盘位置；以当前工作区为基线，保留已有玩法、背景和其他章节修改。

## 实际变化

- 小料壶、葱花／牛肉盘、豆皮浆碗、糯米馅碗及豆皮备货盘的适配框放大25%；生面盘由174×102增至217.5×127.5，按新版素材等比适配。面碗仍使用275×228的原适配框。
- 煮面锅三档画布与漏勺放大20%；豆皮锅三档使用441.6×344.4适配框，食物覆盖、切线与交互同步。前排原料略调位置，三级锅的抬高机械件可自然投影到桌面后沿上方，底座位于桌面内。
- 新版小料／生面盘、蛋酒盘、带把手豆皮备货盘及金币盘位于`resource/art/Wuhan/Trays_v2/`。移除旧托盘按横条分段拉伸的绘制方法，改用实际可见轮廓等比显示。盘内食物依据实际盘底位置排布，蛋酒维持原杯体尺寸、原库存规则。
- 金币盘在工作台局部坐标(1536,90)，设计显示体量沿用250×86、缩放0.9，完整托盘距右侧斜边至少20设计像素。位置由场景统一维护；钱堆、飞币与收钱反馈使用盘内区域。
- 共享`CoinTrayView`新增导出属性`CoinSurface`。默认区域仍为(26,16,198,52)，天津沿用默认；武汉配置(35,23,180,35)，硬币布局和缩放随区域适配。收入、付款次数累积、结算及存档未改变。
- 工作台点击判断覆盖上提后的漏勺轮廓，解决放大后二级漏勺上提越出原控件边界、无法继续拖入面碗的问题。

## 素材与复现

内置imagegen生成，绿底源图和实际提示词保存在[素材目录说明](../resource/art/Wuhan/Trays_v2/README.md)。按项目规则先生成绿底，再使用`tools/prepare_wuhan_trays.ps1`输出透明PNG。脚本只对与画布边界相连的高饱和绿色及轮廓边缘去绿，保留内部青绿装饰；透明像素RGB也清零。旧素材未覆盖。

首批素材的横长比例未用于小料、蛋酒或豆皮盘；其中一张横长版本用作金币盘。其他三种重新生成合适物理宽深比例，未通过非等比缩放补救透视。
