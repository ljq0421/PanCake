# 共用教学保护与语言切换

## 运行边界

正式版和 Demo 复用 `GameTranslation`、`JourneySettings`、`TutorialProtection`、`DayController` 与煎饼工作台保护代码。是否启用 Demo 只决定内容、开放范围、独立教学编排及保存位置，不再决定能否使用翻译与保护能力。

## 教学保护

- `DayConfig.Tutorial` 默认是 `TutorialProtection.None`。现有普通营业配置没有新增保护，耐心、收入与焦糊规则沿用原配置。
- `DayController.TryPrepareTutorial(cityId, day, catalog, out error)` 使用对应版本的关卡准备独立示范：取首个订单作为示例、安排在时刻 0 出现；冻结营业及耐心计时，保留入场／离场动画，示例收入不进入营业账本。
- `TutorialProtection.GuidedExample` 提供上述计时、收入保护和煎饼防焦。煎饼工作台从 `DayConfig.Tutorial` 初始化；独立示范的调用者将 `controller.Tutorial` 交给工作台。保护会等待加蛋，并将两面分别停在成熟状态。
- 也可以通过关卡 `tutorial` 配置分别设置 `freezeBusinessClocks`、`protectPancakeHeat`、`suppressRevenue`。仅防焦不视为独立示范，不阻止普通营业结算。普通营业重新初始化时恢复该关卡自己的策略。
- 天津 Demo 的开始／跳过／重试／完成提示和记录保存仍是 Demo 编排。此次没有自动给正式版增加相同的开场教学，也没有改动其他城市既定教学流程。扬州的独立营业控制器保持原实现。

## 语言

- 两种运行配置都在设置中提供简体中文／English。共用翻译资源位于 `Data/Localization/en.json`，中文直接使用原文，未翻译文案保留原文。
- 当前英文覆盖首批 Demo 涉及的首页、设置、天津及主要账本文案；不代表正式版全城市已完成翻译。
- 正式版设置仍保存到 `user://journey_settings.cfg`，Demo 设置仍保存到 `user://demo/journey_settings.cfg`，避免两种运行互相覆盖偏好。游戏存档位置也保持独立。
- 导出预设已包含 `Data/Localization/*.json`。添加新的导出预设时也应包含此目录。

## 验证入口

- `SharedTeachingSelfTest`：使用正式版数据验证独立示范、关卡配置保护、示例交付无收入、退出后恢复普通焦糊及四城普通计时。
- `StartScreenSelfTest`：正式版实际按钮切换语言、设置重读、未翻译原文回退及中文恢复。
- `DemoTutorialSelfTest`、`DemoUiSelfTest`：原 Demo 教学与语言流程回归。
