# 一、全局统一规范（所有素材通用）

## 1）统一画风要求

所有营业结算页相关素材，统一遵循：

* 二维、扁平、圆润、粗描边
* 大色块、低细节、强卡通化
* 温馨、轻松、治愈、模拟经营感
* 不写实，不做照片感，不做真实UI软件面板感
* 不要复杂材质
* 不要真实纸纹、木纹、金属纹、布纹
* 不要复杂高光、反射、景深、噪点
* 不要强烈体积光、电影光照
* 不要真实办公软件窗口感

## 2）统一配色建议（天津首版）

建议以**账本暖色系**为主，兼顾早餐铺温度感：

* 奶油米白
* 浅暖棕
* 深棕描边
* 柔和金色 / 浅金币色
* 少量暖红棕点缀
* 少量低饱和绿色 / 橙色 用于状态区分

## 3）通用技术建议

* 绝大多数素材建议：**透明背景 PNG**
* 程序文字尽量后期排版，不直接画死在素材里
* 带“标题/按钮/指标”的素材，尽量**做底板或图标，不要把文案写死**
* 这样天津、武汉、西安都能复用
