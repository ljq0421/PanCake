画布尺寸严格为 **1920×1080，16:9 横向构图**。

【最高优先级画风要求】

画面必须是**明显的二维卡通休闲游戏美术**。

必须明显区别于现实照片、半写实插画、写实游戏美术和3D渲染。

整体呈现：

**二维、扁平、圆润、粗描边、大色块、低细节、玩具化、图标化、强卡通化。**

所有物体必须经过明显的几何简化：

- 圆润造型
- 比例略微夸张
- 简单轮廓
- 大面积纯色块
- 每个物体最多约2～4个主要颜色层级
- 只保留一眼能够识别的关键结构
- 不追求真实结构
- 不追求真实比例
- 不追求真实材质

使用统一、清晰、略粗的深色卡通描边。

阴影只允许一层简单块状阴影或非常轻微的柔和阴影。

禁止：
真实金属反光、真实木纹、真实墙面纹理、真实油污、真实食物纹理、摄影景深、电影光照、环境反射、体积光、复杂渐变、复杂高光、高精度机械结构、PBR材质、3D模型感、半写实人物。

【视角】

使用**轻微俯视的3/4卡通视角**。

透视需要简单、稳定、容易读图，不要强纵深，不追求真实空间透视。

整个画面更像经过设计的二维模拟经营游戏操作界面，而不是现实早餐店场景插画。

【配色】

使用温暖明快的卡通配色：

奶油米黄、暖木色、柔和橙黄、浅砖红、浅绿色。

避免大面积灰黑金属色。

避免复杂综合色彩。

【场景】

表现一个高度卡通化的天津街边早餐铺主工作区。

中央是最大的**圆形卡通煎饼炉**，作为绝对视觉中心。

左侧是明显更小的**卡通油条炸锅**。

右侧是很小的**成品豆浆托盘**，不是豆浆机。

周围只出现少量经过高度简化的鸡蛋、薄脆、香葱、火腿、酱料。

后方出现一名等待早餐的卡通顾客。

背景只用少量简单墙面、窗户、木结构和挂饰营造天津街边早餐铺氛围。

背景弱化，不抢工作台视觉焦点。

设备之间保留明显留白，不要堆满。

不要文字、数字、Logo、水印。

最终效果必须让人第一眼确认：

**这是一款二维、简约、强卡通化的休闲模拟经营游戏，而不是现实早餐店插画。**

# 《早餐铺子》统一UI画风要求

UI必须与天津章节二维卡通美术协调，但不依赖任何未定义的UI参考图。

整体为：
二维、扁平、圆润、简约、粗描边、大色块、低细节。

主色使用：
奶油米白、暖黄色、浅橙色、暖棕色，少量浅绿色和浅红色作为状态提示。

UI边框使用统一的深暖棕色粗描边。

圆角明显，造型柔和。

每个UI元素最多使用2～4个主要颜色。

阴影最多使用一层简单的向下偏移阴影。

禁止：
玻璃拟态、透明玻璃效果、金属效果、真实材质、高光反射、复杂渐变、3D按钮、浮雕效果、复杂花纹、写实阴影。

UI必须像二维休闲模拟经营游戏界面，而不是手机App界面或写实餐饮软件。

缩小到游戏实际显示尺寸后仍然必须清晰易读。
