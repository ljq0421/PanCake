# 煎饼铺玩法与操作说明

> 项目：Project Cake  
> 章节：第一章 · 清晨煎饼铺  
> 整理日期：2026-09-01  
> 当前口径：四区单鏊正式运行时

## 1. 一句话概括

煎饼铺是一款以鼠标手工摊煎饼为技巧核心、以多个设备同时运转为经营压力、以日结升级改变劳动结构的 PC 街头小铺经营游戏。

玩家最初只经营一口鏊子，亲手完成倒面、摊面、翻面、加料和打包；随着成长，逐步解锁油条、现磨豆浆和成品饮品，在同一张工作台上同时处理生产、库存、顾客耐心、交付与收款。

## 2. 核心体验

### 2.1 手工制作

煎饼不是点击按钮等待进度条完成。玩家的鼠标轨迹会直接影响饼皮的：

- 覆盖范围；
- 平均厚度；
- 厚薄均匀度；
- 破洞和不规则边缘；
- 正反两面火候；
- 最终品质与顾客反馈。

### 2.2 同屏调度

四个区域会同时出现在同一工作台上：

1. 煎饼区；
2. 油条区；
3. 现磨豆浆区；
4. 成品饮品区。

玩家需要在单鏊煎饼、炸锅成熟窗口、豆浆接杯、饮品库存和多个顾客之间不断切换注意力。

### 2.3 经营成长

每个营业日结束后，玩家用当天获得的金币购买配料、设备、暂存空间和自动化能力。升级不会增加第二口鏊子，而是减少重复劳动、提高设备吞吐量或增加容错，让后期重点逐步转向多设备经营。

## 3. 设计核心

- **单鏊长期约束**：煎饼区始终只有一口鏊子，成长不会增加第二或第三个鏊位。
- **操作留下结果**：鼠标轨迹、厚薄、火候和配方会反映在成品与评分中。
- **失误允许继续**：普通失误不会立刻强制重做，可以继续完成并接受品质损失。
- **反馈必须可理解**：结果会说明火候、配料、酱料或订单匹配的问题。
- **成长改变劳动结构**：自动化主要替代重复动作，但不会替玩家完成整套经营。
- **四区同时常驻**：不通过分页或弹窗切换生产线，经营压力来自同屏信息与注意力分配。

## 4. 完整营业循环

```text
5 秒开场备货
→ 顾客到店并生成订单
→ 制作煎饼或操作其他设备
→ 点击订单中的目标商品交付
→ 查看品质与订单反馈
→ 点击收款位硬币收款
→ 继续接待下一位顾客
→ 营业倒计时归零
→ 统一收取未领取款项
→ 查看日结
→ 购买成长内容
→ 下一日激活成长并重新备货
```

### 营业时间

- 每天开始有 5 秒备货窗口。
- 第 1 日教学单不消耗营业倒计时，也不能被拒绝。
- 教学完成或跳过后，第 1 日正式营业时间为 60 秒。
- 第 2 日及以后为 120 秒。
- 剩余 10 秒时显示打烊提示。
- 倒计时归零后立即日结，不允许延时完成当前订单。

## 5. 四个工作区

| 区域 | 主要内容 | 操作重点 | 经营压力 |
| --- | --- | --- | --- |
| 煎饼 | 单鏊、面糊、秘制酱料及成长配料 | 倒面、摊面、火候、配方、打包 | 单件制作时间长，品质维度多 |
| 油条 | 四格炸锅、油条面胚、成品盘，后期双篮与鸡排 | 装胚、启动、升篮、沥油、收纳 | 整批共享计时，错过窗口会衰减或焦糊 |
| 现磨豆浆 | 空杯堆、豆浆机、加糖罐，后期自动和双口 | 取杯、控制接杯量、加糖 | 少接会降低收益与口碑，双口增加并行选择 |
| 成品饮品 | 果汁货架与库存 | 长按补货、按订单交付 | 制作简单，但会占用金币和库存注意力 |

## 6. 煎饼操作流程

### 6.1 倒面

1. 点击面糊勺拿起工具。
2. 在空鏊面按住鼠标左键。
3. 系统完成一次定量倒面。

### 6.2 摊面

1. 点击摊饼器。
2. 在鏊面按住左键并移动。
3. 围绕鏊心画圈，把面糊从内向外摊开。

摊饼轨迹按鼠标移动距离采样，而不是按画面帧数采样，因此相同轨迹在不同帧率下应产生近似结果。

### 6.3 鸡蛋与第一面火候

- 订单需要鸡蛋时，点击鸡蛋容器加入一份。
- 加入鸡蛋后继续使用摊饼器摊开蛋液。
- 观察火候提示，在适合的时间点击主操作按钮“翻面”。
- 过早、过晚或局部火候不均都会降低品质。

### 6.4 加料与补货

- 短点击已解锁且有库存的配料容器，加入一份配料。
- 配料由系统放到固定位置，不需要拖到鏊面。
- 原地长按配料容器约 0.20 秒进入补货。
- 补货逐份扣费，库存满或金币不足时自动停止。
- 面糊和秘制酱料为无限量，不进入普通付费补货。

当前可成长解锁的主要煎饼配料包括：

- 鸡蛋；
- 薄脆；
- 香葱；
- 肉松；
- 火腿；
- 香菜；
- 炸好的油条。

### 6.5 刷酱

- 翻面后点击秘制酱料源。
- 系统自动完成一次均匀刷酱。
- 不需要拿起酱刷手动画轨迹。
- 双份酱料订单需要按订单份数执行。

### 6.6 打包

- 点击主操作按钮“打包”。
- 系统自动完成两侧折叠。
- 煎饼自动装入纸袋并进入可交付状态。
- 当前版本不提供手动抓边折叠。

### 6.7 交付

- 点击目标顾客订单卡中的煎饼商品。
- 如果只有一张可用煎饼，系统直接交付。
- 如果暂存盘中有多张煎饼，先选择成品，再点击订单目标。
- 一次点击只交付一份，不会自动交给其他顾客。

## 7. 油条区操作

### 7.1 基础流程

```text
长按油条机加入面胚
→ 装入 1～4 根
→ 点击启动
→ 等待炸制
→ 成熟时点击升篮
→ 自动沥油 2 秒
→ 点击任意油条，将整篮收入成品盘
→ 点击订单中的油条逐根交付
```

### 7.2 时间规则

- 基础炸制时间：10 秒。
- 成熟安全期：5 秒。
- 品质衰减期：10 秒。
- 衰减期结束后：焦糊。
- 沥油时间：2 秒。

整批油条共享计时和品质。成熟后不及时升篮，会先持续掉品质，最后整批焦糊。

### 7.3 收纳与废弃

- 沥油完成后，点击任意一根油条会尝试把整篮收入共享成品盘。
- 成品盘空间不足时，整批保持原状，不会只移动一部分。
- 成品盘中的油条按订单逐根交付。
- 油条也可以作为煎饼配料。
- 焦糊的整锅炸物可以投入站内废弃区。

### 7.4 成长

- 高级油条机提供可开关的自动升篮。
- 双篮炸锅增加第二条炸物产线，并解锁炸鸡排。
- 油条和鸡排属于同一区域，但订单交付严格匹配具体商品，不能互相替代。

## 8. 现磨豆浆区操作

### 8.1 基础流程

1. 点击杯堆，把一个空杯放到出浆口。
2. 按住出浆口接豆浆。
3. 按住约 0.8 秒可以接满。
4. 购买加糖罐后，可先选择杯子，再点击糖罐加糖。
5. 点击订单中的豆浆商品交付。

### 8.2 接杯品质

- 接满：正常品质和收益。
- 提前松开：形成未接满豆浆。
- 未接满豆浆仍然可以交付，但收益与口碑会降低。

### 8.3 糖量

- 0 份：无糖；
- 1 份：正常糖；
- 2 份：多糖。

### 8.4 成长

- 中级豆浆机：从按住接浆变为点击自动接满。
- 高级豆浆机：提供左右双出浆口，可以分别接满或同时接满两杯。

## 9. 成品饮品区操作

- 当前商品为果汁。
- 果汁没有加工过程。
- 在货位上原地长按即可补货。
- 每补一瓶都会消耗金币。
- 有库存时，点击订单中的果汁商品即可交付。
- 该区域的主要压力来自库存、补货时机和资金占用。

## 10. 订单与顾客

- 工作台最多维持 3 名顾客的队列。
- 订单既可以是单品，也可以是跨区域组合单。
- 未解锁的内容不会进入订单池。
- 已经解锁但库存为 0 的内容仍可能被顾客点单。
- 点击某个订单商品只服务对应顾客和对应商品。
- 同一区域的不同商品不会自动互相替代，例如油条不能代替鸡排。
- 玩家可以交付不完美或不匹配的成品，系统会继续结算并给出相应扣分。

## 11. 评分

### 11.1 煎饼评分维度

- 饼皮覆盖；
- 厚度与均匀度；
- 正反面火候；
- 鸡蛋状态；
- 酱料份数、覆盖与均匀度；
- 配料种类与份数；
- 订单匹配；
- 打包结构；
- 制作时间与顾客耐心。

### 11.2 配料评分规则

当前配料评分只比较：

- 订单要求的配料种类与份数；
- 实际加入的内容；
- 漏放、多放和意外加入的内容。

配料固定落点仍会被保存用于画面和诊断，但当前不会因为“放得靠边”而扣配料分，也不会产生“容易漏料”之类的负面标签。

### 11.3 等级

| 等级 | 分数 |
| --- | ---: |
| A | 85 分及以上 |
| B | 65～84 分 |
| C | 65 分以下 |

A 和 B 计入该区域的“合格”熟练度，A 级还会单独累计。

### 11.4 典型失误

| 失误 | 处理方式 |
| --- | --- |
| 饼皮厚薄不均、覆盖不足或破洞 | 允许继续制作，在结果中降低相应品质 |
| 第一面或第二面欠火、焦糊 | 允许继续，火候得分降低 |
| 漏配料、多配料或份数错误 | 指出具体缺少或多放的内容 |
| 未翻面直接交付 | 允许完成，但扣 12 分 |
| 制作时间过长 | 时间维度下降，顾客耐心也会形成压力 |

## 12. 金币、口碑与熟练度

### 12.1 金币

- 完成订单获得金币。
- 煎饼价格会随配料增加。
- 补货消耗金币。
- 成长项目在日结时购买。
- 豆浆接杯品质会影响豆浆子项收益。

### 12.2 收款

- 顾客完成结算后，硬币先出现在收款位。
- 点击硬币后，金币正式计入可用资金。
- 打烊时仍未领取的款项会被统一收取，不会丢失。

### 12.3 口碑

| 订单表现 | 口碑变化 |
| --- | ---: |
| 全部商品为 A | +4 |
| 全部商品为 A 或 B | +3 |
| 订单中含 C | +1 |
| 订单失败 | -2 |
| 未开始制作即拒绝 | -1 |

### 12.4 区域熟练度

每个区域分别记录合格订单数和 A 级订单数，并形成未评级、铜、银、金四个阶段。

- 煎饼铜牌：8 单合格、其中 2 单 A。
- 其他区域铜牌：4 单合格、其中 1 单 A。
- 通用银牌：20 单合格、其中 8 单 A。
- 通用金牌：50 单合格、其中 25 单 A。

## 13. 每日目标

每天可能出现不同经营目标，例如：

- 完成 3 份 A 级煎饼；
- 完成 4 份至少 B 级且没有焦糊的油条；
- 完成 4 杯至少 B 级且没有浪费的豆浆；
- 完成 4 份至少 B 级的成品饮品；
- 完成 2 个组合订单且不能出现失败。

完成目标后会获得额外金币和口碑。

## 14. 成长内容

### 14.1 生效规则

- 只能在营业结束、进入日结后购买成长。
- 购买时立即扣除金币。
- 当天购买的内容在下一营业日统一生效。
- 新解锁的库存从 0 开始，需要重新备货。

### 14.2 煎饼成长

| 类别 | 内容 | 主要作用 |
| --- | --- | --- |
| 配料 | 鸡蛋、薄脆、香葱、肉松、火腿、香菜 | 增加订单组合和售价，也增加配方与库存压力 |
| 自动化 | 一键打蛋、定量面糊勺、压饼器 | 减少重复手工动作 |
| 鏊子能力 | 不会糊的鏊子、快熟鏊子 | 增加容错并提高生产速度 |
| 暂存 | 煎饼暂存盘 | 可以提前制作成品，但不会增加鏊子数量 |

### 14.3 其他区域成长

| 区域 | 成长内容 |
| --- | --- |
| 油条 | 油条炸锅、共享成品盘、高级自动升篮、双篮炸锅与鸡排 |
| 豆浆 | 初级豆浆机、加糖罐、中级自动接满、高级双口 |
| 成品饮品 | 果汁成品饮品架 |

### 14.4 代表价格

| 阶段 | 成长价格 |
| --- | --- |
| 煎饼配料 | 鸡蛋 10；薄脆 30；香葱 50；肉松 80；火腿 80；香菜 50 |
| 煎饼减负 | 一键打蛋 60；定量面糊勺 120；压饼器 120；不会糊鏊子 180；快熟鏊子 240；暂存盘 40 |
| 油条 | 油条炸锅 200；成品盘 50；高级油条机 250；双篮炸锅 350 |
| 豆浆 | 初级豆浆机 200；加糖罐 50；中级豆浆机 250；高级豆浆机 350 |
| 成品饮品 | 成品饮品架 200 |

实际购买还会受到前置成长和区域解锁条件限制，成长工坊会显示当前缺少的条件。

## 15. 操作速查

| 输入 | 作用 |
| --- | --- |
| 鼠标左键点击 | 拿工具、点击配料和按钮、选择成品、点击订单商品交付、点击硬币收款 |
| 左键按住并移动 | 在鏊面倒面或摊面 |
| 原地长按 | 补货；部分设备使用长按装入原料 |
| 松开左键 | 结束连续操作或补货；豆浆根据按住时间决定接杯量 |
| 鼠标右键 | 放回当前工具或取消当前动作 |
| `Esc` | 暂停或恢复游戏 |
| 方向键 / `Enter` | 开始页菜单选择和确认 |
| 数字键 `1`～`4` | 可选工具快捷键，不是必须操作 |

暂停期间，营业时间、顾客耐心和生产计时都会停止。

## 16. 新玩家第一日建议

1. 进入新游戏，确认开局只有煎饼区可用。
2. 跟随教学箭头完成第一次倒面和摊面。
3. 教学期间不消耗营业时间，可以用来熟悉工具和鏊面位置。
4. 先保证订单配方正确，再追求高品质和制作速度。
5. 教学结束后的 60 秒内，优先完成能够及时交付的订单。
6. 顾客付款后及时点击收款位，但临近打烊时可先处理关键生产。
7. 日结时购买成长，并注意它要到下一日才生效。

最重要的上手思路是：先把一张煎饼的固定节奏练顺，再逐步解锁其他区域。四区全部开放后，真正稀缺的是玩家的注意力，而不是点击速度。

## 17. 当前实现边界

- 正式基线为四区单鏊，不存在第五设备区。
- 成长不会增加第二个鏊子。
- 手动刷酱已经退休，当前为点击后自动刷匀。
- 手动折边已经退休，当前为点击打包后自动折叠装袋。
- 生配料不支持拖入鏊面，当前使用短点击固定落点加入。
- 新游戏不自带鸡蛋、薄脆和香葱，所有付费配料均需成长解锁。
- 当前存档会保存活动订单、顾客状态、生产快照、金币、成长和库存。
- 高频营业状态采用约 2 秒的合并写盘窗口，退出时会立即刷新待保存内容。

## 18. 当前验证状态

项目已经配置自动检查、GPU 交互检查和发布门禁，可以验证逻辑、场景、存档与基础交互合同。

以下内容仍需真人按照当前四区基线实际试玩后确认：

- 连续制作 20 张煎饼的手感；
- 连续操作约 10 分钟后的手腕、手指和视线疲劳；
- 1920×1080、1366×768、1280×720 下的真实操作；
- 四区全开、3 名顾客同时存在时的信息辨识度；
- 误触率、目标辨识度和音效听感。

在真人验收单完成前，只能说明自动检查和运行时合同已经具备，不能宣称操作手感已通过真人验证。
