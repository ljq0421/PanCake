# 煎饼工作台画风与布局执行规范

> 状态：当前四区单鏊工作台的视觉与布局基线。  
> 目标版本：Godot 4.7.1，基准视口 1920×1080。  
> 适用场景：`res://scenes/gameplay/four_area_workstation.tscn`。  
> 规则优先级：若本文与 `docs/four_area_workstation_runtime.md` 或当前运行时实现冲突，以运行时合同和实现为准。

## 1. 目的与范围

本文用于指导当前四区工作台的布局调整、素材重绘、UI 重排和人工验收。

本次改版只解决以下问题：

1. 全解锁后缺少稳定的视觉层级；
2. 设备、托盘和食材的透视不统一；
3. 工作站边界不清，物件像被逐个塞进剩余空位；
4. 顶部 HUD、订单卡和顾客互相争抢空间；
5. 机器、库存和场景纹理的颜色同时过于突出；
6. 状态文字漂浮，无法快速判断它属于哪个设备；
7. 重复库存逐件陈列，解锁越多画面越拥挤。

本文不修改生产规则、订单规则、评分规则、成长规则或存档合同，也不新增第五区域、第二个鏊位或新的设备位。

## 2. 已冻结的运行时事实

布局和美术不得破坏以下现有规则：

- 固定四区：煎饼、油条、现磨豆浆、成品饮品；
- 煎饼区只有一个鏊位；
- 同屏最多 5 位顾客；
- 基准视口为 1920×1080；
- 拉伸模式为 `canvas_items`，宽高比策略为 `expand`；
- 面糊和摊饼器需要鼠标按住或移动，其余生配料主要通过点击容器加入；
- 可补货容器支持原地长按，生配料长按判定为 0.20 秒；
- 玩家通过顾客订单卡中的商品图标完成交付。

四区是并列的营业能力，不是“炸制 → 煎制 → 配料 → 饮品”的强制流水线。视觉上可以从左到右组织，但不得让玩家误以为所有订单都必须经过全部设备。

## 3. 体验目标与视觉优先级

玩家进入全解锁界面后，应在 3 秒内完成三件事：

1. 找到当前最紧急的顾客或订单；
2. 判断该订单对应哪个工作站；
3. 看清当前设备状态和下一步可执行动作。

视觉优先级固定为：

| 等级 | 内容 | 规则 |
| --- | --- | --- |
| L+ | 当前订单、当前食物、当前交互反馈 | 同一时刻最多一个 L+ 焦点 |
| L | 煎饼鏊台与正在制作的煎饼 | 长期核心操作区 |
| M+ | 油条炸锅、现磨豆浆机 | 独立计时生产线 |
| M | 成品饮品、包装和出餐托盘 | 辅助与交付内容 |
| S | 配料容器、杯子、工具、库存数量 | 不得与机器争夺视觉中心 |

静态设备不能比当前订单和当前食物更醒目。视觉中心应随玩家任务变化，而不是永久锁定在某台机器上。

## 4. 1920×1080 屏幕布局

### 4.1 安全区

- 左右安全边距：32 px；
- 顶部安全边距：20 px；
- 关键控件之间的最小间距：16 px；
- HUD、订单卡和顾客之间不得发生不可控遮挡；
- 背景和装饰可以延伸到安全区之外，交互内容不得超出安全区。

### 4.2 垂直分区

| 分区 | 建议范围 | 高度占比 | 内容 |
| --- | --- | ---: | --- |
| 常驻 HUD | Y=20～82 | 约 6% | 金币、营业日、口碑、倒计时、当前结算摘要 |
| 订单卡 | Y=92～252 | 约 15% | 5 个固定订单槽位 |
| 顾客区 | Y=238～650 | 约 38% | 顾客、耐心和必要反馈 |
| 工作台 | Y=650～1080 | 约 40% | 四区设备、原料、工具和出餐内容 |

订单卡与顾客区可以轻微重叠以保持归属关系，但订单卡不得进入 HUD 的可视范围。工作台顶部边缘保持稳定，不因解锁数量改变。

### 4.3 五个顾客槽位

5 个槽位始终存在，中心位置按安全区等分。每个槽位包含：

```text
订单卡
  ↓
顾客
  ↓
耐心/状态
```

规则：

- 所有订单卡位于同一基准 Y 轴；
- 所有顾客脚底位于同一基准 Y 轴；
- 少于 5 位顾客时保留空槽，不临时放大其余人物；
- 人物建议较当前全解锁截图缩小 8%～10%；
- 当前选中顾客使用金色描边或底部光带，其他顾客保持正常饱和度；
- 不使用大面积半透明遮罩区分顾客，以免遮住人物表情和服装。

## 5. 工作台四区布局

### 5.1 水平分区

| 区域 | 建议宽度 | 主要内容 | 定位 |
| --- | ---: | --- | --- |
| A 油条区 | 24% | 炸锅、面胚入口、油条成品盘 | 左侧独立计时支线 |
| B 煎饼区 | 27% | 单鏊、面糊、摊饼器、主操作按钮 | 核心操作区 |
| C 配料与出餐区 | 31% | 鸡蛋、薄脆、肉类、酱料、葱花、香菜、包装、暂存盘 | 高频输入与交付区 |
| D 饮品区 | 18% | 现磨豆浆机、杯子、成品饮品库存 | 右侧独立饮品支线 |

区域宽度允许在视觉调整中浮动 ±2%，但不得通过不断缩小交互物来塞入新内容。

### 5.2 区域内部秩序

每个区域优先遵循：

```text
上层：输入或库存
中层：设备或主要操作面
下层：成品、包装或状态
```

具体规则：

- 油条成品盘贴近炸锅下方，不跨到煎饼区；
- 面糊、摊饼器和主操作按钮围绕鏊台布置，不进入配料矩阵；
- 生配料与调味料形成两个清晰模块，不拆成十几个无分组小盘；
- 包装袋、暂存盘和交付物放在配料区下层；
- 豆浆杯与现磨豆浆机保持同组；
- 成品饮品使用紧凑库存盘，不再逐盒铺满右下角；
- 废弃篓位于煎饼区与配料区之间的下缘，使用固定槽位，不作为漂浮物件。

### 5.3 区域分隔

不增加厚重边框。优先采用以下弱分隔方式：

- 同材质浅色桌垫；
- 设备或托盘的自然边界；
- 16～24 px 的稳定间距；
- 极轻的局部明暗变化。

分区必须能在灰度截图中被看懂，但不能把工作台切成四个独立面板。

## 6. 现有物件的首轮比例调整

以下数值均以当前全解锁截图为基线，只用于第一轮排版，不与其他缩放规则重复叠加。

| 物件 | 首轮调整 | 目的 |
| --- | --- | --- |
| 煎饼鏊台 | 整体缩小 8%～10% | 给工具、配料和废弃篓留出呼吸空间 |
| 鏊面 | 保持最大有效操作面，不随外壳同比过度缩小 | 保证摊饼操作精度 |
| 油条炸锅 | 外轮廓缩小不超过 8%，正面面板高度减少 10%～15% | 让炸篮和食物成为重点 |
| 现磨豆浆机 | 高度减少 15%～20%，宽度减少 5%～10% | 降为辅助设备，避免遮挡顾客 |
| 顾客人物 | 整体缩小 8%～10% | 为订单卡和墙面留白 |
| 食材容器 | 关键容器可放大 5%～8% | 提高点击辨识度 |
| 杯子、工具 | 保证交互范围，不通过视觉缩小解决拥挤 | 降低误触 |

完成首轮布局后必须重新截图评估，不自动执行第二轮相同比例缩放。

## 7. 透视与绘制规范

### 7.1 固定视角

工作台物件统一采用正面 30°～35°俯视的伪 3D 卡通视角：

- 能看见物体顶部和少量正面；
- 不出现强侧面；
- 同类容器的顶部压缩比例一致；
- 人物继续保持正面视角，不强行套用台面透视。

圆形水平顶面的基准椭圆比例为：

```text
短轴高度 ÷ 长轴宽度 = 0.36 ± 0.02
```

该比例应用于锅、碗、杯口、机器顶盖和圆形托盘。若为了识别性需要偏离，必须在同类组件中统一偏离，不能逐张素材自由调整。

### 7.2 母版素材

正式重绘前先制作并确认 4 个透视母版：

1. 圆形锅或盘；
2. 长方形金属托盘；
3. 带顶部和正面的机器；
4. 杯子或圆筒容器。

后续素材必须从母版推导，不直接以旧素材各自的角度为准。

### 7.3 光线、描边与阴影

- 主光源固定来自左上方；
- 高光方向保持一致；
- 机器外轮廓建议 4～6 px；
- 小型食材和工具建议 3～4 px；
- UI 边框建议 2～3 px；
- 阴影使用暖灰棕，避免纯黑；
- 同一高度的容器使用相近的阴影长度和模糊程度。

## 8. 设备画风规范

### 8.1 煎饼鏊台

- 鏊面从近纯黑调整为暖炭灰，基准色 `#36332F`；
- 锅沿略偏暖，并提供一圈克制高光；
- 鏊面保留轻微明暗和使用纹理，不能是一整块均匀黑色；
- 外壳、旋钮和指示灯降低对比度；
- 当前火候和制作状态贴近设备显示，不在人物区漂浮。

### 8.2 油条炸锅

- 保留双炸篮的识别特征；
- 减少正面机箱高度和控制面板视觉重量；
- 炸篮、油面和正在制作的食物比旋钮、灯和外壳更醒目；
- 成品油条全部进入统一成品盘，不散落在桌面上；
- 计时和过火提示固定附着在炸锅区域。

### 8.3 现磨豆浆机

- 主体由高饱和绿色改为米白、低饱和豆绿和金属灰组合；
- 豆绿色建议以 `#7FA784` 为基准，再按场景光照调整；
- 高饱和绿色只用于运行或完成反馈，不用于整台机器；
- 出浆口、杯位和完成状态比装饰铭牌更明显；
- 机器不得遮挡第 5 位顾客的主体或订单卡。

### 8.4 成品饮品库存

- 不逐盒展示真实库存数量；
- 使用 4～6 个代表物表达品类；
- 真实数量使用角标；
- 空库存显示空托盘和缺货标识；
- 成品饮品与现磨豆浆保持视觉区分，但共享容器角度、描边和光照规范。

## 9. 容器组件库

只保留三类基础容器。实际尺寸允许按内容比例微调，但不得新增无规范尺寸。

| 级别 | 参考尺寸 | 用途 |
| --- | --- | --- |
| S | 96×76 px | 酱料、葱花、香菜、小型调味 |
| M | 176×96 px | 鸡蛋、肉类、薄脆、杯子 |
| L | 288×120 px | 成品、包装、油条、饮品库存 |

所有容器统一：

- 顶部透视比例；
- 圆角半径；
- 3～4 px 描边；
- 金属或陶瓷材质语言；
- 左上高光和右下阴影；
- 内容距容器边缘至少 10 px；
- 空、正常、偏低、缺货四种状态。

## 10. 库存与内容密度

当前运行时通过点击容器使用生配料，因此库存不需要逐件精确陈列。

统一规则：

- 正常库存：展示 3～5 个代表物和数量角标；
- 偏低库存：展示 1～2 个代表物、黄色角标和补货提示；
- 缺货：保留空容器、`0` 数量和清晰缺货图标；
- 无限库存：不显示虚假数量，使用无限标记或省略数字；
- 正在消耗时只播放一次局部减少反馈，不让容器整体跳动；
- 解锁增加时不通过增加桌面实物数量表达成长。

需要保留逐件表现的内容，只限于真正独立占用设备槽位或能够被玩家分别取出的成品。

## 11. 配色系统

### 11.1 色彩职责

| 职责 | 建议基准色 | 用途 |
| --- | --- | --- |
| 场景奶油色 | `#F3D9AB` | 墙面、暖色基础 |
| 木色 | `#B9783E` | 工作台、结构木件 |
| HUD 深墨绿 | `#17342F` | 常驻顶部 UI |
| 面板米白 | `#F7E8C6` | 订单卡、信息卡 |
| 设备米白 | `#E6DDD0` | 机器主体 |
| 设备豆绿 | `#7FA784` | 机器局部和正常状态 |
| 铁锅炭灰 | `#36332F` | 鏊面和深色金属 |
| 当前操作金黄 | `#F1B63C` | 选中、当前任务、完成奖励 |
| 警告珊瑚红 | `#D75B49` | 过火、缺货、错误 |
| 成功绿 | `#4D9875` | 完成、可交付、正常状态 |

### 11.2 使用规则

- 场景和设备承担低饱和背景；
- 食物保留最高饱和度；
- 人物服装可以保持多样颜色，但当前顾客通过描边或底光区分，不整体改色；
- UI 深色只用于顶部常驻栏和必要弹层，不铺满顾客区；
- 同一状态在全界面使用同一颜色；
- 警告和完成不得只依靠颜色，还要配合图标、文字或声音。

## 12. 工作台背景

- 木纹对比较当前全解锁截图降低约 20%；
- 减少细碎线条，保留较大的木纹块面；
- 工作台中心可比左右边缘亮 3%～5%；
- 边缘允许轻微压暗，但不能形成明显黑色晕影；
- 设备下方阴影用于落地，不用于制造额外装饰细节；
- 顾客背后的墙面保留留白，不继续增加高对比装饰。

## 13. 顶部 HUD 与状态信息

### 13.1 信息等级

| 等级 | 内容 | 展示方式 |
| --- | --- | --- |
| 一级常驻 | 金币、营业日、口碑、倒计时 | 固定在顶部单行 HUD |
| 二级任务 | 当前订单、结算摘要、关键操作结果 | 紧凑卡片，可展开查看详情 |
| 三级提醒 | 缺货、库存满、过火风险、设备完成 | 就近提示，并进入提醒轨道 |

### 13.2 HUD 布局

顶部只保留一行主栏：

```text
左：金币 / 营业日 / 口碑
中：营业倒计时
右：当前订单或最近结算摘要
```

规则：

- 主栏高度建议 56～62 px；
- 右侧摘要收起时不超过 420×62 px；
- 展开详情时使用独立弹层，不向下覆盖订单卡；
- “材料库存已满”不得长期占据整条横幅；
- “当前无风险”使用小型正常状态图标，不显示大段文字；
- 真正风险出现时才展开文字提醒；
- 临时消息消失后，可在最多 3 条的提醒轨道中查看近期状态。

## 14. 订单卡规范

### 14.1 尺寸和排列

- 固定 5 个槽位；
- 建议宽度 168～184 px；
- 建议高度 144～160 px；
- 卡片顶部、商品区、要求区和进度条使用相同结构；
- 所有进度条位于卡片底部同一位置；
- 卡片之间至少保留 16 px；
- 最左和最右卡片不得被屏幕边缘或顶部摘要裁切。

### 14.2 状态

- 默认：米白背景、棕色细描边；
- 当前选中：4 px 金色描边和轻微上浮；
- 耐心偏低：珊瑚红图标与文字，同时改变进度条样式；
- 可交付：商品图标出现一次完成反馈，并持续显示可交付标记；
- 已完成或离场：槽位清空，不保留残余进度条；
- 多商品订单优先展示 1～3 个主商品图标，详细要求在卡内展开或通过详情查看，不无限增高卡片。

## 15. 设备状态与交互反馈

所有状态必须附着在对应设备或容器上，不再使用无归属的漂浮文字。

| 状态 | 视觉 | 补充反馈 |
| --- | --- | --- |
| 默认 | 正常颜色和轮廓 | 无 |
| 悬停 | 亮度提高约 8%，出现轻描边 | 可显示简短名称 |
| 已选中 | 金色环或局部底光 | 工具状态文字贴近工作站 |
| 进行中 | 局部进度环或进度条 | 保留对应设备声音 |
| 即将完成 | 黄色预警 | 简短音效或图标 |
| 已完成 | 绿色完成标记 | 每次只播放一次完成动效和音效 |
| 风险 | 珊瑚红图标和明确文字 | 不依靠闪烁作为唯一提示 |
| 不可用 | 降低饱和度并显示原因 | 不完全隐藏已解锁设备 |

“油条·未开始”“火候·未开始”等状态应改为设备内的小标签。未开始且无需玩家处理时降低存在感；需要操作时再提升为 L+ 焦点。

## 16. 点击范围与可访问性

- 所有鼠标目标的有效范围至少为 56×56 px；
- 小图标可以小于 56 px，但必须由透明点击容器补足范围；
- 长按补货时，在目标周围显示 0.20 秒环形进度；
- 文字字号不得因内容增加而缩小到难以阅读；
- 小型库存数字建议不低于 22 px；
- 状态不得只用红、黄、绿区分，必须同时提供图标、文字或形状变化；
- 完成和警告音效必须不同，静音时仍能只靠画面完成全部操作；
- 连续闪烁只用于严重且短暂的警告，并提供非闪烁的持续标记。

## 17. 宽高比与缩放

核心布局以 1920×1080 安全矩形为准。

- 16:9：按基准比例缩放；
- 更宽屏幕：扩展背景，不横向拉散四区和顾客槽位；
- 更高屏幕：增加背景和工作台边缘，不扩大人物与设备；
- 1600×900 和 2560×1440 必须保持相同信息层级；
- 不允许通过非等比拉伸素材填满额外空间；
- 关键按钮、订单卡和设备状态不得因窗口变化进入裁切区。

## 18. 实施顺序

### P0：只改布局和可见性

1. 压缩顶部 HUD 为单行；
2. 建立 5 个统一订单槽位；
3. 缩小顾客并统一站位；
4. 按 24% / 27% / 31% / 18% 重排四区；
5. 把漂浮状态文字移动到对应设备；
6. 用数量角标替代橙汁、杯子、鸡蛋等重复库存陈列。

P0 不要求重画全部素材，应先验证空间秩序和操作路径。

### P1：设备和容器美术

1. 调整鏊面颜色与尺寸；
2. 缩小豆浆机并降低饱和度；
3. 压低炸锅正面面板；
4. 建立 S/M/L 容器组件库；
5. 统一透视母版、描边、高光和阴影；
6. 降低工作台木纹对比度。

### P2：状态与反馈

1. 接入悬停、选中、进行中、完成、风险和缺货状态；
2. 将临时提醒接入最多 3 条的提醒轨道；
3. 统一各区进度和完成反馈；
4. 完成静音条件下的可操作性检查。

### P3：分辨率与真人试玩

1. 截取空白、部分解锁和全解锁三类画面；
2. 检查 1920×1080、1600×900、2560×1440；
3. 真人鼠标分别完成四区商品；
4. 记录误触、视线往返、目标寻找时间和连续营业疲劳；
5. 只根据观察到的问题调整，不在验收阶段顺手新增功能。
