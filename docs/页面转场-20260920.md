# 首页、天津与武汉页面转场

用户确认：采用明显的手账翻页、幕布揭开效果；首页全部子页及两城营业、结算、返回、设置、升级、暂停等相关弹窗全部纳入。

## 实现

- 用户已采纳第二版柔软开合，并推广到约定范围的书页弹窗：设置、帮助、配乐署名及天津／武汉营业账本。中央书脊固定，打开向两侧舒展落平，关闭时外沿朝观察者抬起并向中央合拢；非线性曲面让页中与外沿依次舒展，总时长 520ms。`settings_book_fold.gdshader` 共用开合动作，首页与营业账本分别匹配各自的透明裁切和遮罩颜色；背景全屏连续合成，阴影沿书页轮廓变化。
- 首页设置样例的已确认动图保留在 `.tmp/settings-fold-preview/settings-spread-v2.gif`；`JourneyTransitionSelfTest --settings-fold-preview` 可重新采集实际视口开合帧。
- `JourneyTransition` 自动加载，单个 CanvasLayer 管理临时截图、Shader、Tween、输入拦截和独立暂停原因。
- 首页跨页使用 520ms 纸页卷折、暖色纸背与折边阴影；返回首页及从账本／升级返回章节使用反向翻页。同页存档刷新不重播。
- 天津、武汉进入或退出营业使用 720ms 双侧布帘：旧画面上合拢，完全遮挡后揭开新画面。布帘优先于目的页及弹窗动效，避免同一次切换叠播。
- 2026-09-20 最终确认：仅首页、天津、武汉的书页弹窗使用上述柔软开合，正式版与试玩版同步；此前横向卷页方案被替换。营业账本不同时淡入纸面，原有结算内容动画在书页展开后继续。
- 非书页的确认页、暂停菜单及界面教学保留 320ms 开合；账本升级入口和返回沿用已有翻页。原生 ConfirmationDialog 保留 220ms 淡入及截图合拢，以及窗口自身确认、取消、焦点规则。进出营业的幕布不变。
- 原营业结算数字累计、印章及账本内页动画保留。西安、广州、扬州营业页不接入本次弹窗动效；共享首页页面照常使用翻页。
- 截图只在转场开始时采集，结束后释放；不新增美术图片。窗口尺寸变化、失焦或减少动态效果启用时结束当前转场；headless 环境直接切换。
- 转场使用 `journey-transition` 暂停原因；教学重新准备营业时保留该原因，结束时仅释放该原因，不解除手动暂停或营业明细暂停。天津工作台同步读取控制器暂停状态。
