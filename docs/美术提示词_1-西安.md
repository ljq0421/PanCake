# 零、西安章节城市视觉DNA｜所有后续提示词最高优先级共同要求

以下规则适用于西安章节全部：

- 场景
- 工作台
- 设备
- 食物
- 容器
- 顾客
- UI
- 地图节点

除非某一单项提示词明确要求透明背景或必须与既有素材严格对齐，否则均默认继承本节。

## A｜与天津、武汉统一的内容

西安、武汉、天津必须明显属于：

**同一款《早餐铺子》、同一美术团队、同一世界尺度。**

统一保持：

- 二维
- 扁平
- 圆润
- 粗描边
- 大色块
- 低细节
- 玩具化
- 图标化
- 强卡通化
- 轻微俯视3/4卡通视角
- 深暖棕或统一深色卡通描边
- 每个物体约2～4个主要颜色层级
- 一层简单块状阴影或极轻微柔和阴影
- 相同NPC轻Q版比例
- 相同UI圆角语言
- 相同设备几何简化程度

禁止为了区分城市改变整个画风。

**城市差异只能来自：**

- 主色
- 几何轮廓
- 工作台布局
- 建筑语言
- 食物色块
- 环境氛围
- NPC服装配色
- 少量城市装饰

---

# B｜西安章节专属主色体系

西安不能继续复制天津：

**奶油黄＋暖木橙＋浅砖红**

也不能复制武汉：

**青绿＋米白＋蒸汽白**

西安环境主色使用：

- **麦穗米黄**
- **浅砂岩色**
- **城墙暖灰**
- **低饱和青砖灰**
- **柔和赭石**
- **暗枣红**

食物重点色使用：

- **白吉馍麦黄色**
- **烙馍金黄色**
- **腊汁肉暖褐红**
- **深酱褐色**
- **腊汁琥珀棕**
- **胡辣汤暖红褐色**

少量辅助色：

- 柔和橄榄绿
- 灰蓝
- 米白
- 深青灰

最终形成西安章节固定组合：

# **麦黄＋城墙灰＋暗枣红＋腊汁暖褐＋烙馍金黄**

不要把整个场景全部染成土黄色。

城墙灰和青砖灰用于平衡暖色。

暗枣红只作为：

- 遮雨棚
- 招牌边缘
- 窗框
- 工作台装饰
- 少量UI强调色

不要大面积通红。

---

# C｜西安章节专属几何语言

天津：

**大圆形煎饼炉＋横向开阔桌面**

武汉：

**左圆锅＋中央小圆碗＋右大方锅**

西安必须主动避开以上两种工作台剪影。

西安工作台结构固定为：

### 左侧

**低矮横向圆角长方形白吉馍炉**

视觉特点：

扁、宽、低。

---

### 中央

**大块厚实圆角长方形砧板＋肉夹馍组装区**

这是绝对视觉中心。

不要做成圆形。

中央应该明显表现：

**切、剁、夹**

的操作空间。

---

### 右侧

**较小圆形深锅胡辣汤区**

以及：

**预剁肉盘 / 腊汁肉锅**

整体视觉轮廓为：

# **扁长方炉＋大长方砧板＋小圆汤锅**

即使只看设备黑色剪影：

也必须明显区别于天津和武汉。

---

# D｜西安章节专属建筑语言

表现：

**现代西安街边早餐铺**

而不是：

唐代宫殿。

背景优先使用：

- 米白或浅砂岩墙面
- 少量青砖灰墙裙
- 暗枣红遮雨棚
- 简化深灰窗框
- 开放式早餐窗口
- 小板凳
- 简化储物架
- 极少量生活化挂饰

城市识别可以在：

**极远背景**

加入一小段：

**高度简化的西安城墙 / 城楼剪影。**

要求：

- 面积不超过背景视觉面积约5%
- 低对比度
- 高度图标化
- 不要成为视觉中心

禁止：

- 唐宫
- 大雁塔作为巨大主视觉
- 兵马俑陈列
- 满屏红灯笼
- 汉服店
- 古装街
- 旅游宣传海报
- 仿古宫殿早餐店

西安城市身份必须主要来自：

**早餐铺＋食物＋配色＋工作台结构。**

# E｜西安专属空气感

西安章节表现：

# **干爽、清晨、略带暖意、扎实、有烟火气。**

与武汉明显区别：

武汉：

湿润、青绿、蒸汽较明显。

西安：

干爽、麦黄、灰砖、蒸汽较克制。

允许：

- 胡辣汤锅上方1～2条简化白色蒸汽
- 清晨天空浅灰蓝 / 米灰色块
- 少量柔和暖黄色环境色块
- 极少量早餐摊热气

禁止：

- 真实尘土
- 沙尘天气
- 写实晨光
- 电影阳光
- 体积光
- 镜头光晕
- 强烈夕阳感

所有天气和空气感必须保持二维卡通表达。
