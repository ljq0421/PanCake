# 正式版音乐、教学重看与五卡收藏接入

本次将现有 Demo 功能接入正式版源码，未导出或发布新的安装包。

## 已接入

- 首页播放 Wholesome，天津播放 Carefree，武汉播放 Local Forecast - Elevator。两版共用播放器与场景路由，保留循环、1.2 秒切曲淡变、暂停/营业明细降至四分之一音量、失焦冻结及音乐音量控制。帮助页两版均显示配乐署名。
- 正式版天津、武汉准备页新增“重看首份教学”。分别使用正式第 1 天内容练习煎饼和热干面；不修改正式日配置。练习冻结营业时间与耐心、保护火候，不产生收入、关卡进度或收藏。完成或跳过后回到原本选择的正式营业日；完成练习后保存已学动作，保存失败可重试。
- 经营手账新增“旅途收藏”入口。复用煎饼、油条、豆浆、热干面、豆皮五卡与原交付品质规则；武汉卡随武汉城市开放显示。
- 合格部分交付先暂存，正常结算保存成功后正式入册，同时显示新收藏提示。金币、关卡进度与收藏原子提交；保存失败一起回滚。首次来源显示正式营业日，重复获得不覆盖来源。
- 正式 v3 存档新增可缺省的 BreakfastRecords 字段，旧档读取为空记录。旧档没有逐件交付证据，因此不倒推历史收藏。Demo 与正式存档仍独立。
- 正式营业计划生成独立 RunId，过期交付回执不能写入新一轮收藏。
- 收藏列表的英文长名称按可用宽度缩小，避免与入册状态相挤。
