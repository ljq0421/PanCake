# 新游戏工作台首屏审查

## 审查范围

- 画面：新游戏、教学第 1 步、工作台初始状态。
- 用户目标：快速理解订单，并完成第一次“拿起面糊勺 → 倒入面糊”的操作。
- 证据：`01-start.png`。

## 总体判断

当前的空旷感主要来自“首局内容密度”与“完整场景尺度”不匹配，而不只是装饰不足。订单、顾客、锅、调料和教学气泡被分散在宽屏画面的不同区域，玩家的视线需要多次跳转，主要操作区也没有形成足够强的视觉重心。

## 步骤 1：进入工作台并开始教学

健康度：需优化。

### 做得好的部分

- 场景风格统一，店铺背景、木质工作台和道具具有明确的经营氛围。
- 教学目标有高亮边框，第一步动作也有文字说明。
- 订单、顾客、烹饪工具与调料均已出现在首屏，不需要切页寻找。

### 主要问题

1. 结构性问题：早期只有一口锅和少量调料，却使用了适合后期多工位的完整横向场景，导致大面积空间没有功能。
2. 视觉重心分散：订单在上方、顾客在中部、锅在下方、调料和教学气泡偏右，缺少单一明确的任务轴线。
3. 信息竞争：左上状态提示、中央“教学中”、订单卡和右下教学气泡同时争夺注意力。
4. 操作区缺少容器：锅、调料、废弃篮和热度条像散落在桌面上，没有通过托盘、台垫或工位边界形成一个完整工作站。
5. 当前教学气泡较长，且与实际目标位置横向相邻，容易遮挡后续道具并压缩右侧空间。

### 优先建议

1. 首局采用“收紧舞台、逐步展开”：在教学与早期营业日只呈现中央约 60%–70% 的可用工作台；随着新设备解锁，再扩展左右工位。
2. 建立垂直任务轴：订单卡 → 顾客 → 锅/操作区，让玩家第一眼就能顺着同一中轴理解当前任务。
3. 将锅、调料和废弃篮组合进一个明确的操作台容器；调料放入托盘，热度与进度贴近锅体，减少漂浮感。
4. 把首步教学改成短指令和步骤状态，例如“1/3 拿起面糊勺”，把“倒入锅中”留到下一步；保留高亮与拖拽轨迹即可。
5. 对未来内容使用“关闭的柜门、遮布或低对比度的锁定工位”表达成长空间，而不是直接留白或堆满不可用按钮。
6. 装饰只补低对比度环境层，例如菜单板、挂巾、备料架和轻微蒸汽；不要让装饰看起来可以点击。

## 无障碍风险与验证缺口

- 从截图可见，浅黄色文字叠在明亮木纹上的区域可能存在对比度不足风险。
- 教学不能只依赖黄色描边表达目标，建议同时提供图标、文字和轻微动画提示。
- 仅凭截图无法确认键盘/手柄焦点、点击目标尺寸、动效减弱设置与读屏顺序，需要在运行时验证。

## 推荐落地顺序

- P0：收紧首局可视区域；重排订单—顾客—锅的中轴；缩短教学文案。
- P1：建立工作站容器；合并或弱化顶部提示；加入锁定工位的成长暗示。
- P2：补充低对比度环境装饰与轻量氛围动效。
