# 武汉经营手账

武汉首页左侧改为今日营业牌，通过「经营手账」进入与天津同布局的双页账本。左页三列四行显示 Day 1～12，右页显示当日主题、武汉食物或设备插图，以及存档中的最佳收入、满意度与 Perfect 单数。

- `Scripts/UI/WuhanHub.cs` 管理入口、今日记录和原有 `DayRequested(int)` 营业路由。
- `Scripts/UI/WuhanLedger.cs` 负责模态遮挡、日期预览、存档展示、键盘焦点及营业请求。默认选中武汉最高已解锁日；已打开时刷新存档保留正在查看的日期。
- 复用天津账本和书签原始纹理，以局部着色器映射为武汉米白纸面、青绿封皮和墨绿描边；素材文件不变。插图取自 `WuhanArtCatalog`，面碗由现有空碗和拌匀面条组合。
- 日期只预览，右页按钮才开始营业。锁定日期可查看前一天解锁条件，禁止营业；启动时再次检查进度和存档错误。
- 记录仅取 `SaveData.Wuhan`，预览和选关不修改金币及其他城市记录；沿用既有重玩差额结算。印章表示已有记录，星级仅在章节汇总显示。
- 无记录显示「等待开店」，存档异常时禁用手账与首页营业按钮，并指引返回天津手账使用现有全局重置入口。
- 遮挡层拦截背景点击；Tab／Shift+Tab 循环焦点，方向键移动日期焦点，Space／Enter 激活按钮，Esc／「合上手账」关闭并恢复入口焦点。无翻页动画。
