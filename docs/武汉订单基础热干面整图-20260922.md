# 武汉订单基础热干面整图

订单气泡原先分别缩放空碗和面条层，共行布局缩窄时会造成相对位置不一致。现在使用 `resource/art/Wuhan/基础热干面完整成品.png`，碗和面条作为一张图整体缩放，共行宽度也按该整图计算。加料图标仍独立展示；工作台制作图层和手账成品图保持原用途。正式版与试玩版共用此订单组件。
