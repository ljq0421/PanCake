# 全项目音效方向与入账爽感

## 用户明确的方向

2026-09-16，用户要求：金币入账是游戏爽点，反馈要鲜明、爽快；整个项目的音效与处理可以参考《小丑牌》。此前听感偏好：K03、K07 最满意，K11 比 K10 更合适；金币必须有金属感并保持卡通感；M01、M02、M04 不采用；M03 可继续，但两次微调仍不明显。

当前仍处于先试听、再决定接入的阶段。此文记录全项目声音方向与本轮试听，不代表已修改五城音效或最终批准某个触发规则。

## 参考依据

- 用户指定《小丑牌》为参考作品。[官方网站](https://www.playbalatro.com/)、[发行方官方预告](https://www.youtube.com/watch?v=D19ZAmVjJUQ)作为后续对照入口。

## 全项目拟采用的声音层次

| 事件 | 声音方向 | 处理重点 |
| --- | --- | --- |
| 点按、取料、放下 | 短、干、有触感 | 低于奖励声，避免每次动作都抢注意力 |
| 制作、搅拌 | K03 一类弹性节奏 | 用短动作表达操作，长时间底噪保持克制 |
| 翻面、提起 | 简短移动声配明确落点 | 对齐动作成功时刻，避免松散拖尾 |
| 正确部分交付 | 较小的正向反馈 | 和订单完成、金币入账保持等级差 |
| 订单完成 | K11 方向的明亮短乐句 | 成功感明确，给收入声留空间 |
| 金币入账 | 扎实金属撞击、紧凑跳响、亮尾 | 成为经营过程最突出的正向反馈，处理主体能量 |
| 交付失败 | K07 方向的卡通回弹候选 | 清楚表达未成功，最终映射待确认 |
| 低耐心、自然超时 | 可辨识的短提示 | 保留现有提醒次数、教学保护及打烊规则 |
| 账本、暂停与通用 UI | 短而克制 | 不与经营奖励抢占前景 |

这些方向适用于整项目声音语言。不要求每个城市新增同样的制作动作，不迁移城市收银交互。

- [试听页面](D:/CodexHome-Clean-Test-20260814/visualizations/2026/09/16/01a0a9fe-94ea-72e2-b776-e42b4d32c0c8/audio-audition/cartoon/reward-v5/index.html)
- [完整配方与来源](D:/CodexHome-Clean-Test-20260814/visualizations/2026/09/16/01a0a9fe-94ea-72e2-b776-e42b4d32c0c8/audio-audition/cartoon/reward-v5/manifest.json)

R01 为一个主方向，长度 0.66 秒。结构：立即的低中频金属落点和短点击，约 22/100/162 毫秒的错落硬币层，约 55/205 毫秒的明亮金属尾音。先压低素材的孤立尖峰、建立主体，再编排层次。本轮重新制作时序、密度和包络。

旧 M03 平均 RMS 约 -32.25 dBFS；R01 约 -18 dBFS，峰值约 -5.12 dBFS。主体能量增加约 14.25 dB，未出现样本削波。这些是文件测量值，不是主观响度或爽感验收结论。页面另提供两者同为 -30 dBFS RMS 的对比，便于独立比较音色与编排。

场景试听中普通动作约 -27～-29 dBFS RMS，完成提示约 -24 dBFS RMS，与入账拉开主次。K03、K07、K11 的参照文件未改变。连续四笔入账示例使用轻微递升音高，仅演示连续奖励方向，不表示游戏新增连击、倍率或按金额分档功能。

素材继续来自已核实的 CC0 来源：Kenney RPG Audio 的硬币、金属点击与金属锅录音，以及 Sadiquecat 的金属铃声。铃声仍为公开 HQ MP3 预览，最终选用后需取得原始文件。没有使用《小丑牌》资产。来源、滤波、叠层、变调及变速参数保存在 manifest.json。

## 接入约束与验证现状

- 一笔合法收入只触发一次入账事件；一个奖励音内部可以有多个声层，不因飞币数量重复触发。
- 保留五城自动入账／点击收钱的差异，以及耐心、收入、满意度与存档规则。
- 暂停、营业明细、失焦与离开城市时停止，恢复不补播。结算账本不重复播放金币奖励。
- 完成与入账的错峰、连续变调、背景让位、同时播放上限，需在接入阶段结合游戏验证，试听时序不等于最终参数。
- 本轮交付试听、页面和方向文档。验证包含 WAV 可解码、非静音、峰值、原参照一致性、本地链接、ZIP 完整性和前后能量变化；没有 Godot 接入、实际扬声器听感验收或全城市测试。
