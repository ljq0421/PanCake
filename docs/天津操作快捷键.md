# 天津操作快捷键

鼠标补货已更新：六种小料和豆浆均长按盘碗或库存标牌0.45秒，空盘也长按；触发后可松手。详见 [天津金币托盘与长按补货](天津金币托盘与长按补货.md)。

2026-09-08：天津营业界面增加可选键盘辅助，保留完整鼠标操作。当前仅启用 F/G，不增加鸡蛋、香葱、补货或顾客选择快捷键。

| 按键 | 当前阶段的操作 |
| --- | --- |
| F | 第一面可翻时翻面；刷酱时收刷；抹酱完成或加料后折叠；折叠后装袋 |
| 鼠标右键短按 | 刷酱时收刷，保留当前酱量 |
| 鼠标右键长按 0.45 秒后拖动 | 把炉面煎饼、成品煎饼、熟油条或炸锅整批食物拖到桌面底部垃圾桶，松开丢弃；豆浆及原料不可丢弃 |
| G | 已装入生油条后下锅；普通炸锅炸制时抬篮 |
| Esc | 拖拽时取消拖拽；否则暂停或恢复营业，沿用原行为 |

制作按钮随当前阶段显示“翻面 F”“折叠 F”“装袋 F”“下锅 G”“抬篮 G”。每次按下仅执行一个当前可用动作，长按重复事件、松键及带修饰键的 F/G 不执行生产。未到可操作阶段时不响应，也不预先排队。

快捷键调用现有按钮操作，保留火候、库存、沥油等待和装袋转移动画。高级炸锅仍自动抬篮；G 不提前取出。摊面、抹酱、实物拖入、出餐与补货维持原交互。清理炉面和炸锅统一长按右键后拖入垃圾桶，F/G 不会触发丢弃。左键拖动只用于制作和出餐，不能丢弃。结束刷酱使用短按右键、F 或收刷按钮。

仅在天津营业及收尾阶段接受输入；开门倒计时、暂停、失焦、确认弹窗、结算、隐藏界面及拖拽期间屏蔽生产快捷键。实验台和其他城市不启用本次绑定。
