# P1 完整煎饼垂直切片真人验收单

> 引擎：Godot 4.7.1 stable  
> 自动检查不能替代本表。每次验收记录实际完成时间、订单和主观问题。

## 1. 首次游玩可理解性

- [ ] 不阅读开发文档，仅根据订单卡、阶段提示和按钮文字完成第一张订单。
- [ ] 能说明摊饼后存在两条互斥路径：“翻面后刷酱/放料”或“未翻面直接刷酱/放料”，之后都进入折叠、包装和出餐。
- [ ] 鸡蛋只可在第一面加入；翻面前酱料与其他小料不可用，翻面后点击酱料自动刷匀，点击“打包”自动折叠并装袋。
- [ ] 翻面路径仍可正常完成；翻面成功后无需等待即可直接挤酱。
- [ ] 能分辨甜面酱瓶与辣椒酱瓶，并理解点击形成最小酱团、长按增加用量、切换酱瓶不会清空另一种酱团。

## 2. 连续操作与画面

- [ ] 左侧工具架的四件工具点击范围符合视觉预期；右侧六格全部是小料位，前四格可拖拽、后两格明确保留待上架。
- [ ] 配料拖到饼外时会回到托盘；落在破洞或无饼区域时提示清楚。
- [ ] 完整鸡蛋拖动、刚打入的生蛋图和开始摊动后的程序化蛋层衔接自然，没有明显跳变或双重叠图。
- [ ] T 形摊面器接触蛋黄后能看到蛋黄破开；新手以约 4 个逐渐扩大的圈即可达到可翻面覆盖，不需要长时间反复画圈。
- [ ] 从第一圈到第四圈，摊蛋拖动保持跟手，不随蛋液覆盖扩大出现越来越明显的掉帧或输入滞后。
- [ ] 鸡蛋、薄脆、火腿肠、葱花在真实运行尺寸下都能辨认，且不会遮住火候和酱料判断。
- [ ] 鏊子外圈、底部区域和左侧控制条可舒适到达，没有 UI 截断有效椭圆操作域。
- [ ] 鏊子下沿完整位于工作台桌面内，不再压入前方抽屉或越出桌面。
- [ ] 鏊子上沿与收款槽之间有清晰间隔；顾客下沿贴近柜台，人物与鏊子的相对位置接近 `visual_style_anchor_v8.png`。
- [ ] 第一面颜色变化足以支持翻面判断；翻面后立即开放酱瓶与小料，不出现第二面等待或“确认火候”按钮。
- [ ] 点击/长按酱瓶时，两种未摊开酱团的大小变化可见；酱刷经过后酱团缩小且刷痕扩散。
- [ ] 两种酱料在饼面上的颜色、重叠和浓度差异可见。
- [ ] 折叠前、折叠拖动中和单边落下后，未被覆盖的酱痕颜色不变；翻起内侧的酱随曲面移动，不出现平面色块覆盖。
- [ ] 折片压住的酱痕随遮挡隐藏，双折完成后不再透出内部酱料。

## 3. 订单、评分与反馈

- [ ] 至少完成经典、香辣火腿、双酱全料三种订单。
- [ ] 故意漏放一种配料后，订单分与顾客反馈明确指出缺失。
- [ ] 故意放入订单外配料后，订单分与反馈能区分“多放”而不是“缺少”。
- [ ] 分别制作火候偏生、偏焦和两面较均匀的成品，火候评分顺序符合观察。
- [ ] 配料明显靠边、堆在中央和较均匀摆放时，配料评分与标签有可理解差异。
- [ ] 分别制作鸡蛋覆盖不足、局部堆积和较均匀摊开的成品，“摊蛋”分、标签和总分顺序符合观察。
- [ ] 厚料压在折片上时能出现鼓包；严重破洞仍可用托盘结束，不产生死路。
- [ ] 两侧折叠落稳后自动装入纸袋，没有额外包装选择；破损只影响成品质量分。

## 4. 节奏、暂停与声音

- [ ] 单张正常订单制作时间落在暂定 35–70 秒附近；若普遍超出，记录具体步骤。
- [ ] 最低火力下新手用约一分钟完成摊饼与打蛋时不会焦化；默认火力下正常学习操作也不会迅速变焦。
- [ ] 进入刷酱/配料阶段后，即使停留观察和放料，面饼也不再继续焦化。
- [ ] 耐心下降能制造压力，但不会迫使玩家放弃观察面饼。
- [ ] `Esc` 暂停期间火候和顾客耐心都不继续推进。
- [ ] 倒面、摊面、翻面、刷酱、放料、折叠和出餐提示音不会刺耳或过密。
- [ ] 完成评价后能收款并进入下一订单，面饼、配料、工具、酱刷和包装全部重置。
