是的，而且从这张截图看，问题不只是“升级前后的设备长得不够不一样”，而是：**玩家看到了升级条件和参数，却没有直观地看到“花完这笔金币，下一次营业会有什么不同”。**

最明显的例子就是煮面锅：**“面篮数量从 1 个变成 2 个”本来可以成为很有吸引力的升级点，但现在它藏在右下角被遮挡的参数区域里；反而“当前等级”的六行说明占据了主要位置。**

我建议保留现在的左右书页结构，重点重做“升级收益的表达”，而不是继续增加装饰或说明文字。

## 一、当前页面为什么没有把升级的吸引力表现出来？

| 当前表现                 | 对升级动机的影响                     | 建议改变                        |
| -------------------- | ---------------------------- | --------------------------- |
| 中间只有一张煮面锅大图          | 无法直接辨认买完以后设备哪里变了             | 当前设备与升级后设备同框展示              |
| 标题主要是“煮面锅、Lv2 → Lv3” | 强调了等级，但没有说清获得什么能力            | 增加功能名称，例如“双篮煮面锅”            |
| 当前属性完整列出，升级后属性需要滚动   | 玩家先读到已经拥有的东西，新能力反而不显眼        | 默认只展示本次发生的变化                |
| 升级费用、禁用按钮很突出，收益不突出   | 先看到“要付多少钱、现在不能买”，后看到“为什么值得买” | 先展示能力，再展示价格与条件              |
| 左侧是“待解锁、未开放、生面无限供应”  | 这次访问似乎没有一个清晰、可追求的购买目标        | 区分“设备未开放”“下一级未开放”“已拥有的常驻能力” |

尤其是左侧煮面锅已经显示 **Lv2**，下面却写“待解锁”，容易产生语义冲突。

这里应该明确写成：

**“下一级：第 7 天后开放”**

而不是让玩家误以为“这口锅本身还没有解锁”。

---

## 二、先把“参数变化”翻译成“玩家想获得的能力”

### 煮面锅这次升级，主卖点应该是“一口锅，同时煮两份面”

建议把右页的标题层级改成：

> **双篮煮面锅**
> 一口锅，同时煮两份面
> 煮面锅 Lv2 → Lv3

“Lv2 → Lv3”继续保留，但作为辅助信息，不再承担主要的吸引任务。

因为“升到三级”只是系统层面的进度，**“可以同时煮两份面”才是玩家能够想象的下一局体验。**

这里有一个重要边界：截图可以确认升级后面篮变成两个，但**不要直接宣传为“出餐效率翻倍”或“收入翻倍”**。热干面后面还有加料、拌面、交付，整体收益还受这些环节影响。

更准确、也更有画面感的说法是：

> **两份面一起下锅，连续来客也能提前准备。**

其他升级也可以按照同样的方法改写，但只展示本级实际提供的功能：

| 真正发生的升级变化 | 面向玩家的主要表达              |
| --------- | ---------------------- |
| 面篮数量增加    | **两份面，可以同时煮**          |
| 开启自动提篮    | **煮好了自己提，不用一直守着锅**     |
| 开启最佳熟度锁定  | **面煮好后，不再担心煮过头**       |
| 开启自动翻面    | **豆皮自己翻，腾出手来做热干面**     |
| 增加有限食材容量  | **多备一些，忙起来少补几次货**      |
| 缩短制作时间    | **下一份，更快出锅**；旁边再补实际时间差 |

**主文案讲体验，次文案讲数值。** 不需要删掉数值，只是不让数值独自负责说服玩家。

## 三、右书页建议改成“看得见的对比”，取消默认参数滚动

我建议右页从上到下分成四个区域，而且核心内容全部在一屏内看完。

### 1. 顶部：本次升级到底获得什么

不要同时堆“设备名、当前等级、升级后等级、两张参数表标题”。

压缩成：

> **双篮煮面锅**
> **一口锅，同时煮两份面**
> Lv2 → Lv3

其中第二行可以放在一条浅金色纸签上，成为右页最醒目的收益说明。

### 2. 中部：现在与升级后，两台设备直接比较

这是最值得腾出空间的区域。

| 现在 · Lv2    | 升级后 · Lv3   |
| ----------- | ----------- |
| 当前设备插图      | 双篮结构的设备插图   |
| **同时煮 1 份** | **同时煮 2 份** |
| 一个可工作的煮面位   | 两个可同时工作的煮面位 |

两台设备使用**相同视角、相近展示尺度**，这样结构差异才容易辨认。升级后的设备可以有一点浅金色底衬，但不要主要依赖金边、闪光和星星来表示升级。

你现在中间那张大锅图已经占用了不少空间，把它与右侧的两张参数卡重新整合，完全可以做成这一组横向对比。

美术上仍然保持手账风格：**两张设备贴图、简洁的小标题、一根箭头、一条收益纸签**，不用再嵌套两层厚边框面板。

### 3. 下部：只列“本次新增”，不重复已有能力

例如这次确定发生的是双篮变化，那么重点就是：

> **新增：双篮同时工作**

若当前配置也确实开启自动提篮，再增加第二项：

> **新增：煮好自动提篮**

像“锁定最佳熟度：开启”，如果升级前后都没有变化，就不应该继续占据主要展示位置。

现有的最佳煮面时间、自然沥水时间、快速沥水时间等，可以收进一个小型的 **“详细参数”** 入口，供想研究数值的玩家查看。

**不是不要详细信息，而是不让详细信息挡住升级理由。**

### 4. 底部：价格与购买状态

保持一个固定的购买区域，不再让“升级后”参数卡延伸到它下面。

推荐顺序是：

> 升级价格：**520 金币**
> 解锁条件 / 当前还差多少
> 操作按钮

这样右页的阅读过程就变成：

**得到什么 → 哪里不同 → 新增什么 → 需要多少金币。**

而不是现在的：

**看一口锅 → 读当前参数 → 找升级后参数 → 发现不能买。**

## 四、设备外观必须把“功能变化”画出来，而不是只把高级设备画得更豪华

这是升级动力的第二个关键：**商店里承诺的新能力，买完之后必须在工作台上持续看得见。**

### 煮面锅：让“双工作位”成为真正的造型区别

建议 Lv2 与 Lv3 的主要差别放在结构上：

**Lv2** 保留单工作位特征，锅沿只有一组明确的操作位置。

**Lv3** 增加能够辨认的双工作位结构，例如两个锅沿卡槽、双提篮支架，或者与实际交互一致的双篮组件。只要看一眼，就知道它能同时处理两份。

也不需要为了表现双篮把锅无限放大，挤占武汉工作台。可以在既有设备占地内调整结构。

考虑到你之前对武汉空锅素材有“锅中不要固定画漏勺”的要求，建议：

**锅体与篮子、支架分层制作，不把两个漏勺永久烘焙进空锅底图。** 升级页的工作状态预览可以显示实际使用中的篮子，空闲锅体仍然保持干净。

### 自动化升级：必须有一个能看懂的动作

例如实际提供自动提篮时，升级后的独特表现应该是：

> 面煮好 → 机构带动篮子升起 → 停在沥水位置。

实际提供豆皮自动翻面时，则应该有：

> 翻面机构启动 → 豆皮翻面 → 继续煎制。

这些动作比“自动提篮：开启”“自动翻面：开启”更能说明升级价值。

但不要为了让高级设备看起来厉害，就添加实际玩法里不存在的机械臂、额外操作位或自动流程。**升级页与营业中的设备必须说同一件事。**

## 五、增加一个很短的“工作预览”，比再写三行说明更合适

对于双篮升级，我建议在选中设备时，让中间的对比区域播放一次约 **2～3 秒的工作预览**。

左侧表现：一份面在煮，另一份还在等待。

右侧表现：两份面同时进入各自的煮面位，一起处于制作状态。

预览只演示煮面环节，不直接跳成“两份完整热干面自动出餐”，避免夸大实际效果。节奏和动作也应该符合本级真实功能。

播放一次后停留在清晰的对比状态，旁边放一个很小的重播图标。**不建议两口锅一直循环弹跳、闪光，那会让手账页面显得吵，也会抢走价格和按钮的注意力。**

购买成功之后，可以接一个短演出：

**金币扣除 → 新组件“咔嗒”装上 → “双篮开工”小印章落下 → 新设备轻弹一次。**

这里的“新组件装上”很重要。它把抽象的数值购买变成了“我真的给店里添置了东西”，也符合你现在想增加的可爱动感。

## 六、截图里的购买条件，也正在削弱“再开一天就能买”的期待

你现在有 **496 金币**，升级需要 **520 金币**，实际只差 **24 金币**。

这个差额本来可以形成一个很清晰的小目标，但页面没有把它表达出来；与此同时，下面又写着“完成第 7 天后开放”。

这两种限制要分别说清楚，不能只统一变灰：

| 当前状态         | 建议表达                            |
| ------------ | ------------------------------- |
| 还没达到营业日条件    | 按钮写 **“第 7 天后可升级”**，价格旁补充当前资金差额 |
| 营业日已满足，但金币不足 | 按钮写 **“还差 24 金币”**，随实际余额更新      |
| 营业日和金币都满足    | 按钮写 **“升级为双篮锅”**，价格紧邻按钮显示       |

当营业日还没满足时，不要只强调“再赚 24 金币”，否则玩家赚够钱以后仍然不能购买，会觉得页面没有把条件讲清楚。

同时，**锁住的应该是购买按钮，不是对未来能力的展示**。尚未开放的升级，也应该能看清设备、收益和工作预览，让玩家有理由期待。

左页的“备料台 Lv1｜生面无限供应”也值得单独处理：如果生面已经无限供应，而且这个项目没有真实的后续升级，就不适合继续用“Lv1”的成长语义展示。可以改成“已生效”的常驻能力，降低它在升级列表里的权重；有其他真实可升级内容时，再展示那些内容。

## 七、页面改完之后，还要让下一次营业兑现这次升级

结合你之前真人试玩反馈“太平缓、缺少继续营业的冲动”，我认为这里不能只做成一个更漂亮的商店。

**玩家需要在买完之后，真的用一次新能力，并意识到“这钱花得值”。**

例如购买双篮锅后的下一次营业，在自然出现连续热干面订单时，用一次很轻的设备局部提示，引导玩家把两份面同时下锅。不要重新弹整页教学，也不要立即增加一大波订单，把刚获得的优势全部抵消掉。

升级的方向应该是：

**减少重复等待和盯锅负担，让玩家更从容地安排热干面与豆皮的制作顺序。**

而不是把所有核心操作都自动做完，也不是让基础设备故意难用来逼迫购买。

另外，建议检查升级页第一次正式开放给玩家时，是否至少存在一个已经解锁、能够通过短期经营争取到的购买目标。截图里三个项目分别处于“下一级锁定、设备未开放、无限供应”的状态；如果玩家在试玩早期反复看到的都是这种组合，再好的对比美术也很难变成实际的购买动力。

---

**我的优先级建议是：先把煮面锅 Lv2 → Lv3 做成一个完整样板——“单份与双份同框对比、功能结构明显不同、本次收益无需滚动、购买条件说清楚、买完下一局能马上用出来”。**

暂时不用急着提高所有升级数值，也不能仅凭这张截图判断 520 金币是否太贵。先让玩家看懂并体验到这笔钱买到了什么，再判断升级效果和价格是否还需要调整。
