## A. 新玩家首日闭环

开始前不阅读开发文档，只依据游戏内订单、箭头、阶段提示和控件反馈操作。

- [ ] 新游戏只看到煎饼区可用；基础面糊和秘制酱料可用，鸡蛋、薄脆、葱花等付费配料未解锁且不会进入首单。
- [ ] 5 秒开场备货结束后，首个教学顾客与订单自动出现，不需要重进场景或手动刷新。
- [ ] 教学期间显示“教学中”，等待、暂停和尝试操作均不会消耗营业倒计时；教学单不能被误拒绝。
- [ ] 第一次能理解“点击面糊勺，再在鏊面按住倒面”，且有效按下不会闪退回空闲状态或需要重复点击。
- [ ] 第一次能理解点击摊饼器后在鏊面画圈；鼠标快速移动、经过边缘和松手时没有断笔、粘住或明显输入滞后。
- [ ] 合法阶段能理解主按钮用于翻面，点击后状态与画面反馈一致。
- [ ] 翻面后点击秘制酱料会自动刷匀，不会留下一个仍需手动拖动的酱刷。
- [ ] 点击“打包”一次后能看到两侧自动折叠、装袋并进入可交付状态；无需再抓饼边或补点第二次。
- [ ] 点击教学顾客订单卡里的煎饼商品后，成品只交给该顾客，并完成教学。
- [ ] 教学结束后营业倒计时从 60 秒保留值继续下降；第 2 日及以后为 120 秒。

## B. 配料、补货、评分与交付

使用正常成长流程已解锁至少一种付费配料的存档，不直接修改运行时数据。

- [ ] 短点击有库存配料会在稳定、可预测的位置加入一份；不会意外进入拖拽模式。
- [ ] 空库存时短点击不会扣钱或产生幽灵配料；原地长按约 0.20 秒能进入补货，移动或松手能可靠结束。
- [ ] 补货逐份扣费且不会多扣；中途松手后续按能保留未完成进度。
- [ ] 正确种类与份数的配料即得到正确配方反馈；固定落点靠边不会被评价为“易漏”或额外扣配料分。
- [ ] 故意漏放、多放和加入订单外配料时，反馈能分别指出真实差异。
- [ ] 场上有多个顾客时，点击某一订单商品只服务该顾客，不会交给先前焦点或相邻卡片。
- [ ] 只有一个可用成品时，一次点击只消耗一份；没有双交付、丢失或重复结算。
- [ ] 连续倒计时、顾客耐心和生产状态变化超过 2 秒后，退出再继续能恢复最近状态，不出现明显回档。
