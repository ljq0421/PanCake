# 全城市顾客反馈与金币音效

2026-09-13 实施，覆盖天津、武汉、西安、广州、扬州。

## 已确认行为

| 事件 | 播放规则 |
| --- | --- |
| 进店 | 不响 |
| 正确部分交付 | 短促正向提示；一次操作一次，包括武汉批量豆皮 |
| 订单完成 | 明亮完成音，替代最后一件的部分交付音；错误评价改为负向音 |
| 交付失败 | 错配、重复交付、无成品、无有效目标、未配齐上桌均有错误音；连续错误间隔至少 400 毫秒 |
| 低耐心 | 沿用现有生气阈值，每位顾客每次营业只提醒一次；教学耐心保护期间不响；同类声音间隔至少 500 毫秒 |
| 自然超时 | 短下降音，同类声音间隔至少 500 毫秒；打烊批量清理不响 |
| 天津、武汉金币 | 每笔正金额营业收入记账后响一次，不依赖飞币数量及动画设置 |
| 西安金币 | 成功点击收钱时响一次，合并金额一次播放；付款落盘和空盘点击不响 |
| 广州、扬州金币 | 经用户补充确认：保留现有无点击收钱入口的交互，订单完成、营业收入增加时响一次 |

扬州成功放入备餐托盘仍属制作操作，不播放顾客交付音；整盘上桌才播放完成及金币声。未修改顾客耐心、营业收入、最终满意度或存档格式。结算账本的收入计数动画不再重复播放金币声。

## 共享实现

- `BusinessFeedback` 发布含顾客标识、结果类别及金额的语义事件，保存每次营业的低耐心提醒记录。
- `DayController` 将一次交付操作包成一次反馈事务；武汉批量豆皮完成后只生成一次顾客反馈。共享顾客队列区分生气变化、自然超时与强制清理。
- `YangzhouSession` 使用同一事件源，适配整盘上桌与独立营业时钟。
- `BusinessFeedbackAudio` 缓存 22050 Hz、16 位单声道合成 PCM，所有提示短于半秒，具有淡入淡出包络。每类最多三路声音；金币与顾客使用独立播放器，避免互相覆盖。
- 五城界面按各自可操作状态绑定共享播放器；金币盘复用同一播放器实现。暂停、账本、失焦或隐藏时停止，不排队补播。重新绑定及退出场景解除旧订阅。
- 西安、广州原生拖放在松开鼠标后判断拒绝目标；悬停不播放，取消不播放。
