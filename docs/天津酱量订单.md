# 天津酱量订单

## 已确认规则

| 订单要求 | 合格酱量 | 随机出现概率 |
| --- | --- | --- |
| 少酱 | 0% ≤ 酱量 < 50% | 10% |
| 正常 | 50% ≤ 酱量 ≤ 100% | 80% |
| 多酱 | 100% < 酱量 ≤ 150% | 10% |

50%和100%都算正常。概率针对包含煎饼的订单；同一订单中的煎饼采用相同酱量要求。每天实际比例会随随机结果波动，相同种子可复现。

## 操作和反馈

- 点击酱罐拿刷，按住左键刷酱。提示同时显示百分比和少酱／正常／多酱。
- 点击“收刷”进入配料步骤；营业界面也可按F。0%起即可主动收刷。
- 100%时仍可继续刷，150%自动收刷。重复经过已刷区域不累加。
- 收刷保留当前数值和酱层深浅；装袋入盘、切换成品及交付均保留实际酱量。
- 订单气泡显示酱量要求，悬停可查看范围；成品悬停显示实际百分比和类型。
- 酱量不符可交付，沿用配方错配规则：整单七折、无小费、评价55，并显示“酱量不符”。错酱量交付不恢复顾客耐心。

## 实现说明

`SauceRules`统一定义范围、分类和显示文案。现有刷酱追踪仍以16个不同区域作为100%的基准，将停止点扩展到24个区域（150%）。这个值是游戏酱量指标，不是实际饼面面积百分比。

订单使用独立的确定性随机序列选择酱量，避免改变原有到店时间、配方和教学订单安排。成品通过`PreparedPancake.SauceAmount`传递到`DeliveredItem.SauceAmount`，订单行以`OrderLineData.Sauce`记录要求。
