# Project Cake UI 色彩规范

## 方向

运行时 UI 统一使用“清晨摊车”色系：深青灰承载信息，旧青绿表示可交互状态，米白保证正文可读，金黄只用于标题、焦点和关键强调。棕色保留给煎饼、酱料、木柄、竹笼等真实物件，不再作为面板或按钮的主色。

## 核心色板

| 角色 | Godot Color | 用途 |
| --- | --- | --- |
| 深青灰 | `Color(0.045, 0.09, 0.10, 1)` | 主面板、弹窗、HUD 条 |
| 次级青灰 | `Color(0.075, 0.14, 0.15, 1)` | 次级面板、进度槽、禁用底色 |
| 交互青绿 | `Color(0.10, 0.36, 0.31, 1)` | 主按钮常态 |
| 交互高亮 | `Color(0.14, 0.46, 0.38, 1)` | 悬停与键盘焦点 |
| 米白 | `Color(0.96, 0.88, 0.76, 1)` | 正文与按钮文字 |
| 金黄 | `Color(1.0, 0.82, 0.44, 1)` | 标题、焦点边框、关键数字 |

## 使用边界

- 开始页、暂停页、营业 HUD、顾客评价、订单摘要和日结页共用这一色彩关系。
- 主按钮使用青绿底；悬停和键盘焦点使用更亮青绿，并以金黄描边。
- 状态警告仍可使用红、橙、黄；耐心进度仍可按状态变化。这些是语义色，不属于界面主题冲突。
- 食物、工具、摊车和环境美术不机械改色。界面统一不能破坏物件辨识度或清晨场景的材质层次。
- 深棕文字可继续用于米白订单卡、木质标签等实体表面；禁止再把深棕用作通用弹窗、HUD 或按钮底色。
