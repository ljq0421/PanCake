## 1. 当前证据与实现边界

| 当前证据 | 必须处理的影响 |

上述为源码与资源证据，不代替运行或真人验收。工作区已有其他未提交 UI、测试及素材改动；本任务保留这些改动，不清理或回退。

## 2. 最小实现接口

### 运行配置与关卡

- 在 DataCatalog、SaveService 首次加载前确定 ExperienceProfile；公开 Demo 由构建配置确定，不能仅凭可改命令行限制范围。
- Demo 清单提供 ProfileId、ContentRevision、城市与关卡范围、稳定 StageId、展示序号、订单与到达、解锁和展示信息。
- 第一批仅交付 T1～T3 可玩验证内容；完整目标路线仍为两城。试验小包必须明确范围，不标为公开两城 Demo。
- 内容阶段与访问范围由清单决定；缺失、错配配置显示错误，不回退正式版或开放未实现关卡。
- DemoCatalogValidator 验证资源、配置、订单数与顺序；保留正式版的校验，不把固定 13 局写入共享校验器。
- 现有 int day 与稳定 StageId 的映射集中处理，UI、保存和开局使用同一来源。

### 主线与教学

保留显式 Main／Tutorial 两种运行上下文，包含 RunId、ProfileId、StageId、内容版本、有效设备、初始资源与订单计划。本版不增加 Challenge 模式、挑战成绩或人物身份字段。

| 行为 | Main 主线（含普通重玩） | Tutorial 教学 |
|---|---|---|
| 设备 | 真实已购设备 | 本次示范设备 |
| 时间 | 正常开张、营业、收摊 | 独立制作时钟与等待点 |
| 金币与推进 | 正常结算保存；收入只补历史最佳差额 | 不产生收入与主线推进 |
| 早餐记录 | 先暂存，随结算保存 | 不解锁 |
| 结束 | 结算／准备页 | 清除示例食物、输入与声音，重新准备营业 |
| 教学记忆 | 真实动作完成才记学会 | 完成与跳过分别记录 |

T3 升级验证就是普通 T3 重玩：订单、到达、耐心和初始资源规则不变，设备采用本次购买后的实际等级。测试记录分别保存首次与重玩表现，不把每次重玩完整收入重复发放。

### 存档与可靠结算

- Demo 使用独立文件和版本信息；不读取正式版旧档、不运行正式版自动解锁迁移。
- 保存主线入口、金币、设备、完成关卡、每局最佳整次记录、教学动作及必要早餐标识；不保存半局食物或本次逐单评价。
- 推进要求至少完成 1 单并正常收摊、保存成功；零完成保留真实成绩且不开放下一局，允许免费重试，已开放进度不回退。
- 提交顺序为冻结结果、构造新状态、写临时文件并替换、发布永久状态、显示解锁与下一局。
- 保存失败保留相同待提交结果与 RunId，允许重试；重复提交不重复入账，未保存时不能提前确认收藏。
- 兼容调参保留既有资产，不重发奖励；不兼容变更先设计迁移并保留旧档，不静默清空。
- 继续回到待营业的主线准备页；首次完成并保存后准备新开放的下一局，未结算退出及普通重玩保留所选日期。损坏档保留原文件并提示；游戏内明确确认后才重开旅程。

### 早餐事件与双语

- 结构化交付结果提供商品定义、品质、匹配与成功状态、RunId 和 StageId；在匹配验证、消费与进度更新后输出。
- 早餐监听器只收集标识，不重复执行耐心恢复、收入或音效。不增加 CharacterId、人物外观占位和剧情进度。
- 从第一批建立 Godot 本地化键及参数化文案，覆盖可达菜单、教程、订单帮助、升级、结算、错误和退出。
- 不为尚未实现的挑战或熟客预建持久化接口。保留现有五城正式版入口及其规则。

独立挑战、固定设备成绩比较、8 位人物／18 次出场、小记、好感度与人物收藏全部移出本版工作包。后续重新评审才可纳入，不设置占位按钮或空入口。

## 4. 质量门槛与观察表

人数门槛为内部问题发现标准，不代表统计显著性或愿望单转化预测。

| 阶段 | 版本与验收 | 未通过处理 |
|---|---|---|
| A：首份制作 | 修正后的 5 人中至少 4 人无口头指导完成首份；无教学卡死 | 修提示、落点、状态反馈，不加内容掩盖 |
| B：安排与成长 | 至少 3／5 人主动使用一种安排；至少 4／5 人理解所选升级；记录升级前后的行为差异 | 查瓶颈、练习、购买入口和时机 |
| C：完整两城 | 新的 5～8 人记录首轮时长、退出点、疲劳与两城差异；重复出现的阻断先解决 | 压重复、拆密集教学，重新测试受影响段落 |
| D：发布候选 | 实际包完成新建、两城、结尾、退出、继续；无已知丢档、越界或卡死 | 修对应问题并复验 |

首次与升级后 T3 均记录：版本、语言、同类游戏经验、购买等级、起始余额、完成／流失／错误、补货次数及中断、焦糊、主动安排、提示需求和主观收益。相近配置对照不等于严格因果实验，练习本身也会改善表现。

主线首次时长与主动重玩分开统计。观察玩家是否自愿回玩、想改善什么，作为后续挑战设计依据，不设本版回玩人数硬门槛。

不默认接入线上埋点、账号或上传服务；使用本地日志和匿名观察表。商店按钮点击只表示访问，不能直接认定新增愿望单。
