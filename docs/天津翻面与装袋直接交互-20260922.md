# 天津翻面与装袋直接交互

按会话 `01a0c832-3ef7-7490-ad50-fbd04e26fcc0` 的建议，以及本次用户确认实施。正式版与 Demo 共用实现，仅天津启用。

- 翻面：第一面可翻时，按住饼边向饼心短拖，达到约 46 个设计像素后松手确认。不按速度判定；短拖、拖回、远离炉面松手均不翻面。铲子跟随所选左右边靠近，饼皮先弯曲翘起，再接续已有软饼翻面动画。原火候计时继续，变焦时取消手势。
- 装袋：折叠后在炉子左侧出现纸袋。抓起煎饼拖近袋口，袋口张开并轻微吸附；松手确认，约 0.28 秒滑入并轻晃，随后从纸袋原位置拖给顾客。未入袋口则回炉面，不改配方或库存。
- 纸袋使用现有“装袋后的通用煎饼果子”图片的纸袋区域，通过原生纹理网格分层绘制，未新增生成素材。纸张声复用已有音效。
- 移除翻面／装袋的可见按钮，保留 F 快捷操作，教学文字与高亮指向饼面及实物纸袋。
- 手势期间不能重复操作同一份煎饼。Esc／右键取消；暂停、明细、失焦、隐藏、重置清除手势。已确认的装袋中断时直接收稳，不回滚食品；未确认时回原位。
- 减弱动态保留鼠标跟随及判定，跳过翻面腾空、装袋收尾动画。

## 翻面柔软感追加调整

## 复现

```powershell
$env:APPDATA = Join-Path (Get-Location) 'artifacts/tianjin-direct-food-20260922/profile-test'
& 'D:/Godot/GodotSharp/Godot_v4.7.1-stable_mono_win64_console.exe' --path . --log-file 'D:/Project/ProjectCake/project-cake/artifacts/tianjin-direct-food-20260922/visual.log' res://Scenes/Tests/TianjinDirectFoodSelfTest.tscn -- --capture
```

Demo 在末尾追加 `--demo-pilot`；纯逻辑测试增加 `--headless` 并去掉 `--capture`。
