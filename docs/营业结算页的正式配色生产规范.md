# 五、01｜营业结算账本底板

## 执行方式

建议：

> **一套母版 + 三个章节轻换色版。**

主体纸张完全一样，只换非常少的弱装饰。

### 天津

暖金为主，极少海河蓝。

### 武汉

浅青绿为主。

### 西安

浅砂岩 + 少量枣红。

---

## 最终母版提示词

```text
为二维休闲早餐经营游戏《早餐铺子》绘制：
“简化版营业结算账本底板”。

输出：1600×900，透明背景。

主体为一本完全摊开的双页卡通账本，正面或极轻微俯视，左右页等宽，中间窄书脊。

整体必须非常简洁：
二维、扁平、圆润、粗描边、大色块、低细节、温馨轻松。

纸面固定使用奶油米白色。
主描边固定使用深暖棕色。

底板本身只负责提供：
账本轮廓、
轻量分区、
大面积留白。

不要做成已经排版完成的页面。

页面上部预留标题空间。
左页保留大面积收入信息区域。
右页保留经营结果区域。
下部保留经营手记区域。
右下预留按钮空间。

分区只能使用很轻的内边线、少量留白或极浅色块提示。

不要文字。
不要数字。
不要功能图标。
不要复杂角花。
不要书签。
不要丝带。
不要多层边框。
不要真实纸纹。
不要木纹。
不要复杂光影。
不要噪点。
透明背景。
```

# 二十三、最终实际需要“画三套”的素材比想象中少

按照这套规范，我会把真正的美术生产压缩成：

| 类别      | 推荐处理                |
| ------- | ------------------- |
| 01 / 02 | 可以真正做天津、武汉、西安三个轻换色版 |
| 03～11   | **全章节直接共用**         |
| 12      | 一张母版 + 程序换色         |
| 13      | 基本共用                |
| 14～17   | 一张母版 + 程序换色         |
| 18      | 按菜品制作，不按章节染色        |
| 19～20   | 一张母版 + 程序换色         |

所以并不是：

> 20个素材 × 3个城市 = 60张图。

而更接近：

> **一套20件左右的UI母版 + 极少量城市换色版本。**

这更符合你目前“减少美术量、尽量复用”的整体开发方向。

# 二十四、Godot章节主题色可以直接数据化

后面程序层建议直接维护一个：

```csharp
CitySettlementTheme
```

例如概念上：

```text
天津
AccentPrimary = #D7A45F
AccentSecondary = #729DAC

武汉
AccentPrimary = #71A08D
AccentSecondary = #A9C1B3

西安
AccentPrimary = #98594D
AccentSecondary = #CBB38B
```

然后：

* 页签
* 按钮
* 头像内圈
* 贴片边条
* 分隔线
* 奖励章内圈

统一读取章节主题色。

这样以后增加第四座城市时，**不用重新设计结算系统，只需要新增一套章节Accent配色即可。**

我建议把这套作为目前天津、武汉、西安营业结算页的正式配色生产规范。
