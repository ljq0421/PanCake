# 五城页面合并与统一书页

## 当前行为（2026-09-14）

首页“继续旅程”直接进入上次实际开张城市的早餐铺合并页。地图选择城市先刷新右侧摘要，再进入对应合并页。原继续页、独立明信片页与旧城市经营首页不再作为重复的玩家导航步骤。

- 合并页展示城市、早餐、金币、推荐营业日、章节状态及下一站条件；按钮直接开张。
- 经营手账：天津三列五行，其余四城三列四行；点击日期只查看，点击营业按钮才开张。日期和右页保留真实历史成绩，天津、武汉保留随日期变化的既有主题插图。大额收入自适应字号。
- 店铺升级：天津、武汉、西安、广州三项设备，扬州两项；使用原购买接口、价格和解锁条件。武汉备料台仍为现有固定供应展示，不增加新的升级机制。左侧设备卡片只切换选中项，右侧展示真实等级与效果对比、价格及唯一购买按钮；长内容内部滚动，满级只展示当前效果。
- 浏览城市、查看手账和购买升级都不会改变继续位置。`GameController.StartCityBusiness` 校验并准备营业，成功保存继续位置后才显示工作台并启动营业；失败留在准备页，不启动计时。
- 章节完成、地图返回来源页、重置确认、扬州收藏、设置、帮助继续保留。开发工具入口、煎饼实验台、Day 数据面板、专用练习逻辑和实验工作台已移除（2026-09-15）。
- 旧城市 Hub 场景保留作为原专项测试及兼容节点；正式返回路径统一导向新合并页。

## 书页规格与素材约束

`StartScreen.CityPages.cs` 共用 `BookFrame` / `CityFrame`。1920×1080 画布中，书页纹理统一放在 `(240,150,1400,800)`，使用统一透明留白裁剪和等比居中方式。城市概览页使用用户提供的 `旅行手账双页母版-带便签.png`；经营手账、店铺升级及其他书页继续使用原双页母版。三个书签固定在 x=1610、y=290/422/554，尺寸245×100；主操作区固定在右页下方。切换内容不改变书本几何。

新旅程、章节完成以及入口设置／帮助手账也使用相同书页区域。世界地图使用现有木框母版；结算账本主体保留原样，升级弹窗复用相同的双栏设备控件，详见 `营业账本直接升级设备.md`。

没有生成、重绘、覆盖源 PNG，也没有将效果图烘焙成游戏界面。文字、点击区域、进度和设备状态均为原生 Godot 控件；裁透明留白只创建内存 AtlasTexture。

## 数据与接口

`CityPageModel` 仅负责将现有五城配置、存档和美术路径适配为页面信息。升级价格来自实际设备配置，购买有效性复用 SaveService 现有校验。金币、日期、成绩、星级均非效果图中的固定示例值。

`StartScreen` 发出带城市与日期的营业请求、带城市与升级 ID 的购买请求，由 `GameController` 接回原城市实现。天津和武汉 `Initialize` 现在返回准备是否成功，原营业逻辑不变。

存档版本仍为 v3，继续复用 `LastVisitedCityId` / `ContinueCityId`。旧档位置按原兼容规则读取；从本次开始，仅正式开张更新位置。不新增最后浏览城市字段。

- C# 构建：0 警告、0 错误。
- `CityPagesSelfTest`：197项通过（三档视口各一次），包含五城布局、日期、升级购买、失败回滚、继续位置、损坏存档、大额收入、重置与章节完成。
- `StartScreenSelfTest`：114项通过，覆盖真实鼠标／键盘入口、新旅程确认、旧档兼容、设置及章节演出。
- `TianjinLedgerSelfTest`：190项通过；`WuhanLedgerSelfTest`：51项通过，验证原手账与共享调用兼容。
- 图形验收使用独立测试存档，截图目录为 `.tmp/city-pages-review/1920`、`1280`、`1600`；对应窗口1920×1080、1280×720、1600×720。每组包含五城合并页／手账／升级、地图、锁定、满级、损坏存档及大额记录状态。

日志中的人为写盘失败与损坏存档错误属于测试注入；环境根证书读取提示仍存在。Headless 加载旧工作台时还会输出既有 FoodInk 着色器采样提示；实际 OpenGL 图形检查不出现该着色器提示。

复现共享页面测试：从项目目录运行 Godot .NET 控制台程序，传入可写 `--log-file` 和 `res://Scenes/Tests/CityPagesSelfTest.tscn`。图形截图附加 `-- --capture`，小窗口再加 `--small`，宽屏再加 `--wide`；无头逻辑检查使用 `--headless`。

2026-09-14 店铺升级重构验收：书内设备选择与效果对比采用共享 Godot 控件，现有背景与书本几何保持不变。结算升级专项 441 项通过，覆盖三档视口、滚动、全部满级、余额不足和保存失败重试。构建零警告、零错误。新增截图见 `.tmp/upgrade-book-review`；五城两类界面总览见 `.tmp/upgrade-review`。以上为本次升级重构验证，其余专项结果沿用前次记录。
