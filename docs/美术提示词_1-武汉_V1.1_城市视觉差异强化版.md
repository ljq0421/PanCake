# 零、武汉章节城市视觉DNA｜所有后续提示词最高优先级共同要求

以下规则适用于武汉章节全部场景、设备、食物容器、角色和UI素材。除非某一单项提示词明确要求透明背景或必须与既有素材严格对齐，否则均默认继承本节。

## A｜与天津统一的内容

武汉与天津必须属于**同一款游戏、同一美术团队、同一世界尺度**。统一保持：

- 二维、扁平、圆润、粗描边、大色块、低细节、玩具化、图标化、强卡通化
- 轻微俯视3/4卡通视角
- 深暖棕或深色统一卡通描边
- 每个物体约2～4个主要颜色层级
- 一层简单块状阴影或非常轻微柔和阴影
- 相同角色Q版比例、相同设备简化程度、相同UI圆角语言

**不要为了区分城市改变画风。城市差异只能来自配色、几何轮廓、建筑语言、环境氛围和生活细节。**

## B｜武汉专属主色体系

武汉章节必须减少天津章节大面积使用的：

- 奶油黄
- 暖木棕
- 柔和橙黄
- 浅砖红

武汉环境主色改为：

- **柔和米白**
- **浅灰米色**
- **低饱和青绿色**
- **柔和墨绿色**
- **蒸汽白**

武汉食物与重点强调色使用：

- **芝麻暖褐色**：热干面核心识别色
- **金黄色 / 暖橙黄色**：三鲜豆皮核心识别色
- **暖橙红 / 辣油红**：局部点缀
- **葱绿色**：少量食材点缀

最终形成武汉专属组合：

**青绿环境＋米白墙面＋芝麻暖褐热干面＋金黄豆皮＋暖红辣油＋蒸汽白。**

青绿色用于墙裙、遮雨棚、窗框、设备边缘、碗口装饰环、配料容器边框和少量UI装饰；**不能把整张画面全部染成绿色。**

## C｜武汉专属几何语言

天津章节的核心几何语言是：

**大圆形煎饼炉＋横向开阔工作台。**

武汉章节必须主动避开“大圆炉作为绝对中心”的轮廓。武汉工作台的识别结构应为：

- 左侧：**圆形 / 椭圆形煮面锅与漏勺**
- 中央：**较小圆形热干面碗＋横向拌面工作区**
- 右侧：**大块圆角长方形 / 方形豆皮锅**
- 角落：**很小的蛋酒冲泡台**

整体视觉轮廓应表现为：

**圆锅＋小圆碗＋大方锅的组合式紧凑工作台。**

即使只看设备黑色剪影，也应该能够与天津大圆炉工作台明显区分。

## D｜武汉专属建筑语言

武汉早餐铺背景优先使用：

- 柔和米白或浅灰米墙面
- **低饱和青绿色墙裙 / 简化瓷砖色块**
- **柔和墨绿色遮雨棚或窗口边框**
- 开放式早点铺窗口
- 少量圆凳、小桌、置物架
- 少量暖红色生活装饰作为点缀

减少天津章节明显的暖木框架和大面积砖红。

如需要增加武汉城市识别，可以在**极远背景**加入一个高度简化、低对比度、面积很小的黄鹤楼轮廓作为彩蛋，但：

- 不要成为视觉中心
- 不要做旅游海报式地标
- 不要真实建筑细节
- 面积建议不超过背景视觉面积约5%

城市识别必须主要来自早餐铺本身，而不是依赖地标。

## E｜武汉专属空气感

武汉章节表现：

**清晨、略湿润、蒸汽明显、街头过早逐渐热闹。**

允许使用：

- 1～3条非常简化的白色蒸汽线
- 窗外浅灰蓝或青灰色清晨色块
- 极少量卡通薄雾感
- 遮雨棚边缘偶尔的简化水滴元素

禁止：

- 写实雨景
- 真实湿地反射
- 镜面水光
- 写实雾效
- 摄影天气效果

所有“湿润感”仍然必须用二维大色块和极简线条表达。

## F｜武汉设备统一配色

武汉设备不要大面积使用天津式暖木黄 / 橙黄。优先使用：

- 奶油米白或浅暖灰作为主体
- 低饱和青绿色 / 墨绿色作为边缘、把手、支架或控制区点缀
- 少量暖橙红作为提示灯
- 深暖棕描边

真实金属灰只能作为极少量中性色，不能成为设备主体。

## G｜武汉餐具与容器统一识别

武汉碗、托盘、配料容器可以统一加入非常克制的：

- 青绿色边缘
- 青绿色短线装饰
- 墨绿色把手 / 底座点缀

不使用复杂花纹，不写“武汉”文字。

这样即使单独看热干面碗和配料容器，也能与天津暖黄橙色餐具产生差异。

## H｜武汉NPC色彩与人群感

角色画风与天津完全一致，但武汉NPC服装主色优先使用：

- 灰蓝
- 低饱和青绿
- 米白
- 燕麦色
- 柔和橄榄绿
- 少量暖红配饰

避免所有NPC继续大面积穿天津式橙黄、砖红、暖棕。

武汉人群更强调：

**通勤、大学生活、街坊过早、快速外带。**

不要使用所谓“地方民族服装”制造城市差异。

## I｜武汉UI城市皮肤

所有城市共用同一UI结构和交互位置。武汉只做约20%的城市皮肤变化：

- 订单气泡结构继续复用天津
- 耐心条结构继续复用天津
- 按钮形状继续复用天津
- 武汉章节强调色改为**低饱和青绿色 / 墨绿色**
- Perfect、金币等通用正反馈保持全游戏一致
- 可加入极少量蒸汽曲线、碗口圆弧作为章节装饰语言

优先通过Godot Theme、Modulate或可换色UI层实现，不额外增加大量美术素材。

## J｜最终城市辨识度强制测试

完成武汉场景后，假设遮掉所有：

- 城市文字
- 地名
- Logo
- 黄鹤楼等地标

仅看：

- 配色
- 工作台剪影
- 背景结构
- 蒸汽氛围
- 食物色块
- NPC组合

玩家仍应明显感受到：

**“这不是天津早餐铺，而是另一座更湿润、更紧凑、更热闹的过早城市。”**

武汉视觉关键词固定为：

# **青绿｜蒸汽｜紧凑｜芝麻暖褐｜金黄豆皮**
