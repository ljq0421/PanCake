# P1 七类音效真人听感验收

> 历史归档：本表按手动刷酱与手动折边设计，不再用于正式验收。当前音频与操作听感合并记录在 `tests/manual/four_area_current_baseline_playtest.md`。

自动检查只能确认文件、场景绑定和触发路径，不能替代真人听感。请佩戴常用耳机并用笔记本扬声器各完成一轮完整订单。

## 操作检查

- [ ] 点击面糊勺：只响一次厚实的面糊落铁板声，没有电子蜂鸣感。
- [ ] 连续画圈摊面：有效刮动才响；停手、无效向内拖或离开鏊面后不响。
- [ ] 调节火力并等待：滋滋声持续但不抢耳；高火更亮、更强，逐渐变干时会减弱，离开煎制阶段后停止。
- [ ] 合法翻面：只响一次铲起、掠过和落下组合声；被状态机拒绝时不响。
- [ ] 刷甜面酱和辣酱：真正覆盖新格子时才响；刷子空了或重复覆盖时不误响。
- [ ] 左右各折一次：每次成功越线提交都响；未越线回弹不响；自动纸袋包装不冒充折叠声。
- [ ] 合法出餐：评价面板出现时只响一次出餐声；未包装时点击不响。

## 主观检查

- [ ] 七类声音无需看画面也能大致区分。
- [ ] 刮板、刷酱连续触发时没有刺耳爆音或明显“机关枪”重复感。
- [ ] 滋滋声循环接缝不可察觉，10 分钟连续操作不明显疲劳。
- [ ] 警告音仍能压过厨房声，但总体峰值不突兀。
- [ ] 耳机与笔记本扬声器上都没有削波、底噪过大或低频轰鸣。
