# 每日挑战挂件（2026-09-21）

按本次确认，将原 HUD 下方的挑战文字替换为左上角独立手绘挂件，与居中的营业 HUD 并排。

- 使用共用 `DailyChallengePendant`。目前天津、武汉有挑战时显示；其他城市、首日与独立教学继续沿用原挑战开放规则。正式版与 Demo 共用实现。
- 挂件在 1920×1080 设计坐标中位于 `(24, 6)`，尺寸约 `480×162`，沿用游戏视口缩放；不接收鼠标输入。
- 展示“每日挑战”、挑战名称、实际条件、金币奖励。按后续确认，条件（如“完美完成 8 单”）与名称同排，放在名称右侧，删除 `0/8` 数字进度；星格按真实目标数量创建，进度取现有 `DailyChallenge.Progress`，连续好评仍用本场最高连续记录。
- 进度增加时新星点亮并轻弹约 0.44 秒；按后续确认，移除“已达成 · 结算领取”长提示，改为“挑战达成”完成章，仍保留同排任务条件。首次达成时播放共享合成金币旋律，并从奖励区飞出三枚金币进入本城收银袋投币口。已领奖显示“奖励已领取”。不做开局展开收起或持续闪烁。
- 武汉按后续确认使用米白纸面、青绿边框、墨绿文字，星章、星格与金币保留金色；天津保留暖金配色。武汉使用独立 `daily_challenge_city.gdshader` 映射同一底图，保留原 alpha 和手绘明暗。
- 奖金仍由结算发放，不修改营业收入；飞币仅作达成反馈，复用 `CashPendantFeedback`，落点复用各城市 `CashSlot`，不触发营业收入数字跳动。提示音走音效总线，遵循音量与静音。暂停、失焦、隐藏、离开场景时清除飞币并停止音效；恢复时不补播。减少动态效果设置下保留提示音，跳过飞币与轻弹。相同营业日重玩以 RunId 重置显示，重复渲染和已领奖状态不重复庆祝。
