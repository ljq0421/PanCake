# 武汉垃圾桶与右键丢弃

2026-09-11：营业工作台按豆皮是否解锁，使用 `武汉-热干面-v1.png`、`武汉-热干面-豆皮-v1.png`。两图尺寸均为 1672×941，新版纯热干面的器具与豆皮阶段对齐，移除原先横向 200 像素的布局偏移。

## 操作

- 在食物上长按鼠标右键 0.45 秒，再拖入桌面底部垃圾桶，松开右键丢弃。
- 面篮清当前一篮，面碗清一碗，锅内豆皮清当前整锅，熟豆皮库存每次扣一份。制作中、成品和焦糊均可丢弃；未投入原料不可丢弃。
- 左键继续制作和交付，不触发丢弃。焦糊豆皮的原点击清理入口已移除。
- 未达到长按门槛就移动超过共享手势阈值会取消；短按、桶外松手、Esc、暂停、失焦、隐藏或离开营业页面都不扣食物。
- 拖动时经营和烹饪时间继续。正在执行转移动画的来源暂不可拾取。丢弃不返还原料、不扣金币，也不产生订单交付或耐心恢复。

## 实现

`WuhanDayScreen.tscn` 在工作台下声明透明 `TrashZone`，直接使用背景内桶身；原图热区为 `(1008, 870, 150, 71)`，转换为工作台 1920×1080 坐标。共享 `DropZone.FixedHitRect` 确保高亮缩放不扩大破坏性命中区域。

`WuhanWorkstationTrash.cs` 复用天津使用的 `DragService`、`DropZone`、右键参数和 0.45 秒门槛，载荷为 `wuhan_trash`。成功及无效投放使用丢弃专用反馈。

面篮、面碗、锅内豆皮使用运行时批次版本；熟豆皮库存使用队首版本。长按期间、投放及吸附动画结束提交时验证来源；正常烹饪阶段变化不使批次失效，倒面、交付、整锅或部分豆皮入库会使旧来源失效。同步清理相关待倒面预约及视觉动作，不影响其他锅篮。版本号不写入存档。
