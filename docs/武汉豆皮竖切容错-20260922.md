# 武汉豆皮竖切容错 · 2026-09-22

## 已确认调整

- 真人试玩反馈：横切松手后，重新竖划仍经常失败。本次保留分两次按住切割，不增加按住转向连续切刀。
- 竖切允许从锅面任意位置起刀，上划、下划均可。锅面归一化纵向净位移达到 40%，且有效锅面覆盖达到 40% 时立即提交，不等松手。
- 竖向位移须至少为横向位移的 1.15 倍，允许适度斜划；竖切不再要求贴近某条预设切线，预览及完成刀痕吸附到原有三条竖线。
- 来回抖动不累加为完成距离，单击、短划与方向不明确的对角划动不完成切割。
- 横切维持原有切线带与 70% 覆盖要求；每锅八块、第一刀锁品质、库存及设备规则保持原样。正式版与 Demo 使用同一实现。
