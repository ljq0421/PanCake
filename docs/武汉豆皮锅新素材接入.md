## 阶段与资源

| 资源 ID | 文件 | 用途 |
| --- | --- | --- |
| doupi_skin | 豆皮基础层-透明-v1.png | 倒浆后、加蛋前；原始豆皮基础层.png 保留 |
| doupi_egg | 豆皮-鸡蛋覆盖层.png | 摊蛋、第一段煎制、翻面及尚未铺馅的区域 |

| doupi_filling_cooked | 成熟豆皮三鲜馅.png | 成熟、切块、备餐盘、交付和库存丢弃拖影 |
| doupi_burnt | 豆皮焦糊覆盖层.png | 沿用现有覆盖层，重新对齐边界 |

三鲜馅图片自带完整豆皮表面，煎制阶段直接使用整张表面，不再叠加旧皮层或额外染黄。第二段煎制按原有 BrowningProgress 平滑混合生熟图片；成熟时完全使用成熟图原色。

`WuhanDoupiPresentation` 集中保存各素材主体的源四边形；源图已有梯形透视，使用四边形 UV 映射到锅面，避免再次叠加透视。切块、库存与交付预览复用相同分片区域。锅内丢弃预览按当前阶段绘制，包含局部铺馅、成熟程度、已切刀线与剩余块数。

横一刀、竖一刀形成八块，第一刀锁定品质、焦糊时限及自动续补规则均未修改。
