- 官方授权发布仓库：https://github.com/maoken-fonts/KNMaiyuan
- 原始文件：`fonts/TTF/KNMaiyuan-Regular.ttf`，保持原样，未裁剪或修改字形。
- 授权：SIL Open Font License 1.1，完整版权声明及条款见 `OFL.txt`。
- Godot 配置：`project.godot` → `gui/theme/custom_font`。
- 各城界面继承同一字体；字号、配色和布局沿用原有设置。
- 导出脚本将许可证复制为发布目录的 `FONT-LICENSE-KNMaiyuan.txt`；导出预设也包含原始授权文件。
- 预览专用的其他字体不进入正式 Demo 发布包。
